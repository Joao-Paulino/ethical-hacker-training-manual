4. Checklist de Laboratório Unificada / Unified Lab Checklist

Checklist transversal a todos os capítulos, para garantir consistência e evidência auditável. Cross-chapter checklist to ensure consistency and auditable evidence.

4.1 Antes de começar / Before starting

  • Snapshot da VM (ou clone) / VM snapshot (or clone)
  • Rede host-only isolada / Isolated host-only network
  • Kali atualizado com as ferramentas necessárias / Kali updated with required tools
  • Windows com Sysmon + PowerShell logging (para capítulos de deteção) / Windows with Sysmon + PowerShell logging (for detection chapters)
  • Pasta de evidências criada (.\loot) / Evidence folder created
  • Registo de data/hora, operador, case ID / Date/time, operator, case ID log

4.2 Durante o exercício / During the exercise

  • Comandos registados com timestamp / Commands logged with timestamp
  • Outputs exportados (CSV/JSON) / Outputs exported (CSV/JSON)
  • Hashes SHA256 dos artefactos / SHA256 hashes of artifacts
  • PCAP quando aplicável / PCAP when applicable
  • Screenshots de findings críticos / Screenshots of critical findings
  • Notas de false positives / Notes on false positives

4.3 No fim / At the end

  • Relatório Markdown gerado / Markdown report generated
  • Manifesto SHA256 / SHA256 manifest
  • Snapshot revertido (se aplicável) / Snapshot reverted (if applicable)
  • Limpeza de artefactos temporários / Cleanup of temporary artifacts
  • Lições aprendidas registadas / Lessons learned recorded
