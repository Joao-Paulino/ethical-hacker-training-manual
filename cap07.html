2. Contexto e Relevância / Context and Relevance Original

O Live-Forensicator é um toolkit de resposta a incidentes e forense live. A ferramenta suporta integração com IA para processar os achados de forma mais eficiente, o que é útil porque a análise forense é tediosa. A integração é opcional; podes sempre confiar no teu conhecimento para verificar os achados. A ferramenta corre em Windows, Linux e macOS, mas o artigo testa em Windows. É sinalizada por AV porque o WinPmem, admin PS e hash walks parecem suspeitos — usa apenas se for apropriado para o ambiente. Live-Forensicator is an incident response and live forensics toolkit. The tool supports AI integration to process findings more efficiently, which is useful because forensic analysis is tedious. Integration is optional; you can always rely on your own knowledge to verify findings. The tool runs on Windows, Linux, and macOS, but the article tests on Windows. It gets flagged by AV because WinPmem, admin PS, and hash walks look suspicious — use it only if appropriate for the environment.

3. Setup Original

Descarrega o arquivo com os scripts. A ferramenta funciona em Windows, Linux e macOS. Em Windows, abre uma PowerShell elevada, navega até à pasta Windows\ e executa o script. Sem flags, o Forensicator corre uma recolha padrão: informação de sistema, contas de utilizador, estado de rede, processos, serviços, itens de startup, scheduled tasks, análise de event logs, histórico de browser, atividade de ficheiros/USB, e o motor Sigma (que corre sempre por omissão). Download the archive with scripts. The tool works on Windows, Linux, and macOS. On Windows, open an elevated PowerShell, navigate to the Windows\ folder, and run the script. Without flags, Forensicator runs a standard collection: system information, user accounts, network state, processes, services, startup items, scheduled tasks, event log analysis, browser history, files/USB activity, and the Sigma engine (which always runs by default).

O -EVTX extrai event logs; -RAM faz dump de RAM (WinPmem); -PCAP captura tráfego de rede (120s); -BROWSER usa o Nirsoft Browser History View; -ENCRYPTED encripta os artefactos com AES. Podes combinar flags. -EVTX extracts event logs; -RAM dumps RAM (WinPmem); -PCAP captures network traffic (120s); -BROWSER uses Nirsoft Browser History View; -ENCRYPTED encrypts artifacts with AES. You can combine flags.

6. Forensicator AI Original

A IA está desligada por omissão. Quando ativada, cada achado é enviado ao modelo depois de ser construído e recebe um veredicto em linguagem simples, mostrado no tooltip do relatório. Se o modelo estiver em baixo, a recolha termina na mesma e essa linha fica sem veredicto. A IA torna a execução muito mais lenta porque cada achado é uma chamada real ao modelo. AI is off by default. When enabled, each finding is sent to the model after it's built and gets a plain-language verdict shown in the report's tooltip. If the model is down, collection still finishes and that row has no verdict. AI makes the run much slower because every finding is a real model call.

7. Scripts de Impacto / Impact Scripts Impacto Complementar

O Live-Forensicator é excelente para recolha abrangente, mas por vezes precisas de uma verificação rápida e nativa, sem depender de ferramentas externas. Os scripts abaixo replicam a lógica de verificação em PowerShell puro, com output legível e exportação para relatório. Live-Forensicator is excellent for comprehensive collection, but sometimes you need a quick, native check without depending on external tools. The scripts below replicate verification logic in pure PowerShell, with readable output and report export.

7.1 Script 7.1 — Verificação de Artefactos Recolhidos / Collected Artifact Verification

Objetivo: após correr o Live-Forensicator, verificar se os artefactos críticos foram recolhidos e calcular hashes SHA256 para o relatório. Evidência: artifact-manifest.csv. Goal: after running Live-Forensicator, verify that critical artifacts were collected and compute SHA256 hashes for the report. Evidence: artifact-manifest.csv. 
# Script 7.1 - Artifact Verification & Manifest
param([Parameter(Mandatory)][string]$RunDir)
$critical = @("reports\index.html","artifacts","investigation","LOGS")
$results = @()
foreach ($item in $critical) {
    $path = Join-Path $RunDir $item
    if (Test-Path $path) {
        $files = if ((Get-Item $path).PSIsContainer) { Get-ChildItem $path -Recurse -File } else { Get-Item $path }
        foreach ($f in $files) {
            $results += [PSCustomObject]@{
                Artifact  = $f.FullName.Replace($RunDir,"")
                Size      = $f.Length
                SHA256    = (Get-FileHash $f.FullName -Algorithm SHA256).Hash
                Collected = $true
            }
        }
    } else {
        $results += [PSCustomObject]@{ Artifact=$item; Size=0; SHA256=""; Collected=$false }
    }
}
$out = Join-Path $RunDir "artifact-manifest.csv"
$results | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] Manifest: $out" -ForegroundColor Green
Write-Host "[+] Critical artifacts missing: $(($results | ? { -not $_.Collected }).Count)" -ForegroundColor Yellow

7.2 Script 7.2 — Verificação de Integridade de EVTX / EVTX Integrity Check

Objetivo: quando usas -EVTX, verificar se os ficheiros EVTX foram exportados corretamente e se podem ser lidos. Evidência: evtx-integrity.csv. Goal: when using -EVTX, verify EVTX files were exported correctly and can be read. Evidence: evtx-integrity.csv. 
# Script 7.2 - EVTX Integrity Check
param([Parameter(Mandatory)][string]$EvtxDir)
$results = @()
Get-ChildItem $EvtxDir -Filter "*.evtx" -Recurse -EA SilentlyContinue | ForEach-Object {
    try {
        $count = (Get-WinEvent -Path $_.FullName -MaxEvents 1 -EA Stop).Count
        $results += [PSCustomObject]@{ File=$_.Name; Readable=$true; Events=$count; Size=$_.Length }
    } catch {
        $results += [PSCustomObject]@{ File=$_.Name; Readable=$false; Events=0; Size=$_.Length }
    }
}
$out = Join-Path $EvtxDir "evtx-integrity.csv"
$results | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] EVTX files: $($results.Count), unreadable: $(($results | ? { -not $_.Readable }).Count)" -ForegroundColor Green

7.3 Script 7.3 — Extração de IOCs do Relatório / IOC Extraction from Report

Objetivo: extrair IPs e hashes do relatório HTML do Live-Forensicator para um CSV, facilitando a correlação com threat intel. Evidência: iocs-extracted.csv. Goal: extract IPs and hashes from the Live-Forensicator HTML report into a CSV, easing correlation with threat intel. Evidence: iocs-extracted.csv. 
# Script 7.3 - IOC Extraction
param([Parameter(Mandatory)][string]$ReportDir)
$html = Get-ChildItem $ReportDir -Filter "*.html" -Recurse | Get-Content -Raw
$ips = [regex]::Matches($html, '\b(?:\d{1,3}\.){3}\d{1,3}\b') | ForEach-Object { $_.Value } | Sort-Object -Unique
$hashes = [regex]::Matches($html, '\b[a-fA-F0-9]{64}\b') | ForEach-Object { $_.Value } | Sort-Object -Unique
$results = @()
$ips | ForEach-Object { $results += [PSCustomObject]@{ Type="IP"; Value=$_ } }
$hashes | ForEach-Object { $results += [PSCustomObject]@{ Type="SHA256"; Value=$_ } }
$out = Join-Path $ReportDir "iocs-extracted.csv"
$results | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] IOCs: $($results.Count) (IPs: $($ips.Count), Hashes: $($hashes.Count))" -ForegroundColor Green

9. Mitigações Blue Team / Mitigations Complementar

  1. Usar Live-Forensicator apenas em ambientes controlados — é sinalizado por AV.
  2. Correr com privilégios elevados — necessário para recolha completa.
  3. Verificar a integridade dos artefactos — usar Script 7.1 e 7.2.
  4. Não confiar apenas na IA — o Investigation Summary é um briefing, não um veredicto.
  5. Documentar a chain of custody — hashes dos artefactos recolhidos.
  6. Testar a integração com IA primeiro — Ollama local ou API comercial.
  7. Combinar com outras ferramentas — DeepBlueCLI, Chainsaw, etc..
