2. Contexto e Relevância / Context and Relevance Original

O PowerView é particularmente útil porque não requer a instalação do RSAT, sendo eficaz em ambientes furtivos ou restritos. Originalmente parte do framework PowerSploit, tornou-se a ferramenta de eleição para operações red team e pós-exploração em ambientes de domínio Windows. Passamos para o PowerView depois de aprendermos a obter dados manualmente com filtros PowerShell e LDAP, porque ferramentas externas podem não estar sempre disponíveis, especialmente em ambientes com defesas ativas. Saber extrair dados discretamente com comandos nativos do Windows é uma competência crítica. PowerView is particularly useful because it doesn't require RSAT installation, making it effective in stealthy or restricted environments. Originally part of the PowerSploit framework, it has become a go-to tool for red team operations and post-exploitation in Windows domain environments. We move to PowerView after learning manual data retrieval with PowerShell filters and LDAP because external tools may not always be available, especially in environments with active defenses. Knowing how to extract data discreetly using native Windows commands is a critical skill.

3. Importar PowerView / Importing PowerView Original

Importar um script permite chamar as suas funções conforme necessário, ao contrário de executar o script, que corre todos os comandos de uma vez. A importação pode ser restringida pela execution policy (ver Cap. 1). Importing a script lets you call its functions as needed, unlike running the script, which executes all commands at once. Importing may be restricted by execution policy (see Ch. 1). 
PS > powershell -ep bypass
PS > . .\PowerView.ps1
Nota / Note:
O ponto e espaço (. .\PowerView.ps1) é dot-sourcing — carrega o script no âmbito atual, tornando todas as funções disponíveis na sessão. The dot-space (. .\PowerView.ps1) is dot-sourcing — loads the script into the current scope, making all functions available in the session.

4. Funções de Domínio e LDAP / Domain & LDAP Functions Original Complementar / Complementary

4.1 Get-DomainDNSZone

Recupera as zonas DNS dentro de um domínio AD. Útil para compreender a estrutura interna da rede, identificar subdomínios e mapear alvos. Fornece informação sobre fronteiras de trust e resolução de nomes interna. Retrieves DNS zones within an AD domain. Useful for understanding internal network structure, identifying subdomains, and mapping targets. Provides insight into trust boundaries and internal name resolution. 
# Listar zonas DNS no domínio atual / List DNS zones in current domain:
Get-DomainDNSZone | Get-DomainDNSRecord

# Consultar domínio ou DC específico / Query specific domain or DC:
Get-DomainDNSZone -Domain corp.test.local -Server dc01.corp.test.local | Get-DomainDNSRecord -Domain corp.test.local -Server dc01.corp.test.local

# Output estruturado / Structured output:
Get-DomainDNSZone | Get-DomainDNSRecord -Properties name,whencreated

4.2 Get-Domain

Recupera informação essencial sobre o domínio: nome, SID, domain controllers e pertença à forest. Visão concisa do ambiente. Retrieves essential domain info: name, SID, domain controllers, and forest membership. Concise environment overview. 
Get-Domain
Get-Domain -Domain corp.test.local

4.3 Get-Forest

Recolhe detalhes da forest a que o domínio pertence: nome, SID, domínios membros, forest mode, global catalogs e DCs. Ajuda a mapear a topologia e fronteiras de trust. Gathers details about the forest the domain belongs to: name, SID, member domains, forest mode, global catalogs, and DCs. Helps map topology and trust boundaries. 
Get-Forest
Get-Forest -Forest corp.test.local

5. Get-DomainUser — Comandos / Commands Original

Recupera objetos de conta de utilizador do AD. Por omissão lista todos, mas podes filtrar por username, SID, filtros LDAP ou atributos específicos. É valioso para identificar contas de serviço, contas desativadas, membresias e atributos exploráveis para escalada ou movimento lateral. Retrieves user account objects from AD. By default lists all users, but you can filter by username, SID, LDAP filters, or specific attributes. Valuable for identifying service accounts, disabled accounts, memberships, and attributes exploitable for escalation or lateral movement.

5.1 Listar e detalhar / List and detail

# Listar todos os utilizadores / List all users:
Get-DomainUser

# Detalhe de um utilizador / Specific user detail:
Get-DomainUser -Identity sql_service -Properties * | Format-List

5.2 Kerberoasting (-SPN)

# Utilizadores Kerberoastable / Kerberoastable users:
Get-DomainUser -SPN -Properties samaccountname,memberof,serviceprincipalname

# Cross-domain / Cross-domain:
Get-DomainUser -SPN -Domain domain.local | select samaccountname,memberof,serviceprincipalname | fl

# Kerberoastable Domain Admins:
Get-DomainUser -SPN | Where-Object {$_.memberof -match 'Domain Admins'} | Select Name, ServicePrincipalName

5.3 AS-REP Roasting (-KerberosPreauthNotRequired)

Get-DomainUser -KerberosPreauthNotRequired

5.4 PasswordNotRequired (-UACFilter PASSWD_NOTREQD)

Get-DomainUser -UACFilter PASSWD_NOTREQD | Select-Object samaccountname,useraccountcontrol

5.5 Delegação (-UnconstrainedDelegation)

Get-DomainUser -UnconstrainedDelegation -Properties samaccountname,useraccountcontrol,memberof

5.6 SID History (-LDAPFilter '(sidHistory=*)')

Get-DomainUser -LDAPFilter '(sidHistory=*)'

5.7 Descrições com segredos / Descriptions with secrets

Get-DomainUser -Properties samaccountname,description | Where-Object {$_.description -ne $null}

5.8 Exportar para CSV / Export to CSV

Get-DomainUser -Properties samaccountname,description,memberof | Export-Csv .\users.csv -NoTypeInformation

Script 3.1 — Enumeração Completa de Utilizadores / Full User Enumeration

Objetivo: enumerar todos os utilizadores com os atributos relevantes, exportar para CSV e JSON, e mostrar um resumo no ecrã. Evidência: ficheiros users.csv e users.json + contagem. Goal: enumerate all users with relevant attributes, export to CSV and JSON, and show an on-screen summary. Evidence: users.csv and users.json files + count. 
# ============================================================
# Script 3.1 — Full User Enumeration
# Requires: PowerView.ps1 dot-sourced
# Usage: .\enum-users.ps1 -OutputDir .\loot
# ============================================================
param(
    [string]$OutputDir = ".\loot",
    [string]$Domain    = $null
)
$ErrorActionPreference = "Stop"
if (-not (Test-Path $OutputDir)) { New-Item -ItemType Directory -Path $OutputDir | Out-Null }

$props = @(
    "samaccountname","name","description","memberof","serviceprincipalname",
    "useraccountcontrol","pwdlastset","lastlogon","admincount",
    "doesnotrequirepreauth","trustedfordelegation","sidhistory","enabled"
)

Write-Host "[*] Enumerating users..." -ForegroundColor Cyan
$users = if ($Domain) {
    Get-DomainUser -Domain $Domain -Properties $props
} else {
    Get-DomainUser -Properties $props
}

$users | Select-Object $props |
    Export-Csv -Path (Join-Path $OutputDir "users.csv") -NoTypeInformation -Encoding UTF8
$users | Select-Object $props |
    ConvertTo-Json -Depth 3 |
    Out-File (Join-Path $OutputDir "users.json") -Encoding UTF8

Write-Host "[+] Total users: $($users.Count)" -ForegroundColor Green
Write-Host "[+] Enabled:     $(($users | ? { $_.enabled }).Count)" -ForegroundColor Green
Write-Host "[+] Disabled:    $(($users | ? { -not $_.enabled }).Count)" -ForegroundColor Yellow
Write-Host "[+] AdminCount=1: $(($users | ? { $_.admincount -eq 1 }).Count)" -ForegroundColor Red
Write-Host "[+] Saved to:    $OutputDir\users.csv / users.json" -ForegroundColor Green

Script 3.2 — Caça a Kerberoastable + Export para Hashcat / Kerberoastable Hunt + Hashcat Export

Objetivo: encontrar contas com SPN, priorizar as que pertencem a Domain Admins, e exportar a lista em formato pronto para hashcat -m 13100. Evidência: kerberoastable.txt (lista de SPNs) + kerberoastable.csv. Goal: find SPN accounts, prioritize those in Domain Admins, and export the list in a format ready for hashcat -m 13100. Evidence: kerberoastable.txt (SPN list) + kerberoastable.csv. 
# ============================================================
# Script 3.2 — Kerberoastable Hunt
# Requires: PowerView.ps1 dot-sourced
# Usage: .\kerberoast-hunt.ps1 -OutputDir .\loot
# Next step: request TGS with Rubeus/GetUserSPNs.py and crack
#            hashcat -m 13100 hashes.txt wordlist.txt
# ============================================================
param([string]$OutputDir = ".\loot")
$ErrorActionPreference = "Stop"
if (-not (Test-Path $OutputDir)) { New-Item -ItemType Directory -Path $OutputDir | Out-Null }

Write-Host "[*] Hunting Kerberoastable accounts..." -ForegroundColor Cyan
$spnUsers = Get-DomainUser -SPN -Properties samaccountname,memberof,serviceprincipalname,pwdlastset,admincount

$results = foreach ($u in $spnUsers) {
    [PSCustomObject]@{
        SamAccountName     = $u.samaccountname
        IsDomainAdmin      = ($u.memberof -match "Domain Admins").Count -gt 0
        IsAdminCount1      = $u.admincount -eq 1
        SPN                = ($u.serviceprincipalname -join ";")
        PasswordLastSet    = if ($u.pwdlastset -and $u.pwdlastset -gt 0) {
                                 [DateTime]::FromFileTime($u.pwdlastset)
                             } else { "NEVER" }
        Risk               = if (($u.memberof -match "Domain Admins").Count -gt 0) { "CRITICAL" }
                             elseif ($u.admincount -eq 1) { "HIGH" }
                             else { "MEDIUM" }
    }
}

$results | Sort-Object Risk, SamAccountName |
    Export-Csv (Join-Path $OutputDir "kerberoastable.csv") -NoTypeInformation -Encoding UTF8

# SPN list for Rubeus / GetUserSPNs.py
$results | Where-Object { $_.SPN } |
    ForEach-Object { $_.SPN } |
    Out-File (Join-Path $OutputDir "kerberoastable.txt") -Encoding UTF8

Write-Host "[+] Kerberoastable accounts: $($results.Count)" -ForegroundColor Green
$results | Group-Object Risk | ForEach-Object {
    $color = switch ($_.Name) { "CRITICAL" { "Red" } "HIGH" { "Yellow" } default { "Gray" } }
    Write-Host "    $($_.Name): $($_.Count)" -ForegroundColor $color
}
Write-Host "[+] Saved: $OutputDir\kerberoastable.csv / .txt" -ForegroundColor Green
Write-Host "[i] Next: Rubeus kerberoast / GetUserSPNs.py -request" -ForegroundColor Cyan
Write-Host "[i] Crack: hashcat -m 13100 hashes.txt wordlist.txt" -ForegroundColor Cyan

Script 3.3 — Caça a AS-REP Roastable + Export para Hashcat / AS-REP Roastable Hunt + Hashcat Export

Objetivo: encontrar contas sem pre-autenticação Kerberos e exportar em formato pronto para hashcat -m 18200. Evidência: asrep.csv + lista de usernames. Goal: find accounts without Kerberos pre-auth and export in a format ready for hashcat -m 18200. Evidence: asrep.csv + username list. 
# ============================================================
# Script 3.3 — AS-REP Roastable Hunt
# Requires: PowerView.ps1 dot-sourced
# Usage: .\asrep-hunt.ps1 -OutputDir .\loot
# Next step: GetNPUsers.py -dc-ip DC -usersfile users.txt -format hashcat
#            hashcat -m 18200 hashes.txt wordlist.txt
# ============================================================
param([string]$OutputDir = ".\loot")
$ErrorActionPreference = "Stop"
if (-not (Test-Path $OutputDir)) { New-Item -ItemType Directory -Path $OutputDir | Out-Null }

Write-Host "[*] Hunting AS-REP roastable accounts..." -ForegroundColor Cyan
$asrep = Get-DomainUser -KerberosPreauthNotRequired -Properties samaccountname,memberof,pwdlastset,admincount,enabled

$results = foreach ($u in $asrep) {
    [PSCustomObject]@{
        SamAccountName  = $u.samaccountname
        Enabled         = $u.enabled
        IsDomainAdmin   = ($u.memberof -match "Domain Admins").Count -gt 0
        PasswordLastSet = if ($u.pwdlastset -and $u.pwdlastset -gt 0) {
                              [DateTime]::FromFileTime($u.pwdlastset)
                          } else { "NEVER" }
        Risk            = if (($u.memberof -match "Domain Admins").Count -gt 0) { "CRITICAL" }
                          elseif ($u.admincount -eq 1) { "HIGH" }
                          else { "MEDIUM" }
    }
}

$results | Sort-Object Risk, SamAccountName |
    Export-Csv (Join-Path $OutputDir "asrep.csv") -NoTypeInformation -Encoding UTF8

$results | Where-Object { $_.Enabled } |
    ForEach-Object { $_.SamAccountName } |
    Out-File (Join-Path $OutputDir "asrep-users.txt") -Encoding UTF8

Write-Host "[+] AS-REP roastable: $($results.Count)" -ForegroundColor Green
$results | Group-Object Risk | ForEach-Object {
    $color = switch ($_.Name) { "CRITICAL" { "Red" } "HIGH" { "Yellow" } default { "Gray" } }
    Write-Host "    $($_.Name): $($_.Count)" -ForegroundColor $color
}
Write-Host "[+] Saved: $OutputDir\asrep.csv / asrep-users.txt" -ForegroundColor Green
Write-Host "[i] Next: GetNPUsers.py -dc-ip DC -usersfile asrep-users.txt -format hashcat" -ForegroundColor Cyan
Write-Host "[i] Crack: hashcat -m 18200 hashes.txt wordlist.txt" -ForegroundColor Cyan

Script 3.4 — Auditoria de Delegação / Delegation Audit

Objetivo: mapear delegação irrestrita (utilizadores + computadores), constrained e RBCD. Evidência: delegation.csv com tipo e risco. Goal: map unconstrained (users + computers), constrained, and RBCD delegation. Evidence: delegation.csv with type and risk. 
# ============================================================
# Script 3.4 — Delegation Audit
# Requires: PowerView.ps1 dot-sourced
# Usage: .\delegation-audit.ps1 -OutputDir .\loot
# ============================================================
param([string]$OutputDir = ".\loot")
$ErrorActionPreference = "Stop"
if (-not (Test-Path $OutputDir)) { New-Item -ItemType Directory -Path $OutputDir | Out-Null }

$results = @()

Write-Host "[*] Unconstrained delegation (users)..." -ForegroundColor Cyan
Get-DomainUser -UnconstrainedDelegation -Properties samaccountname,memberof,serviceprincipalname |
    ForEach-Object {
        $results += [PSCustomObject]@{
            Type           = "Unconstrained-User"
            Name           = $_.samaccountname
            MemberOf       = ($_.memberof -join ";")
            SPN            = ($_.serviceprincipalname -join ";")
            Risk           = "CRITICAL"
        }
    }

Write-Host "[*] Unconstrained delegation (computers)..." -ForegroundColor Cyan
Get-DomainComputer -Unconstrained -Properties dnshostname,memberof,serviceprincipalname |
    ForEach-Object {
        $results += [PSCustomObject]@{
            Type           = "Unconstrained-Computer"
            Name           = $_.dnshostname
            MemberOf       = ($_.memberof -join ";")
            SPN            = ($_.serviceprincipalname -join ";")
            Risk           = "CRITICAL"
        }
    }

Write-Host "[*] Constrained delegation (users)..."
Get-DomainUser -TrustedToAuth -Properties samaccountname,msds-allowedtodelegateto |
    ForEach-Object {
        $results += [PSCustomObject]@{
            Type     = "Constrained-User"
            Name     = $_.samaccountname
            MemberOf = ""
            SPN      = ($_.'msds-allowedtodelegateto' -join ";")
            Risk     = "HIGH"
        }
    }

Write-Host "[*] RBCD (computers with msDS-AllowedToActOnBehalfOfOtherIdentity)..."
Get-DomainComputer -Properties dnshostname,msds-allowedtoactonbehalfofotheridentity |
    Where-Object { $_.'msds-allowedtoactonbehalfofotheridentity' } |
    ForEach-Object {
        $results += [PSCustomObject]@{
            Type     = "RBCD-Computer"
            Name     = $_.dnshostname
            MemberOf = ""
            SPN      = "RBCD configured"
            Risk     = "HIGH"
        }
    }

$results | Export-Csv (Join-Path $OutputDir "delegation.csv") -NoTypeInformation -Encoding UTF8
Write-Host "[+] Delegation findings: $($results.Count)" -ForegroundColor Green
$results | Group-Object Type | ForEach-Object { Write-Host "    $($_.Name): $($_.Count)" }
Write-Host "[+] Saved: $OutputDir\delegation.csv" -ForegroundColor Green

Script 3.6 — Verificação e Fallback Nativo / Availability Check & Native Fallback

Objetivo: verificar se o PowerView está carregado; se não estiver, usar Get-ADUser (RSAT) como fallback. Útil quando o PowerView é bloqueado por AV/AMSI. Evidência: indicação do método usado. Goal: check whether PowerView is loaded; if not, use Get-ADUser (RSAT) as fallback. Useful when PowerView is blocked by AV/AMSI. Evidence: which method was used. 
# ============================================================
# Script 3.6 — PowerView availability check + native fallback
# Usage: .\recon-fallback.ps1
# ============================================================
function Test-PowerView {
    return [bool](Get-Command Get-DomainUser -ErrorAction SilentlyContinue)
}

function Test-RSAT {
    return [bool](Get-Module -ListAvailable ActiveDirectory)
}

Write-Host "[*] PowerView available: $(Test-PowerView)" -ForegroundColor Cyan
Write-Host "[*] RSAT available:      $(Test-RSAT)" -ForegroundColor Cyan

if (Test-PowerView) {
    Write-Host "[+] Using PowerView" -ForegroundColor Green
    Get-DomainUser -SPN -Properties samaccountname,serviceprincipalname |
        Select-Object samaccountname, serviceprincipalname
}
elseif (Test-RSAT) {
    Write-Host "[!] PowerView missing — falling back to RSAT" -ForegroundColor Yellow
    Import-Module ActiveDirectory
    Get-ADUser -Filter * -Properties ServicePrincipalName |
        Where-Object { $_.ServicePrincipalName } |
        Select-Object SamAccountName, ServicePrincipalName
}
else {
    Write-Host "[x] Neither PowerView nor RSAT available." -ForegroundColor Red
    Write-Host "[i] Use native LDAP: dsquery * -filter ""(servicePrincipalName=*)"" -attr sAMAccountName servicePrincipalName" -ForegroundColor Cyan
}
