2. Contexto e Relevância / Context and Relevance Original

O dsquery é uma ferramenta clássica do Windows: simples, rápida, e presente em máquinas de gestão de domínio ou workstations de admin. A alto nível, fala LDAP com o AD, aplica filtros, e devolve listas de objetos como utilizadores, computadores, OUs, grupos, e o que pedires. Em domínios bem configurados, corre rapidamente e dá output estruturado fácil de parsear. É conveniente quando não queres carregar ou depender de módulos ou ferramentas maiores . dsquery is a classic Windows tool: simple, fast, and present on domain-managing machines or admin workstations. At a high level, it talks LDAP to AD, applies filters, and returns object lists like users, computers, OUs, groups, and whatever you ask for. On well-configured domains, it runs quickly and gives structured output that's easy to parse. It's convenient when you don't want to load or rely on larger modules or tools .
Nota de furtividade / Stealth note:
O dsquery é um binário de sistema (parte do tooling de AD do Windows), por isso é legítimo para monitorização de endpoint. Os defensores podem não sinalizar imediatamente uma invocação, mas queries amplas ou repetitivas contra o AD podem gerar logs e atrair atenção. Enumerações grandes, wildcards que devolvem milhares de objetos, ou uso repetido de um host invulgar são detetáveis. Favorece queries direcionadas . dsquery is a system binary (part of Windows AD tooling), so it's legitimate for endpoint monitoring. Defenders may not immediately flag an invocation, but broad or repetitive queries against AD can still generate logs and attract attention. Large enumerations, wildcards returning thousands of objects, or repeated use from an unusual host are detectable. Favor targeted queries .

3. dsquery — Visão Geral Original

A sintaxe base é dsquery [filtros] [atributos]. Os tipos principais são user, computer, group, ou, e o wildcard * para queries genéricas. Para propriedades específicas de um objeto, usa-se dsget. The base syntax is dsquery [filters] [attributes]. The main types are user, computer, group, ou, and the * wildcard for generic queries. For specific object properties, use dsget.

4. Find Users Original

PS > dsquery user
Devolve contas de utilizador ativas e inativas. Útil para obter o âmbito inicial de identidades a investigar. Prioriza contas de serviço e admin primeiro. Padrões de nome comuns como svc, adm, e outros podem denunciá-las . Returns user accounts both active and inactive. Useful to get the initial scope of identities to investigate. Prioritize service and admin accounts first. Common name patterns like svc, adm, and others may give them away .

5. Find Computers Original

PS > dsquery computer
Objetos de computador revelam nomes de servidores, hosts DEV, backups, SQL, EXCH, etc. Esta variedade dá-te vetores potenciais de compromisso. Ambientes bem geridos colocam servidores em OUs, o que te diz onde vive a infraestrutura crítica e ajuda a refinar o âmbito rapidamente . Computer objects reveal server names, DEV hosts, backups, SQL, EXCH, etc. This variety gives you potential vectors of compromise. Well-managed environments place servers in OUs, which tells you where critical infrastructure lives and helps you refine scope quickly .

6. Find Groups Original

PS > dsquery * "CN=Users,DC=DOMAIN,DC=LOCAL"
Inspeciona grupos como Domain Admins, Enterprise Admins, Backup Operators e outros potencialmente valiosos. Apontam-te para alvos de alto valor e para pessoas que importam dentro da organização . Inspect groups like Domain Admins, Enterprise Admins, Backup Operators, and other potentially valuable ones. They point you to high-value targets and to people who matter inside the organization .

7. Password-Not-Required Accounts Original

PS > dsquery * -filter "(&(objectCategory=person)(objectClass=user)(userAccountControl:1.2.840.113556.1.4.803:=32))" -attr distinguishedName userAccountControl
Procura utilizadores com a flag PASSWORD_NOT_REQUIRED. É invulgar em contas privilegiadas, mas de vez em quando encontras contas legacy ou mal configuradas que valem a pena investigar. Uma conta que parece não privilegiada à primeira vista pode ainda possuir ou receber direitos que a tornam um pivot para objetos mais interessantes. Ferramentas como o BloodHound ajudam a visualizar essas relações . Searches for users with the PASSWORD_NOT_REQUIRED flag. It's uncommon on privileged accounts, but every once in a while you find legacy or misconfigured accounts worth investigating. An account that looks unprivileged at first can still own or be granted rights that make it a pivot to more interesting objects. Tools like BloodHound help visualize those relationships .

8. Domain Controllers Original

PS > dsquery * -filter "(userAccountControl:1.2.840.113556.1.4.804:=8192)" -limit 5 -attr sAMAccountName
Conhecer os nomes e IPs dos DCs é importante. São os guardiões. LDAP, Kerberos, e insights de replicação vêm deles, e hospedam as joias da coroa da autenticação de domínio . Knowing DC names and their IPs is important. They're the gatekeepers. LDAP, Kerberos, and replication insights come from them, and they host the crown jewels of domain authentication .

9. Invoke-Command — Execução Remota Original

Existem muitas formas de executar comandos remotamente. Algumas requerem binários de terceiros, outras usam capacidades nativas. Ferramentas maliciosas de terceiros são ruidosas e têm assinatura; execução nativa pode ser mais silenciosa. O Invoke-Command é a forma canónica de execução remota em PowerShell, usando WinRM . There are many ways to execute commands remotely. Some require third-party binaries, others use native capabilities. Malicious third-party tools are noisy and signatured; native execution can be quieter. Invoke-Command is the canonical PowerShell remote execution method, using WinRM . 
PS > Invoke-Command -ComputerName DC01 -ScriptBlock { Get-Process }
Para múltiplos hosts, podes passar um array de nomes. Para credenciais diferentes, usa -Credential. Para sessões persistentes, usa New-PSSession e Enter-PSSession. For multiple hosts, pass an array of names. For different credentials, use -Credential. For persistent sessions, use New-PSSession and Enter-PSSession.

10. Scripts de Impacto / Impact Scripts Impacto Complementar

Os scripts abaixo consolidam o recon AD com dsquery e PowerShell nativo. The scripts below consolidate AD recon with dsquery and native PowerShell.

10.1 Script 27.1 — Recon AD Unificado / Unified AD Recon

# Script 27.1 - Unified AD Recon
$out = ".\ad-recon.csv"
$results = @()
# Users
$users = dsquery user 2>$null
if ($users) { $users | ForEach-Object { $results += [PSCustomObject]@{ Type="User"; DN=$_ } } }
# Computers
$computers = dsquery computer 2>$null
if ($computers) { $computers | ForEach-Object { $results += [PSCustomObject]@{ Type="Computer"; DN=$_ } } }
# Groups
$groups = dsquery group 2>$null
if ($groups) { $groups | ForEach-Object { $results += [PSCustomObject]@{ Type="Group"; DN=$_ } } }
$results | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] AD recon: $($results.Count) objects -> $out" -ForegroundColor Green

10.2 Script 27.2 — Caça a PasswordNotRequired / PasswordNotRequired Hunt

# Script 27.2 - PasswordNotRequired Hunt
$out = ".\nopass-accounts.csv"
$results = @()
$filter = "(&(objectCategory=person)(objectClass=user)(userAccountControl:1.2.840.113556.1.4.803:=32))"
$raw = dsquery * -filter $filter -attr distinguishedName userAccountControl 2>$null
if ($raw) {
  for ($i = 0; $i -lt $raw.Count; $i += 2) {
    if ($raw[$i] -match "CN=") {
      $results += [PSCustomObject]@{ DN=$raw[$i]; UAC=$raw[$i+1] }
    }
  }
}
$results | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] PasswordNotRequired accounts: $($results.Count) -> $out" -ForegroundColor Yellow

10.3 Script 27.3 — Deteção de dsquery em Massa / Mass dsquery Detection

# Script 27.3 - Mass dsquery Detection
$out = ".\dsquery-detect.csv"
$hits = @()
Get-WinEvent -LogName Security -MaxEvents 3000 -EA SilentlyContinue |
  Where-Object { $_.Id -eq 4688 } | ForEach-Object {
    $xml = [xml]$_.ToXml()
    $cmd = ($xml.Event.EventData.Data | Where-Object Name -eq "CommandLine").'#text'
    if ($cmd -match "dsquery" -and $cmd -match "(\*|user$|computer$|group$)") {
      $hits += [PSCustomObject]@{ Time=$_.TimeCreated; Command=$cmd }
    }
  }
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] dsquery invocations: $($hits.Count) -> $out" -ForegroundColor Yellow
