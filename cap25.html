2. Contexto e Relevância / Context and Relevance Original

Podes ter a sorte de encontrar um servidor sem antivírus, mas deves tratar isso como exceção e não como regra. O modo "survival" significa que, mesmo que o logging não esteja a ser recolhido ativamente, deves comportar-te como se cada movimento fosse observado. A falta de proteção endpoint não te permite fazer tudo. Vimos pessoas a instalar Gsocket em máquinas Linux a pensar que garantiriam acesso, mas na realidade a monitorização de rede rapidamente detetou esses sockets e os defensores desligaram-nos. O mesmo se aplica ao Windows. You might be lucky to find a server with no antivirus at all, but you should treat that as the exception rather than the rule. Survival mode means that, even if logging is not actively collected, you must treat survival mode as if every move is observed. The lack of endpoint protection does not let you do everything. We saw people install Gsocket on Linux boxes thinking it would secure access, but in reality network monitoring quickly spotted those sockets and defenders shut them down. Same applies to Windows.

4. Script Logging Original

Talvez a verificação mais importante seja determinar se o script logging está ativo. Esta funcionalidade regista cada comando PowerShell executado. Perhaps the most important check is determining whether script logging is enabled. This feature records every executed PowerShell command. 
PS > Get-ItemProperty "HKLM:\SOFTWARE\Policies\Microsoft\Windows\PowerShell\ScriptBlockLogging"
Se EnableScriptBlockLogging estiver definido como 1, toda a tua atividade está a ser armazenada no log PowerShell Operational. Mais tarde veremos estratégias para operar nestas condições. If EnableScriptBlockLogging is set to 1, all your activity is being stored in the PowerShell Operational log. Later we will show strategies for operating under such conditions.

5. Utilizadores Original

Identificar quem mais está presente no sistema é outro passo crítico. O quser é focado no utilizador, mostrando utilizadores com sessão iniciada, tempos de inatividade e detalhes da sessão: Identifying who else is present on the system is another critical step. quser is user-focused, showing logged-in users, idle times, and session details: 
PS > quser
O qwinsta é focado na sessão, mostrando sessões ativas e inativas. É particularmente útil ao preparar um dump de LSASS, pois credenciais de sessões passadas frequentemente permanecem em memória. Também mostra o tipo de conexão (consola ou RDP): qwinsta is session-focused, showing both active and inactive sessions. It's particularly useful when preparing to dump LSASS, as credentials from past sessions often remain in memory. It also shows the connection type (console or RDP): 
PS > qwinsta

6. Enumeração de Rede Original

Navegar numa rede hostil pode ser desafiante. Por vezes ficas baixo e observas, por vezes sondas o terreno. Aqui estão os comandos essenciais para te manteres vivo. Finding your way through a hostile network can be challenging. Sometimes you stay low and watch, sometimes you poke around to test the ground. Here are the essential commands to keep you alive.

6.1 ARP Cache

PS > arp -a
As entradas ARP podem revelar sub-redes e hosts ativos. Se acabaste de aterrar num host, isto pode ser valioso. Nota: uma convenção informal comum é que organizações pequenas usam 192.168.x.x, médias usam 172.16.x.x–172.31.x.x, e grandes empresas operam em 10.0.0.0/8. Não é uma regra, mas é frequentemente verdade na prática. ARP entries can reveal subnets and active hosts. If you just landed on a host, this could be valuable. Note: a common informal convention is that smaller organizations use 192.168.x.x, mid-sized use 172.16.x.x–172.31.x.x, and larger enterprises operate within 10.0.0.0/8. This is not a rule, but it is often true in practice.

6.2 Known Hosts

PS > cat %USERPROFILE%\.ssh\known_hosts
O SSH é nativamente suportado em Windows moderno mas menos usado, já que ferramentas como PuTTY são mais comuns. Ainda assim, vale a pena verificar known hosts, pois podem dar insights sobre segmentação de rede e sub-redes. SSH is natively supported on modern Windows but less frequently used, since tools like PuTTY are more common. Still, it is worth checking for known hosts, as they might give you insights about network segmentation and subnets.

6.3 Rotas

PS > route print
A tabela de rotas expõe que redes o host conhece, incluindo VLANs, VPNs e rotas estáticas. É inestimável para mapear topologia interna e planear pivots. Aprender a ler o output pode levar algum tempo, mas vale definitivamente a pena. The route table exposes which networks the host is aware of, including VLANs, VPNs, and static routes. It's invaluable for mapping internal topology and planning pivots. Learning how to read the output can take some time, but it's definitely worth it.

6.4 Interfaces

PS > ipconfig /all
Conhecer as interfaces de rede instaladas ajuda a compreender conectividade e planear próximos passos. Mantém um registo de interfaces em hosts comprometidos para evitar tentativas de autenticação redundantes. Knowing the network interfaces installed helps you understand connectivity and plan next steps. Maintain a record of interfaces across compromised hosts to prevent redundant authentication attempts.

Adicionar contas diretamente a grupos altamente privilegiados como Domain Admins é imprudente — estes grupos são closely monitored. Hackers experientes procuram contas esquecidas, como utilizadores com o atributo "password not required" ou credenciais expostas em campos LDAP. Directly adding accounts to highly privileged groups like Domain Admins is reckless — these groups are closely monitored. Experienced hackers instead look for overlooked accounts, such as users with the "password not required" attribute or exposed credentials in LDAP fields.

8. Scripts de Impacto / Impact Scripts Impacto Complementar

Os scripts abaixo consolidam a verificação de postura defensiva e reconhecimento básico numa única execução. The scripts below consolidate defensive posture check and basic recon into a single run.

8.1 Script 25.1 — Verificação de Postura Defensiva / Defensive Posture Check

# Script 25.1 - Defensive Posture Check
$out = ".\posture-check.csv"
$results = @()
# AV
$av = Get-CimInstance -Namespace root/SecurityCenter2 -ClassName AntivirusProduct -EA SilentlyContinue
foreach ($a in $av) { $results += [PSCustomObject]@{ Check="AV"; Value=$a.displayName } }
# Script Block Logging
$sbl = (Get-ItemProperty "HKLM:\SOFTWARE\Policies\Microsoft\Windows\PowerShell\ScriptBlockLogging" -Name "EnableScriptBlockLogging" -EA SilentlyContinue).EnableScriptBlockLogging
$results += [PSCustomObject]@{ Check="ScriptBlockLogging"; Value=$sbl }
# Defender status
$mp = Get-MpComputerStatus -EA SilentlyContinue
if ($mp) { $results += [PSCustomObject]@{ Check="DefenderRealtime"; Value=$mp.RealTimeProtectionEnabled } }
$results | Export-Csv $out -NoTypeInformation -Encoding UTF8
$results | Format-Table -AutoSize

8.2 Script 25.2 — Recon de Rede Rápido / Quick Network Recon

# Script 25.2 - Quick Network Recon
$out = ".\net-recon.csv"
$results = @()
# ARP
Get-NetNeighbor -AddressFamily IPv4 -EA SilentlyContinue | Where-Object { $_.State -ne "Unreachable" } | ForEach-Object {
  $results += [PSCustomObject]@{ Type="ARP"; IP=$_.IPAddress; MAC=$_.LinkLayerAddress }
}
# Routes
Get-NetRoute -AddressFamily IPv4 -EA SilentlyContinue | ForEach-Object {
  $results += [PSCustomObject]@{ Type="Route"; IP=$_.DestinationPrefix; MAC=$_.NextHop }
}
# Interfaces
Get-NetIPAddress -AddressFamily IPv4 -EA SilentlyContinue | ForEach-Object {
  $results += [PSCustomObject]@{ Type="Interface"; IP=$_.IPAddress; MAC=$_.InterfaceAlias }
}
$results | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] Network recon: $($results.Count) entries -> $out" -ForegroundColor Green

8.3 Script 25.3 — Enumeração de Sessões e Utilizadores / Session Enumeration

# Script 25.3 - Session Enumeration
$out = ".\sessions.csv"
$results = @()
try {
  $quser = quser 2>$null
  if ($quser) { $quser | ForEach-Object { $results += [PSCustomObject]@{ Output=$_ } } }
} catch {}
try {
  $qwinsta = qwinsta 2>$null
  if ($qwinsta) { $qwinsta | ForEach-Object { $results += [PSCustomObject]@{ Output=$_ } } }
} catch {}
$results | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] Sessions captured -> $out" -ForegroundColor Green
Get-Content $out

10. Mitigações Blue Team / Mitigations Complementar

  1. Ativar Script Block Logging (4104) — deteta recon via PowerShell.
  2. Monitorizar net commands — eventos 4688 com net accounts, net group.
  3. Alertar sobre enumeração massiva de ARP/rotas — comportamento de recon.
  4. Monitorizar quser e qwinsta — recon de sessões.
  5. Restringir Get-CimInstance a utilizadores não-admin — limita enumeração de AV.
  6. Honeytokens — contas falsas em grupos, registos de rede canário.
