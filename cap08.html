2. AnyDesk — Artefactos Forenses Original

O AnyDesk é uma ferramenta de acesso remoto legítima, mas é frequentemente abusada por APTs. Os artefactos forenses incluem ficheiros de trace, logs de sessão, registo e Prefetch. O LOLRMM documenta os caminhos exatos dos ficheiros de trace: %programdata%\AnyDesk\ad_svc.trace, %programdata%\AnyDesk\connection_trace.txt, %APPDATA%\AnyDesk\connection_trace.txt, %APPDATA%\AnyDesk\ad.trace, e C:\Windows\SysWOW64\config\systemprofile\AppData\Roaming\AnyDesk\*. Um estudo forense confirma que os logs de sessão, traces de transferência de ficheiros e traces de conexão são recuperáveis em todos os cenários, e que os artefactos de memória são críticos para capturar conexões em curso. AnyDesk is a legitimate remote access tool, but it's frequently abused by APTs. Forensic artifacts include trace files, session logs, registry, and Prefetch. LOLRMM documents the exact trace file paths: %programdata%\AnyDesk\ad_svc.trace, %programdata%\AnyDesk\connection_trace.txt, %APPDATA%\AnyDesk\connection_trace.txt, %APPDATA%\AnyDesk\ad.trace, and C:\Windows\SysWOW64\config\systemprofile\AppData\Roaming\AnyDesk\*. A forensic study confirms that session logs, file transfer traces, and connection traces are recoverable in all scenarios, and memory artifacts are critical for capturing in-session connections.

2.1 Comandos de análise / Analysis commands

# Listar artefactos AnyDesk
Get-ChildItem "$env:PROGRAMDATA\AnyDesk" -Recurse -EA SilentlyContinue
Get-ChildItem "$env:APPDATA\AnyDesk" -Recurse -EA SilentlyContinue

# Ler traces
Get-Content "$env:PROGRAMDATA\AnyDesk\ad_svc.trace" -Tail 100
Get-Content "$env:APPDATA\AnyDesk\connection_trace.txt" -Tail 50

3. DeadMatter — Extração de Credenciais de Memória Original

O DeadMatter é uma ferramenta C# que extrai credenciais (NTLM hashes, DPAPI keys) de dumps de memória sem offsets fixos, usando estrutura scanning e carving. Funciona em raw dumps, minidumps, ficheiros de hibernação e ficheiros de memória de VMs. É útil quando o EDR/AV bloqueia o dump direto do LSASS — em vez de exfiltrar um dump enorme, processa localmente e extrai só o essencial. DeadMatter is a C# tool that extracts credentials (NTLM hashes, DPAPI keys) from memory dumps without fixed offsets, using structure scanning and carving. It works on raw dumps, minidumps, hibernation files, and VM memory files. It's useful when EDR/AV blocks direct LSASS dumping — instead of exfiltrating a huge dump, it processes locally and extracts only the essentials.

3.1 Compilar / Build

PS > git clone https://github.com/qsecure-labs/DeadMatter.git
PS > cd DeadMatter
PS > dotnet build -c release
O executável fica em bin\Release\Deadmatter.exe. The executable ends up in bin\Release\Deadmatter.exe.

3.2 Verificar Credential Guard / Check Credential Guard

PS > Get-CimInstance -ClassName Win32_DeviceGuard -Namespace root\Microsoft\Windows\DeviceGuard
Se estiver ativo, a extração de credenciais fica comprometida. If enabled, credential extraction is compromised.

3.3 Extrair / Extract

:: Extrair com mimikatz + carving
Deadmatter.exe -f memory_dump.raw

:: Apenas carving
Deadmatter.exe -f memory_dump.raw -m carve

:: Fingerprint do OS
Deadmatter.exe -f memory_dump.raw -m none -i

4. Nyx — Limpeza de Artefactos Forenses Original

O Nyx é um script self-contained que limpa artefactos forenses em Linux, macOS e Windows. Em Windows, os módulos incluem events (Security, Sysmon, PowerShell/Operational, AMSI, etc.), history (PowerShell history, Prefetch, Jump Lists), registry (MRUs, USB history, ShellBags, UserAssist). Nyx is a self-contained script that cleans forensic artifacts on Linux, macOS, and Windows. On Windows, modules include events (Security, Sysmon, PowerShell/Operational, AMSI, etc.), history (PowerShell history, Prefetch, Jump Lists), registry (MRUs, USB history, ShellBags, UserAssist).

4.1 Dry run (obrigatório antes de executar) / Dry run (mandatory before running)

PS > iwr https://raw.githubusercontent.com/evilsocket/nyx/refs/heads/main/nyx.ps1 -OutFile nyx.ps1
PS > .\nyx.ps1 -DryRun

4.2 Executar / Run

PS > .\nyx.ps1
# Ou módulos específicos:
PS > .\nyx.ps1 -Modules events -Force
PS > .\nyx.ps1 -Modules history -Advanced -Force

5. Compromisso baseado em HTA Original

Os atacantes abusam do mshta.exe para executar ficheiros HTA (HTML Application) remotos ou locais, contornando defesas e executando código sem dropar binários. A regra de deteção procura mshta.exe com http://, https:// ou ftp:// na linha de comando. Attackers abuse mshta.exe to execute remote or local HTA (HTML Application) files, bypassing defenses and executing code without dropping binaries. The detection rule looks for mshta.exe with http://, https://, or ftp:// in the command line. 
# Deteção: mshta.exe com URL
Get-WinEvent -LogName Security -MaxEvents 1000 |
  Where-Object { $_.Id -eq 4688 } |
  ForEach-Object {
    $xml = [xml]$_.ToXml()
    $cmd = ($xml.Event.EventData.Data | Where-Object Name -eq "CommandLine").'#text'
    if ($cmd -match "mshta\.exe.*(https?|ftp)://") { $cmd }
  }

6. APTs Chineses e LOLBAS Original

APTs chineses abusam de ferramentas nativas do Windows (LOLBAS) como nltest, certutil, netsh, reg.exe, vssadmin para reconhecimento, roubo de credenciais e movimento lateral, misturando-se com atividade administrativa rotineira. Exemplos: nltest /dclist (listar DCs), certutil -urlcache -split -f (download), reg save hklm\sam (dump SAM), netsh interface portproxy (túnel). Chinese APTs abuse native Windows tools (LOLBAS) like nltest, certutil, netsh, reg.exe, vssadmin for reconnaissance, credential theft, and lateral movement, blending into routine admin activity. Examples: nltest /dclist (list DCs), certutil -urlcache -split -f (download), reg save hklm\sam (SAM dump), netsh interface portproxy (tunnel). 
# Deteção de LOLBAS suspeitos
$patterns = @(
  "nltest.*\/dclist",
  "certutil.*-urlcache.*-f",
  "reg.*save.*hklm\\\\sam",
  "netsh.*portproxy",
  "vssadmin.*create.*shadow"
)
Get-WinEvent -LogName Security -MaxEvents 2000 |
  Where-Object { $_.Id -eq 4688 } |
  ForEach-Object {
    $xml = [xml]$_.ToXml()
    $cmd = ($xml.Event.EventData.Data | Where-Object Name -eq "CommandLine").'#text'
    foreach ($p in $patterns) { if ($cmd -match $p) { [PSCustomObject]@{ Time=$_.TimeCreated; Cmd=$cmd; Pattern=$p } } }
  }

7. Scripts de Impacto / Impact Scripts Impacto Complementar

Os scripts abaixo consolidam a análise dos artefactos numa única execução, com output legível e exportação para relatório. The scripts below consolidate artifact analysis into a single run, with readable output and report export.

7.1 Script 8.1 — Análise de Artefactos AnyDesk / AnyDesk Artifact Analysis

# Script 8.1 - AnyDesk Artifact Analyzer
$paths = @(
  "$env:PROGRAMDATA\AnyDesk",
  "$env:APPDATA\AnyDesk",
  "C:\Windows\SysWOW64\config\systemprofile\AppData\Roaming\AnyDesk"
)
$results = @()
foreach ($p in $paths) {
  if (Test-Path $p) {
    Get-ChildItem $p -Recurse -File -EA SilentlyContinue | ForEach-Object {
      $results += [PSCustomObject]@{
        Path = $_.FullName; Size = $_.Length
        SHA256 = (Get-FileHash $_.FullName -Algorithm SHA256).Hash
        LastWrite = $_.LastWriteTime
      }
    }
  }
}
$out = ".\anydesk-artifacts.csv"
$results | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] AnyDesk artifacts: $($results.Count) -> $out" -ForegroundColor Green

7.2 Script 8.2 — Deteção de Execução HTA / HTA Execution Detection

# Script 8.2 - HTA Execution Detector
$out = ".\hta-detections.csv"
$hits = @()
Get-WinEvent -LogName Security -MaxEvents 3000 -EA SilentlyContinue |
  Where-Object { $_.Id -eq 4688 } | ForEach-Object {
    $xml = [xml]$_.ToXml()
    $cmd = ($xml.Event.EventData.Data | Where-Object Name -eq "CommandLine").'#text'
    $proc = ($xml.Event.EventData.Data | Where-Object Name -eq "NewProcessName").'#text'
    if ($proc -match "mshta\.exe" -and $cmd -match "(https?|ftp)://") {
      $hits += [PSCustomObject]@{ Time=$_.TimeCreated; Process=$proc; Cmd=$cmd }
    }
  }
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] HTA hits: $($hits.Count) -> $out" -ForegroundColor Yellow

7.3 Script 8.3 — Deteção de LOLBAS / LOLBAS Detection

# Script 8.3 - LOLBAS Detector
$out = ".\lolbas-detections.csv"
$patterns = @{
  "nltest" = "nltest.*\/dclist"; "certutil_dl" = "certutil.*-urlcache.*-f"
  "reg_sam" = "reg.*save.*hklm\\\\sam"; "portproxy" = "netsh.*portproxy"
  "vssadmin" = "vssadmin.*create.*shadow"; "dnscmd" = "dnscmd.*\/enumrecords"
}
$hits = @()
Get-WinEvent -LogName Security -MaxEvents 3000 -EA SilentlyContinue |
  Where-Object { $_.Id -eq 4688 } | ForEach-Object {
    $xml = [xml]$_.ToXml()
    $cmd = ($xml.Event.EventData.Data | Where-Object Name -eq "CommandLine").'#text'
    foreach ($k in $patterns.Keys) { if ($cmd -match $patterns[$k]) { $hits += [PSCustomObject]@{ Time=$_.TimeCreated; Technique=$k; Cmd=$cmd } } }
  }
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] LOLBAS hits: $($hits.Count) -> $out" -ForegroundColor Red

7.4 Script 8.4 — Verificação de Integridade Pós-Nyx / Post-Nyx Integrity Check

# Script 8.4 - Forensic Artifact Integrity Check (deteta limpeza)
$checks = [ordered]@{
  "Security log exists" = (Get-WinEvent -LogName Security -MaxEvents 1 -EA SilentlyContinue) -ne $null
  "PowerShell history exists" = Test-Path "$env:APPDATA\Microsoft\Windows\PowerShell\PSReadLine\ConsoleHost_history.txt"
  "Prefetch files count" = (Get-ChildItem "C:\Windows\Prefetch\*.pf" -EA SilentlyContinue).Count
  "Sysmon log exists" = (Get-WinEvent -LogName "Microsoft-Windows-Sysmon/Operational" -MaxEvents 1 -EA SilentlyContinue) -ne $null
  "AMSI log exists" = (Get-WinEvent -LogName "Microsoft-Windows-Windows Defender/Operational" -MaxEvents 1 -EA SilentlyContinue) -ne $null
}
$checks.GetEnumerator() | ForEach-Object {
  $c = if ($_.Value -eq $true -or ($_.Value -is [int] -and $_.Value -gt 0)) { "Green" } else { "Red" }
  Write-Host "$($_.Key): $($_.Value)" -ForegroundColor $c
}

9. Mitigações Blue Team / Mitigations Complementar

  1. Monitorizar AnyDesk — alertar sobre instalação/execução não aprovada; recolher traces para forense.
  2. Credential Guard — ativar para proteger credenciais de memory carving.
  3. Centralizar logs — o Nyx limpa artefactos locais, mas SIEM/EDR externos preservam evidência.
  4. Desativar mshta.exe via AppLocker/WDAC se não for necessário.
  5. Monitorizar LOLBAS — alertar sobre nltest, certutil -urlcache, reg save hklm\sam, netsh portproxy.
  6. Sysmon + Script Block Logging — telemetria que o Nyx não consegue limpar se centralizada.
  7. Honeytokens — traces AnyDesk falsos, logs canário.
  8. Backups offline — contra limpeza de artefactos.
