3. Fase 1 — Recon Red Blue

3.1 Red Team

# Descobrir o domínio
PS > nltest /dsgetdc:sekvoya.local

# Enumeração de utilizadores com dsquery
PS > dsquery user

# PowerView: users com SPN (Kerberoastable)
PS > Get-DomainUser -SPN -Properties samaccountname,serviceprincipalname

# PowerView: AS-REP roastable
PS > Get-DomainUser -KerberosPreauthNotRequired

3.2 Blue Team

EventoO que mostra
4662Acesso a objetos AD (LDAP queries)
4688dsquery.exe / nltest.exe com argumentos suspeitos
4104Get-DomainUser em Script Block Logging
Mitigação: desativar pre-auth, auditar SPNs, limitar dsquery a admin workstations (Cap. 2, 3, 27). Mitigation: disable pre-auth, audit SPNs, limit dsquery to admin workstations (Ch. 2, 3, 27).
