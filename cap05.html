3. Sobrecarga de RAM / Overloading RAM Original

O script loadram.ps1 consome agressivamente memória do sistema. Aloca arrays grandes até quase toda a RAM disponível estar esgotada, deixando apenas um pequeno buffer para o OS não colapsar imediatamente. A máquina torna-se inutilizável e as aplicações deixam de responder. Pode ser usado como tática de DoS ou como distração enquanto outras atividades ocorrem. The loadram.ps1 script aggressively consumes system memory. It allocates large arrays until nearly all available RAM is exhausted, leaving only a small buffer so the OS doesn't immediately collapse. The machine becomes unusable and applications stop responding. It can be used as a DoS tactic or as a distraction while other activities take place. 
PS > .\loadram.ps1

4. Sobrecarga de CPU / Overloading CPU Original

O script loadcpu.ps1 aplica o mesmo princípio aos núcleos do processador, fixando o uso em 100% até o script ser terminado. Tal como a exaustão de RAM, pode servir de cobertura enquanto os hackers fazem outra coisa. The loadcpu.ps1 script applies the same principle to processor cores, pinning usage at 100% until the script is terminated. Just like RAM exhaustion, it can serve as cover while hackers do something else. 
PS > .\loadcpu.ps1

5. Windows License Killer Original

O script license.ps1 limpa as chaves de produto Windows, apagando entradas OEM, retail e volume license do registo. O sistema fica sem dados de ativação. Após reiniciar o Software Protection Service, o Windows fica sem licença e pode recusar validar contra os servidores da Microsoft. The license.ps1 script clears Windows product keys by wiping OEM, retail, and volume license entries from the registry. The system is stripped of activation data. After restarting the Software Protection Service, Windows will be unlicensed and may refuse to validate against Microsoft servers.

5.1 Usage

PS > .\license.ps1

5.2 Verificar chave apagada / Verify key wiped

PS > (Get-WmiObject -query 'select * from SoftwareLicensingService').OA3xOriginalProductKey
O resultado deve estar vazio. The result should be empty.

6. USB e Network Killer Original

Podes matar adaptadores de rede e controladores USB com o script killer.ps1. Depois de o executar, o rato e o teclado deixam de funcionar. Não haverá forma de transferir ficheiros, ligar à rede ou sequer ligar um dispositivo de recuperação sem intervenção significativa. You can kill network adapters and USB controllers with the killer.ps1 script. Once you run it, the mouse and keyboard will stop working. There will be no way to transfer files, connect to the network, or even plug in a recovery device without significant intervention. 
PS > .\killer.ps1

7. Mayhem — Set-CriticalProcess Original Destrutivo

O PowerSploit inclui um módulo chamado Mayhem com duas funções destrutivas. O Windows protege smss.exe e csrss.exe marcando-os como críticos. Se forem terminados, o sistema desencadeia um Blue Screen of Death. Set-CriticalProcess pode marcar qualquer processo com este estatuto crítico. Matá-lo força imediatamente um crash do sistema. PowerSploit includes a module called Mayhem with two destructive functions. Windows protects smss.exe and csrss.exe by marking them as critical. If they are terminated, the system triggers a Blue Screen of Death. Set-CriticalProcess can tag any process with this critical status. Killing it immediately forces a system crash.

7.1 Setup

Copiar o módulo Mayhem do repositório para C:\Program Files\WindowsPowerShell\Modules\. Copy the Mayhem module from the repository to C:\Program Files\WindowsPowerShell\Modules\.

7.2 Executar / Run

PS > Set-CriticalProcess
Confirmar com Y e esperar que a máquina faça BSOD em momentos. Confirm with Y and expect the machine to blue screen in moments.

8. Mayhem — Set-MasterBootRecord Original Irreversível

Esta é a mais destrutiva de todas. Ao contrário do Set-CriticalProcess, este ataque corrompe o Master Boot Record (MBR), que é o primeiro setor do disco rígido. O MBR contém o bootloader e a tabela de partições; sem ele, o Windows não consegue carregar. Quando é sobrescrito, o sistema pode apenas mostrar a tua mensagem personalizada e recusar arrancar para o OS. O OS só funcionará se reparares o MBR, mas as chances são de teres de reinstalar o sistema. This is the most destructive of all. Unlike Set-CriticalProcess, this attack corrupts the Master Boot Record (MBR), which is the first sector of the hard drive. The MBR has the bootloader and partition table; without it, Windows cannot load. When overwritten, the system may only display your custom message and refuse to boot into the OS. The OS will only work if you fix the MBR, but chances are you will have to reinstall the OS.

8.1 Usage

PS > Set-MasterBootRecord -BootMessage 'Pwned'

8.2 Forçar reboot imediato / Force immediate reboot

PS > Set-MasterBootRecord -BootMessage 'Pwned' -Force -RebootImmediately
O sistema deixa de arrancar para o Windows. It will no longer boot into Windows.

10. Mitigações Blue Team / Mitigations Complementar

  1. Restricted Language Mode — bloquear chamadas .NET/WMI arbitrárias; essencial em workstations onde os utilizadores não precisam de PowerShell. / blocks arbitrary .NET/WMI calls; essential on workstations where users don't need PowerShell.
  2. AppLocker/WDAC — bloquear execução de loadram.ps1, loadcpu.ps1, license.ps1, killer.ps1. / block execution of these scripts.
  3. Desativar PowerShell 2.0 — evita downgrade. / prevents downgrade.
  4. Monitorizar criação de ficheiros .ps1 e execução com -ep bypass. / monitor .ps1 creation and -ep bypass execution.
  5. Proteger o MBR — firmware/UEFI Secure Boot, discos com proteção contra escrita no setor 0. / firmware/UEFI Secure Boot, write-protected sector 0.
  6. Backups e snapshots regulares — única defesa real contra MBR corruption. / regular backups and snapshots — the only real defense against MBR corruption.
  7. AMSI + Script Block Logging (4104) — deteta strings como Set-MasterBootRecord, Set-CriticalProcess, loadram. / detects these strings.
  8. Desativar USB storage via GPO onde não é necessário. / disable USB storage via GPO where not needed.
