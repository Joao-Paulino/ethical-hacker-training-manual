1. Objetivos de Aprendizagem / Learning Objectives

Compreender o que é o LDAP e como o PowerShell o usa para consultar Active Directory; dominar filtros PowerShell (Get-ADUser, Get-ADComputer, Get-ADGroup, Get-ADGroupMember); dominar filtros LDAP nativos (-LDAPFilter) com operadores lógicos e OID bitwise; identificar contas AS-REP e Kerberoastable; enumerar delegação, SO legado, Domain Admins e passwords antigas; mapear técnicas a MITRE ATT&CK e propor mitigações. Understand what LDAP is and how PowerShell uses it to query Active Directory; master PowerShell filters (Get-ADUser, Get-ADComputer, Get-ADGroup, Get-ADGroupMember); master native LDAP filters (-LDAPFilter) with logical operators and bitwise OID; identify AS-REP and Kerberoastable accounts; enumerate delegation, legacy OS, Domain Admins, and stale passwords; map techniques to MITRE ATT&CK and propose mitigations.

2. Contexto e Relevância / Context and Relevance Original

O LDAP é um protocolo para consultar serviços de diretório, permitindo obter detalhes sobre contas de utilizador, computadores, grupos ou políticas. Ao usar filtros LDAP em scripts PowerShell, podes recolher informação detalhada de um domínio sem alertar imediatamente os defensores. Como o LDAP é read-only e usa protocolos legítimos, passa frequentemente despercebido — é uma forma discreta de mapear o ambiente, descobrir relações de confiança e planear ações futuras. LDAP is a protocol for querying directory services, retrieving details about user accounts, computers, groups, or policies. By using LDAP filters in PowerShell scripts, you can quietly gather detailed domain information without immediately alerting defenders. Since LDAP is read-only and uses legitimate protocols, it often goes unnoticed — a discreet way to map the environment, uncover trust relationships, and plan further actions.

3. Filtros PowerShell / PowerShell Filters Original

3.1 Listar Software Instalado / List Installed Software

Get-CimInstance win32_product -Filter "NOT Vendor like '%Microsoft%'" | fl
Consulta a classe WMI Win32_Product, excluindo software Microsoft, e mostra em lista (fl). Ajuda a identificar o propósito do host e misconfigurations para escalada. Nota: Win32_Product é lento e pode disparar reparações MSI — em produção prefere ler as chaves Uninstall do registo. Queries WMI class Win32_Product, excluding Microsoft software, and lists output (fl). Helps identify host purpose and privilege-escalation misconfigurations. Note: Win32_Product is slow and can trigger MSI reconfiguration — in production prefer reading the registry Uninstall keys.

3.2 Filtrar Utilizadores / Filter Users

Get-ADUser -Filter {name -like "adm*"}
Devolve contas cujo name começa por "adm" — candidatos a contas administrativas em domínios antigos com contas legadas. Returns accounts whose name starts with "adm" — candidates for administrative accounts in legacy domains with stale accounts.

3.3 Filtrar Computadores / Filter Computers

Get-ADComputer -Filter "DNSHostName -like '*SQL*'"
Localiza hosts cujo DNSHostName contém "SQL" — útil para priorizar servidores de base de dados. Finds hosts whose DNSHostName contains "SQL" — useful to prioritize database servers.

3.4 Filtrar Grupos Administrativos / Filter Administrative Groups

Get-ADGroup -Filter "adminCount -eq 1" | Select-Object Name
adminCount = 1 marca objetos protegidos pelo AdminSDHolder (tipicamente controlados por Domain Admins). Têm permissões elevadas e são alvos de alto valor. adminCount = 1 flags objects protected by AdminSDHolder (typically controlled by Domain Admins). They hold elevated permissions and are high-value targets.

3.5 Filtrar Admins AS-REP Roastable / Filter AS-REP Roastable Admins

Get-ADUser -Filter {adminCount -eq 1 -and DoesNotRequirePreAuth -eq $true}
Contas com Kerberos pre-authentication desativada devolvem um AS-REP cifrado sem credenciais válidas. Se forem também admins (adminCount = 1), o impacto é máximo: o blob pode ser crackeado offline (Hashcat modo 18200) para recuperar a password. Accounts with Kerberos pre-authentication disabled return an encrypted AS-REP without valid credentials. If they are also admins (adminCount = 1), impact is maximal: the blob can be cracked offline (Hashcat mode 18200) to recover the password.

3.6 Filtrar Admins Kerberoastable / Filter Kerberoastable Admins

Get-ADUser -Filter "adminCount -eq '1'" -Properties * | where servicePrincipalName -ne $null | select SamAccountName,MemberOf,ServicePrincipalName | fl
Filtra admins (adminCount = 1) com SPN registado. Qualquer conta com SPN recebe TGS cifrado com o hash da password — um utilizador de domínio normal pode pedir o ticket e crackeá-lo offline (Hashcat modo 13100). O select mostra SamAccountName, grupos e SPNs. Filters admins (adminCount = 1) with a registered SPN. Any account with an SPN receives a TGS encrypted with its password hash — a normal domain user can request the ticket and crack it offline (Hashcat mode 13100). The select shows SamAccountName, groups, and SPNs.

3.7 Filtrar um Utilizador / Filter a User

Get-ADUser -Identity sql_service -Properties * | Select-Object * | Format-List
Extrai todos os atributos da conta sql_service e lista-os. Serve para aprofundar reconhecimento após identificar uma conta vulnerável (ver MemberOf, Description, PasswordLastSet). Pulls all attributes of the sql_service account and lists them. Used to deepen reconnaissance after spotting a vulnerable account (check MemberOf, Description, PasswordLastSet).

3.8 Contas PasswordNotRequired / PasswordNotRequired Accounts

Get-ADUser -Filter * -Properties PasswordNotRequired | Where-Object { $_.PasswordNotRequired } | Select-Object SamAccountName, Name
Identifica contas com a flag PasswordNotRequired, que podem ter password em branco — permitindo autenticação sem credenciais. Raro, mas crítico quando existe. Identifies accounts with the PasswordNotRequired flag, which may have blank passwords — allowing credential-less authentication. Rare, but critical when present.

3.9 Filtrar Descrições de Utilizador / Filter User Descriptions

Get-ADUser -Filter * -Properties Description | Select-Object SamAccountName, Name, Description
O campo Description é frequentemente mal configurado e pode conter credenciais ou informação sensível em texto claro — um clássico achado de auditoria. The Description field is often misconfigured and may contain plaintext credentials or sensitive info — a classic audit finding.

3.10 Filtrar Domain Admins / Filter Domain Admins

Get-ADGroupMember -Identity "Domain Admins" -Recursive | Where-Object { $_.objectClass -eq 'user' } | Select-Object Name, SamAccountName
Lista recursivamente membros do grupo Domain Admins, filtrando apenas objetos user (exclui grupos aninhados e computadores). Domain Admins/Enterprise Admins têm controlo total do domínio — são os "gems" do AD. Recursively lists Domain Admins members, keeping only user objects (excludes nested groups and computers). Domain Admins/Enterprise Admins have full domain control — the "gems" of AD.

3.11 Filtrar PasswordLastChanged / Filter PasswordLastChanged

Get-ADUser -Identity username -Properties PasswordLastSet | Select-Object SamAccountName, Name, @{Name='PasswordLastChanged';Expression={$_.PasswordLastSet}}

Get-ADUser -Filter "samAccountName -like 'Adm*'" -Properties PasswordLastSet | Where-Object { -not $_.PasswordLastSet -or $_.PasswordLastSet -lt (Get-Date).AddMonths(-1) } | Select-Object samAccountName, @{Name='PasswordLastChanged';Expression={$_.PasswordLastSet}}
1.º comando: consulta PasswordLastSet e cria uma propriedade calculada (@{Name=...;Expression={...}}) renomeada para PasswordLastChanged. 2.º comando: encontra contas Adm* cuja password nunca foi definida (-not $_.PasswordLastSet) ou não muda há mais de um mês (-lt (Get-Date).AddMonths(-1)). Isto permite encontrar contas ainda válidas após uma resposta a incidente em que o blue team forçou resets. 1st command: reads PasswordLastSet and creates a calculated property (@{Name=...;Expression={...}}) renamed to PasswordLastChanged. 2nd command: finds Adm* accounts whose password was never set (-not $_.PasswordLastSet) or not changed in over a month (-lt (Get-Date).AddMonths(-1)). This surfaces accounts still valid after an incident response where the blue team forced resets.

3.12 Contar Utilizadores / Counting Users

(Get-ADUser -SearchBase "OU=Employees,DC=DOMAIN,DC=LOCAL" -Filter *).Count
Conta utilizadores dentro de uma OU específica (-SearchBase) — dimensiona o ambiente e estima a superfície de misconfigurations. Substituir Employees e DOMAIN/LOCAL pelos valores reais. Counts users inside a specific OU (-SearchBase) — sizes the environment and estimates the misconfiguration surface. Replace Employees and DOMAIN/LOCAL with real values.

4. Filtros LDAP / LDAP Filters Original Complementar / Complementary

Os filtros LDAP são expressões textuais entre parênteses que especificam que objetos do AD recuperar. Usam a sintaxe LDAP: operadores lógicos & (AND), | (OR), ! (NOT). A regra OID 1.2.840.113556.1.4.803 é um bitwise AND sobre userAccountControl — permite testar flags individuais. LDAP filters are text expressions in parentheses specifying which AD objects to retrieve. They use LDAP syntax: logical operators & (AND), | (OR), ! (NOT). Rule OID 1.2.840.113556.1.4.803 is a bitwise AND on userAccountControl — lets you test individual flags.

4.1 Filtrar Descrições via LDAP / Filter Descriptions via LDAP

Get-ADUser -Properties * -LDAPFilter '(&(objectCategory=user)(description=*))' | select samaccountname, description
(&(...)(...)) = AND. Devolve utilizadores (objectCategory=user) que tenham qualquer descrição (description=*). Equivalente LDAP ao filtro PowerShell anterior, mas potencialmente mais rápido no DC. (&(...)(...)) = AND. Returns users (objectCategory=user) that have any description (description=*). LDAP equivalent of the previous PowerShell filter, potentially faster on the DC.

4.2 Filtrar Contas Trusted for Delegation / Filter Trusted Accounts

# trusted users
Get-ADUser -Properties * -LDAPFilter '(userAccountControl:1.2.840.113556.1.4.803:=524288)' | select Name, memberof, servicePrincipalName, TrustedForDelegation | fl

# trusted computers
Get-ADComputer -Properties * -LDAPFilter '(userAccountControl:1.2.840.113556.1.4.803:=524288)' | select DistinguishedName, servicePrincipalName, TrustedForDelegation | fl
O valor 524288 corresponde à flag TRUSTED_FOR_DELEGATION em userAccountControl (delegação irrestrita). Estas contas/máquinas podem ser abusadas para impersonar utilizadores de altos privilégios sem conhecer as suas passwords (ataques de delegação, ex.: S4U2Self/S4U2Proxy). O 1.º comando lista utilizadores; o 2.º, computadores. Value 524288 is the TRUSTED_FOR_DELEGATION flag in userAccountControl (unconstrained delegation). These accounts/computers can be abused to impersonate high-privilege users without knowing their passwords (delegation attacks, e.g., S4U2Self/S4U2Proxy). 1st command lists users; 2nd lists computers.

4.3 Filtrar Distribuições Windows / Filter Windows Distributions

# Windows Server 2012
Get-ADComputer -LDAPFilter '(samAccountType=805306369)(!(primaryGroupId=516))(objectCategory=computer)(operatingSystem=Windows Server 2012*)' -Properties OperatingSystem | Select Name, OperatingSystem

# Windows Server 2008
Get-ADComputer -LDAPFilter '(samAccountType=805306369)(!(primaryGroupId=516))(objectCategory=computer)(operatingSystem=Windows Server 2008*)' -Properties OperatingSystem | Select Name, OperatingSystem

# Windows Server 2003
Get-ADComputer -LDAPFilter '(samAccountType=805306369)(!(primaryGroupId=516))(objectCategory=computer)(operatingSystem=Windows Server 2003*)' -Properties OperatingSystem | Select Name, OperatingSystem
samAccountType=805306369 = tipo de conta computador. !(primaryGroupId=516) = exclui Domain Controllers (grupo 516). objectCategory=computer restringe a computadores. operatingSystem=Windows Server XXXX* filtra pela versão do SO. Objetivo: identificar servidores legados/desatualizados (2012, 2008, 2003) — alvos prioritários porque permitem múltiplas sessões sem fechar as ativas e têm menos proteções. Nota técnica: o artigo encadeia os sub-filtros sem um & externo; na prática, o Get-ADComputer aplica-os implicitamente, mas a forma canónica seria (&(samAccountType=805306369)(!(primaryGroupId=516))(objectCategory=computer)(operatingSystem=...)). samAccountType=805306369 = computer account type. !(primaryGroupId=516) = excludes Domain Controllers (group 516). objectCategory=computer restricts to computers. operatingSystem=Windows Server XXXX* filters by OS version. Goal: identify legacy/outdated servers (2012, 2008, 2003) — priority targets because they allow multiple sessions without closing active ones and have fewer protections. Technical note: the article chains sub-filters without an outer &; in practice Get-ADComputer applies them implicitly, but the canonical form would be (&(...)(...)(...)(...)).

6. Mitigações Blue Team / Blue Team Mitigations Complementar / Complementary

  1. Advanced Audit Policy → Directory Service Access — ativar e monitorizar evento 4662 (acesso a objetos AD). / enable and monitor event 4662.
  2. Alertar sobre consultas LDAP com userAccountControl bitwise, DoesNotRequirePreAuth, servicePrincipalName=*, enumeração massiva de Description. / Alert on these.
  3. Honeytokens — contas/descrições falsas com "password" para detetar enumeração. / fake accounts/descriptions with "password".
  4. Remover TRUSTED_FOR_DELEGATION desnecessário; preferir constrained ou resource-based delegation. / remove unnecessary; prefer constrained or RBCD.
  5. Desativar Kerberos pre-auth só quando exigido; auditar contas com DoesNotRequirePreAuth. / disable only when required; audit such accounts.
  6. Auditar PasswordNotRequired e PasswordLastSet antigos; forçar rotação. / audit and force rotation.
  7. gMSA (group Managed Service Accounts) para serviços com SPN — passwords longas e rotativas. / for SPN services — long rotating passwords.
  8. Limitar adminCount=1 ao mínimo; rever AdminSDHolder. / minimize; review AdminSDHolder.
  9. Proteger Description — política de não guardar segredos; DLP. / policy against secrets; DLP.
  10. Remover SO legado (2003/2008/2012) ou isolar em VLANs restritas. / remove or isolate in restricted VLANs.
  11. Monitorizar Get-AD* em endpoints não-admin via PowerShell logging (4104). / monitor via 4104.
