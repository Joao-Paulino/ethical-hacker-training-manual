2. AnyDesk — Artefactos Forenses Original

O AnyDesk é uma ferramenta de acesso remoto legítima, mas é frequentemente abusada por APTs. Os artefactos forenses incluem ficheiros de trace, logs de sessão, registo e Prefetch. O LOLRMM documenta os caminhos exatos: C:\Users\%username%\AppData\Roaming\AnyDesk\ad.trace, C:\Users\%username%\AppData\Roaming\AnyDesk\connection_trace.txt, C:\ProgramData\AnyDesk\ad_svc.trace. Um estudo forense confirma que os logs de sessão e traces de conexão são recuperáveis, e que os artefactos de memória são críticos para capturar conexões em curso. AnyDesk is a legitimate remote access tool, but it's frequently abused by APTs. Forensic artifacts include trace files, session logs, registry, and Prefetch. LOLRMM documents the exact paths: C:\Users\%username%\AppData\Roaming\AnyDesk\ad.trace, C:\Users\%username%\AppData\Roaming\AnyDesk\connection_trace.txt, C:\ProgramData\AnyDesk\ad_svc.trace. A forensic study confirms that session logs and connection traces are recoverable, and memory artifacts are critical for capturing in-session connections.

2.1 Comandos de análise / Analysis commands

# Listar artefactos AnyDesk

# Ler traces
Get-Content "$env:APPDATA\AnyDesk\ad.trace" -Tail 100
Get-Content "$env:APPDATA\AnyDesk\connection_trace.txt" -Tail 50

3. DeadMatter — Extração de Credenciais de Memória Original

O DeadMatter é uma ferramenta C# que extrai credenciais (NTLM hashes, DPAPI keys) de dumps de memória sem offsets fixos, usando estrutura scanning e carving. Funciona em raw dumps, minidumps, ficheiros de hibernação e ficheiros de memória de VMs. É útil quando o EDR/AV bloqueia o dump direto do LSASS — em vez de exfiltrar um dump enorme, processa localmente e extrai só o essencial. DeadMatter is a C# tool that extracts credentials (NTLM hashes, DPAPI keys) from memory dumps without fixed offsets, using structure scanning and carving. It works on raw dumps, minidumps, hibernation files, and VM memory files. It's useful when EDR/AV blocks direct LSASS dumping — instead of exfiltrating a huge dump, it processes locally and extracts only the essentials.

4. Nyx — Limpeza de Artefactos Forenses Original

O Nyx é um script self-contained que limpa artefactos forenses em Linux, macOS e Windows. Em Windows, os módulos incluem events (Security, Sysmon, PowerShell/Operational, AMSI, etc.), history (PowerShell history, Prefetch, Jump Lists), registry (MRUs, USB history, ShellBags, UserAssist). Nyx is a self-contained script that cleans forensic artifacts on Linux, macOS, and Windows. On Windows, modules include events (Security, Sysmon, PowerShell/Operational, AMSI, etc.), history (PowerShell history, Prefetch, Jump Lists), registry (MRUs, USB history, ShellBags, UserAssist).

5. Scripts de Impacto / Impact Scripts Impacto Complementar

Os scripts abaixo consolidam a análise dos artefactos numa única execução, com output legível e exportação para relatório. The scripts below consolidate artifact analysis into a single run, with readable output and report export.

5.1 Script 18.1 — Análise de Artefactos AnyDesk / AnyDesk Artifact Analysis

# Script 18.1 - AnyDesk Artifact Analyzer
$paths = @(
  "$env:APPDATA\AnyDesk",
  "$env:PROGRAMDATA\AnyDesk",
  "C:\Windows\SysWOW64\config\systemprofile\AppData\Roaming\AnyDesk"
)
$results = @()
foreach ($p in $paths) {
  if (Test-Path $p) {
    Get-ChildItem $p -Recurse -File -EA SilentlyContinue | ForEach-Object {
      $results += [PSCustomObject]@{
        Path = $_.FullName; Size = $_.Length
        SHA256 = (Get-FileHash $_.FullName -Algorithm SHA256).Hash
        LastWrite = $_.LastWriteTime
      }
    }
  }
}
$out = ".\anydesk-artifacts.csv"
$results | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] AnyDesk artifacts: $($results.Count) -> $out" -ForegroundColor Green

5.2 Script 18.2 — Deteção de AnyDesk Fora do Padrão / Non-Standard AnyDesk Detection

# Script 18.2 - Non-Standard AnyDesk Detection (Sigma rule logic)
$out = ".\anydesk-suspicious.csv"
$hits = @()
Get-WinEvent -LogName Security -MaxEvents 2000 -EA SilentlyContinue |
  Where-Object { $_.Id -eq 4688 } | ForEach-Object {
    $xml = [xml]$_.ToXml()
    $proc = ($xml.Event.EventData.Data | Where-Object Name -eq "NewProcessName").'#text'
    if ($proc -match "AnyDesk" -and $proc -notmatch "Program Files") {
      $hits += [PSCustomObject]@{ Time=$_.TimeCreated; Process=$proc }
    }
  }
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] Suspicious AnyDesk: $($hits.Count) -> $out" -ForegroundColor Red

5.3 Script 18.3 — Verificação de Integridade Pós-Nyx / Post-Nyx Integrity Check

# Script 18.3 - Forensic Artifact Integrity Check (deteta limpeza)
$checks = [ordered]@{
  "Security log exists" = (Get-WinEvent -LogName Security -MaxEvents 1 -EA SilentlyContinue) -ne $null
  "PowerShell history exists" = Test-Path "$env:APPDATA\Microsoft\Windows\PowerShell\PSReadLine\ConsoleHost_history.txt"
  "Prefetch files count" = (Get-ChildItem "C:\Windows\Prefetch\*.pf" -EA SilentlyContinue).Count
  "Sysmon log exists" = (Get-WinEvent -LogName "Microsoft-Windows-Sysmon/Operational" -MaxEvents 1 -EA SilentlyContinue) -ne $null
}
$checks.GetEnumerator() | ForEach-Object {
  $c = if ($_.Value -eq $true -or ($_.Value -is [int] -and $_.Value -gt 0)) { "Green" } else { "Red" }
  Write-Host "$($_.Key): $($_.Value)" -ForegroundColor $c
}

7. Mitigações Blue Team / Mitigations Complementar

  1. Monitorizar AnyDesk — alertar sobre execução fora de Program Files.
  2. Credential Guard — ativar para proteger credenciais de memory carving.
  3. Centralizar logs — o Nyx limpa artefactos locais, mas SIEM/EDR externos preservam evidência.
  4. Monitorizar criação de serviços e execução de binários em Temp.
  5. Sysmon + Script Block Logging — telemetria que o Nyx não consegue limpar se centralizada.
  6. Honeytokens — traces AnyDesk falsos, logs canário.
  7. Backups offline — contra limpeza de artefactos.
