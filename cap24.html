3. Variáveis e Output Original

Em Bash, declarar uma variável é tão simples como escrever foo=1. Em PowerShell, precisas de adicionar um cifrão: $foo=1. Para imprimir o valor de uma variável no ecrã, podes usar o universal echo ou o cmdlet específico Write-Host. É mais longo? Definitivamente. Mas o benefício é que com Write-Host podes controlar o output de formas interessantes. In Bash, declaring a variable is as simple as writing foo=1. In PowerShell, you need to add a dollar sign: $foo=1. To print the value of a variable to the screen, you can use the universal echo or the PowerShell-specific cmdlet Write-Host. Is it longer? Definitely. But the benefit is that with Write-Host you can control the output in interesting ways.

3.1 Write-Host com formatação / Write-Host with formatting

PS > Write-Host (2,4,6,8,10,12) -Separator "->" -ForegroundColor DarkMagenta -BackgroundColor White
Este snippet imprime a sequência de números dentro dos parênteses, coloca -> entre eles, e muda tanto a cor do texto como do fundo. Para um script descartável não é necessário, mas para um relatório diário pode ser bastante útil. This snippet will print the sequence of numbers inside the parentheses, place a -> between them, and also change both the text and the background colors. For a quick throwaway script this isn't necessary, but for a daily report it might be quite useful.

5. Exemplo Prático: Test-Connection Original

Suponhamos que queremos medir o tempo médio de resposta de um website como google.com. Para isso precisamos de enviar vários pings e calcular a média. Suppose we want to measure the average response time from a website like google.com. To do this we need to send several pings and calculate the average. 
Write-Host `n "Waiting for test ..."
$Avg = 0
$Site = "www.google.com"
$PingSite = Test-Connection -Count 5 $Site
$Avg = ($PingSite | Measure-Object ResponseTime -Average)
$Calc = ($Avg.Average) -as [int]
Clear-Host
Write-Host "Average response time to $Site is $Calc ms"
Se não fizermos cast do valor para inteiro, obtemos um número de vírgula flutuante, o que não é muito conveniente para este propósito. Este é um dos casos em que um comando PowerShell é realmente mais forte que o clássico ping do Linux. O cmdlet Test-Connection produz objetos estruturados que já contêm tempos de resposta, estado e outras propriedades úteis. Isso significa que podes canalizar os resultados diretamente para ferramentas como Measure-Object e fazer matemática sem precisar de parsear texto com awk ou grep. If we don't cast the value to an integer, we get a floating-point number, which isn't very convenient for this purpose. This is one of the instances where a PowerShell command is actually stronger than the classic Linux ping. The Test-Connection cmdlet outputs structured objects that already contain response times, status, and other useful properties. That means you can pipe the results directly into tools like Measure-Object and do math on them without needing to parse text with awk or grep.

6. Aliases Original

Para tornar o PowerShell mais fácil de usar, podes criar aliases. Vale a pena verificar os aliases já disponíveis no teu sistema. To make PowerShell easier to use, you can create aliases. It's worth checking the aliases already available on your system. 
PS > Get-Alias
Aliases podem até apontar para programas. Por exemplo, vamos criar um alias para lançar a calculadora: Aliases can even point to programs. For example, let's make an alias for launching the calculator: 
PS > Set-Alias -Name calc -Value calc.exe
Para remover um alias: To remove an alias: 
PS > Remove-Item alias:calc

7. Funções Original

Se queres que o teu alias represente um comando com parâmetros, precisas de o envolver numa função. If you want your alias to represent a command with parameters, you need to wrap it in a function. 
function AL01 { Test-Connection -Count 2 google.com }
Set-Alias ping AL01
Agora quando escreveres ping, ele fará dois pings a google.com. Nota: uma vez que fechas o PowerShell, todos os aliases criados desta forma desaparecem. Now when you type ping, it will perform two pings to google.com. Note: once you close PowerShell, all aliases you created this way disappear.

8. Profile Original

Para manter os aliases permanentemente, precisas de os guardar no teu profile. O PowerShell tem na verdade quatro profiles possíveis. Podes vê-los com: To keep them permanently, you need to save them in your profile. PowerShell actually has four possible profiles. You can see them with: 
PS > $profile | Format-List -Force
Para verificar se existem no teu sistema: To check if they exist on your system: 
PS > $profile | Format-List -Force | ForEach-Object { Test-Path $_ }
Se o resultado for False, o ficheiro simplesmente não existe. Podes criá-lo e adicionar os teus aliases e funções. If the result is False, the file simply doesn't exist. You can create it and add your aliases and functions.

9.1 Script 24.1 — Equivalente de grep/awk em PowerShell / grep/awk Equivalent

# Script 24.1 - grep/awk equivalent
param([string]$File, [string]$Pattern)
Get-Content $File | Select-String -Pattern $Pattern | ForEach-Object { $_.Line }

9.2 Script 24.2 — Teste de Conectividade em Massa / Bulk Connectivity Test

# Script 24.2 - Bulk ping test with average
param([string[]]$Targets)
$results = foreach ($t in $Targets) {
  $p = Test-Connection -Count 3 $t -EA SilentlyContinue
  if ($p) {
    $avg = ($p | Measure-Object ResponseTime -Average).Average
    [PSCustomObject]@{ Target=$t; AvgMs=[math]::Round($avg,0); Status="OK" }
  } else {
    [PSCustomObject]@{ Target=$t; AvgMs=0; Status="FAIL" }
  }
}
$results | Format-Table -AutoSize
$results | Export-Csv ".\ping-results.csv" -NoTypeInformation -Encoding UTF8

9.3 Script 24.3 — Mapeamento de Aliases Bash → PowerShell / Alias Mapping

# Script 24.3 - Bash to PowerShell alias reference
$mapping = [ordered]@{
  "ls" = "Get-ChildItem"; "cat" = "Get-Content"; "grep" = "Select-String"
  "ps" = "Get-Process"; "kill" = "Stop-Process"; "pwd" = "Get-Location"
  "echo" = "Write-Output"; "cp" = "Copy-Item"; "mv" = "Move-Item"
  "rm" = "Remove-Item"; "man" = "Get-Help"; "find" = "Get-ChildItem -Recurse"
}
$mapping.GetEnumerator() | ForEach-Object {
  [PSCustomObject]@{ Bash=$_.Key; PowerShell=$_.Value }
} | Format-Table -AutoSize
