2. Contexto e Relevância / Context and Relevance Original

Em ambientes protegidos por EDR, o dump direto do LSASS é rapidamente bloqueado ou sinalizado. O DeadMatter propõe uma mudança de abordagem: em vez de lutar contra as proteções, captura uma imagem completa de memória com uma ferramenta DFIR legítima (FTK Imager, DumpIt) e analisa-a offline, onde o EDR não vê. O que fica no alvo é um artefacto de "captura de memória" — que em muitos ambientes é interpretado como resposta a incidentes legítima, não como ataque. In EDR-protected environments, direct LSASS dumping is quickly blocked or flagged. DeadMatter proposes a shift in approach: instead of fighting protections, it captures a full memory image with a legitimate DFIR tool (FTK Imager, DumpIt) and analyzes it offline, where the EDR can't see. What remains on the target is a "memory capture" artifact — which in many environments is interpreted as legitimate incident response, not attack.

3. O que é DeadMatter Original

O DeadMatter é uma ferramenta C# que extrai credenciais de dumps de memória sem depender de offsets fixos. Em vez de apenas parsing estruturado (como o Mimikatz faz), faz também signature carving: procura padrões de credenciais nos bytes brutos, mesmo que o dump esteja incompleto ou não siga o formato esperado. Inputs suportados: raw dumps, minidumps de LSASS, ficheiros de hibernação descomprimidos, e ficheiros de memória de VMs. Outputs: NTLM hashes, DPAPI master/pre-keys, e metadados de sessões de logon. DeadMatter is a C# tool that extracts credentials from memory dumps without relying on fixed offsets. Instead of only structured parsing (like Mimikatz), it also performs signature carving: it searches for credential patterns in raw bytes, even if the dump is incomplete or doesn't follow the expected format. Supported inputs: raw dumps, LSASS minidumps, decompressed hibernation files, and VM memory files. Outputs: NTLM hashes, DPAPI master/pre-keys, and logon session metadata.

4. Credential Guard Original

Antes de capturar memória, verifica o estado do Credential Guard. Se estiver ativo, as credenciais são isoladas em LsaIso.exe (VTL1) e não ficam acessíveis no dump de memória padrão. Em muitas empresas, Windows 10 Pro e Windows Server anteriores a 2025 ainda têm o Credential Guard desativado, pelo que esta verificação é rápida e frequentemente favorável. Before capturing memory, check Credential Guard status. If enabled, credentials are isolated in LsaIso.exe (VTL1) and aren't accessible in a standard memory dump. In many enterprises, Windows 10 Pro and Windows Server versions prior to 2025 still have Credential Guard disabled, so this check is quick and often favorable. 
PS > Get-CimInstance -ClassName Win32_DeviceGuard -Namespace root\Microsoft\Windows\DeviceGuard
Se o resultado indicar {0} (desativado), podes prosseguir. Caso contrário, esta técnica não funcionará nesse alvo. If the result indicates {0} (disabled), you can proceed. Otherwise, this technique won't work on that target.

7. Scripts de Impacto / Impact Scripts Impacto Complementar

Os scripts abaixo ajudam o blue team a detetar a cadeia de dois estágios do DeadMatter: captura de memória e execução offline. The scripts below help the blue team detect DeadMatter's two-stage chain: memory capture and offline execution.

7.1 Script 20.1 — Deteção de Captura de Memória / Memory Capture Detection

Objetivo: detetar execução de FTK Imager, DumpIt, ou WinPmem (ferramentas de captura de memória) fora de contexto de IR autorizado. Evidência: memcapture-detect.csv. Goal: detect FTK Imager, DumpIt, or WinPmem execution (memory capture tools) outside authorized IR context. Evidence: memcapture-detect.csv. 
# Script 20.1 - Memory Capture Tool Detection
$out = ".\memcapture-detect.csv"
$patterns = @("FTK Imager", "DumpIt", "winpmem", "Memoryze", "Belkasoft")
$hits = @()
Get-WinEvent -LogName Security -MaxEvents 3000 -EA SilentlyContinue |
  Where-Object { $_.Id -eq 4688 } | ForEach-Object {
    $xml = [xml]$_.ToXml()
    $proc = ($xml.Event.EventData.Data | Where-Object Name -eq "NewProcessName").'#text'
    $cmd  = ($xml.Event.EventData.Data | Where-Object Name -eq "CommandLine").'#text'
    foreach ($p in $patterns) {
      if ($proc -match $p -or $cmd -match $p) {
        $hits += [PSCustomObject]@{ Time=$_.TimeCreated; Tool=$p; Command=$cmd }
      }
    }
  }
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] Memory capture tools: $($hits.Count) -> $out" -ForegroundColor Red

7.2 Script 20.2 — Deteção de Dumps Grandes em Disco / Large Dump File Detection

Objetivo: detetar ficheiros .raw, .dmp ou .mem de tamanho anormalmente grande (acima de 1 GB) em diretórios de utilizador ou Temp. Evidência: large-dumps.csv. Goal: detect .raw, .dmp, or .mem files of abnormally large size (over 1 GB) in user or Temp directories. Evidence: large-dumps.csv. 
# Script 20.2 - Large Dump File Detection
$out = ".\large-dumps.csv"
$hits = @()
$searchPaths = @("C:\Users", "C:\Windows\Temp", "C:\Temp")
foreach ($base in $searchPaths) {
  Get-ChildItem $base -Recurse -Include "*.raw","*.dmp","*.mem" -File -EA SilentlyContinue |
    Where-Object { $_.Length -gt 1GB } |
    ForEach-Object {
      $hits += [PSCustomObject]@{ Path=$_.FullName; SizeGB=[math]::Round($_.Length/1GB,2); LastWrite=$_.LastWriteTime }
    }
}
$hits | Export-Csv $out -NoTypeInformation -Encoding UTF8
Write-Host "[+] Large dumps: $($hits.Count) -> $out" -ForegroundColor Yellow

7.3 Script 20.3 — Verificação de Credential Guard / Credential Guard Check

Objetivo: verificar se o Credential Guard está ativo (se estiver, o DeadMatter não consegue extrair credenciais do dump). Evidência: output no ecrã. Goal: check if Credential Guard is enabled (if so, DeadMatter can't extract credentials from the dump). Evidence: on-screen output. 
# Script 20.3 - Credential Guard Status Check
$dg = Get-CimInstance -ClassName Win32_DeviceGuard -Namespace root\Microsoft\Windows\DeviceGuard -EA SilentlyContinue
if ($dg) {
  $status = $dg.SecurityServicesRunning
  if ($status -contains 1 -or $status -contains 2) {
    Write-Host "[!] Credential Guard is ENABLED (VBS running)" -ForegroundColor Red
    Write-Host "    DeadMatter extraction will likely FAIL on this host." -ForegroundColor Red
  } else {
    Write-Host "[+] Credential Guard is DISABLED - extraction feasible" -ForegroundColor Green
  }
  Write-Host "VirtualizationBasedSecurityStatus: $($dg.VirtualizationBasedSecurityStatus)"
  Write-Host "SecurityServicesRunning: $($status -join ',')"
} else {
  Write-Host "[?] Could not query DeviceGuard (may not be available)" -ForegroundColor Yellow
}

9. Mitigações Blue Team / Mitigations Complementar

  1. Ativar Credential Guard — torna a extração impossível em muitos casos.
  2. Monitorizar execução de ferramentas DFIR (FTK, DumpIt, WinPmem) — Script 20.1.
  3. Alertar sobre dumps grandes em disco — Script 20.2.
  4. Monitorizar criação de ficheiros .raw/.dmp/.mem em diretórios de utilizador.
  5. Restringir execução de binários não assinados — AppLocker/WDAC.
  6. Egress filtering — bloquear exfiltração de dumps para fora da rede.
  7. Honeytokens — ficheiros de dump falsos com credenciais isca.
